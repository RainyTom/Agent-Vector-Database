# 方法草案：span-aware episode index

更新日期：2026-10-24。对象是[问题定义 v4](problem-definition.md)。本文给出初始索引与算法；基线见[baseline.md](baseline.md)，基线只保留标准做法。

## 1. 要解决的结构性困难

episode 的四个约束里，时间窗与空间范围可以对段下推，持续时间与段数只依赖区间端点。因此：

- 只按段过滤（无论先时间还是先空间）都无法判断一个候选区间是否满足 $P_\Delta$ 与 $P_m$；
- 只按段向量检索（ANN）也无法保证候选能组装成满足跨度的 episode；
- 穷举 $[u,v]$ 的代价是 $O(s^2)$ 个候选区间，而每个区间的 DTW 是 $O(msd)$。

方法的核心不是“换一个更强的 ANN”，而是**把 span 约束与向量下界放进同一个候选枚举结构**，让精确 DTW 只作用于少量区间。

## 2. 索引结构

### 2.1 S1：段序列区间树（per trajectory）

对每条轨迹的段序列 $\sigma_1..\sigma_s$ 建静态平衡树，叶子是单段，内部节点覆盖连续段区间 $[l,r]$，存：

| 字段 | 用途 |
|---|---|
| $\min t^{s}$，$\max t^{e}$ | 判定 $P_W$ 与时间跨度可行性 |
| $\operatorname{bbox}(X_{l:r})$ | 判定 $P_R$ |
| $r-l+1$ | 判定 $P_m$ |
| $\bar{\mathbf e}$、$\max\lVert\mathbf e\rVert$、簇计数 | 向量下界 |
| $\operatorname{LB}(\cdot)$ 缓存 | 可选：按查询缓存节点下界 |

内存：每段约 40 B 加向量摘要；对 $s\le 10^3$ 的轨迹可忽略。

### 2.2 S2：时空单元倒排

把段按（时间桶, 空间单元）分桶，键为

$$
(\lfloor t^{s}_k/\Delta_T\rfloor,\ \lfloor \ell_k/\Delta_S\rfloor),
$$

值为段 id 或轨迹 id。查询时取 $W$ 覆盖的时间桶与 $R$ 覆盖的空间单元的交集，得到候选轨迹集合。$\Delta_T$ 与 $\Delta_S$ 是构建参数，实验中固定并报告。

### 2.3 S3：语义路由（可选，第二阶段）

对段向量做 $K$ 类聚类，每个（时间桶, 空间单元）内按簇建倒排或小 HNSW；查询第 $i$ 个单元按 $\tau_i$ 选择时间桶偏移，形成“对角”路由。S3 是可选的候选生成加速，不改变正确性定义：启用时为近似模式。

## 3. 查询算法

输入 $Q=(\mathbf q_{1..m};\tau_{1..m};W;R;\delta_\Delta;k)$。

### 阶段 0：查询预处理

- 计算 $\Delta_Q=\tau_m$；
- 计算 $W$ 覆盖的时间桶集合与 $R$ 覆盖的空间单元集合；
- 若启用 S3，计算每个查询单元的时间桶偏移。

### 阶段 1：候选轨迹

取 S2 中时间桶与空间单元交集的轨迹集合 $C$（可按桶大小做选择顺序：先取最小的桶）。

若 $|C|$ 超过预算 $C_{\max}$，按“命中桶数”降序截断；截断只在近似模式下允许。

### 阶段 2：span 可行性枚举（S1）

对每条候选轨迹，枚举可行起点 $u$：$t^{s}_u\ge w_s$。对每个 $u$，终点 $v$ 必须满足

$$
t^{e}_v\le w_e,\qquad
t^{e}_v-t^{s}_u\in[\Delta_Q-\delta_\Delta,\ \Delta_Q+\delta_\Delta],\qquad
v-u+1\ge m .
$$

由于 $t^{e}_v$ 随 $v$ 单调，$v$ 的可行集合是一个连续区间 $[v_{\min}(u),v_{\max}(u)]$，用双指针在 $O(s)$ 内得到，不需要枚举 $O(s^2)$。

### 阶段 3：下界剪枝

对候选区间 $[u,v]$，用 S1 的节点摘要计算

$$
\mathrm{LB}(Q,[u,v])
=
\frac{1}{m}\sum_{i=1}^{m}\min_{j\in[u,v]}\lVert \mathbf q_i-\mathbf e_j\rVert .
$$

性质：任何对齐路径（步长 $(1,1)/(0,1)$）的代价至少是每个查询单元到区间内最近段距离之和，因此 $\mathrm{LB}\le D_{\mathrm{norm}}$，剪枝不漏解。

实现上用规范覆盖的 $O(\log s)$ 个节点近似 $\min_j$：节点只存 $\bar{\mathbf e}$ 与 $\max\lVert\mathbf e\rVert$ 时，取

$$
\min_{j}\lVert\mathbf q_i-\mathbf e_j\rVert
\ \ge\ \lVert\mathbf q_i\rVert-\max_{j}\lVert\mathbf e_j\rVert ,
$$

该下界很松，作为第一版基线；第二阶段把节点摘要换成 $B$ 个簇中心，用 $\min_b(\lVert\mathbf q_i-\mathbf c_b\rVert-\text{radius}_b)$ 收紧。

维护当前 top-k 的第 $k$ 名分数 $\theta$；若 $\mathrm{LB}\ge\theta$，跳过该区间。

### 阶段 4：精确验证

对通过剪枝的区间算精确 DTW（步长 $(1,1)/(0,1)$，归一化 $D/m$），更新每轨迹最优与全局 top-k。

### 阶段 5：输出

按 $(s_Q,\operatorname{id})$ 取前 $k$，返回轨迹、分数、段区间与时间区间。

## 4. 正确性与复杂度

**命题 2（不漏解）** 在候选集完整（不截断）且下界有效时，算法返回与穷举相同的 top-k。

证明：阶段 2 的 $v$ 区间由单调性给出，覆盖全部满足 $P_W,P_\Delta,P_m$ 的端点；阶段 3 的下界对任意对齐路径成立，故被剪掉的区间不可能优于当前第 $k$ 名；阶段 4 精确计算剩余区间。

**复杂度**：

| 阶段 | 成本 |
|---|---|
| 候选轨迹 | $O(|C|)$ |
| span 枚举 | $O(s)$ 每轨迹（双指针） |
| 下界 | $O(\log s)$ 每候选区间（第一版 $O(\log s)$ 节点） |
| 精确 DTW | $O(msd)$ 每未剪枝区间 |

相对 B2 的改进点是：把“所有可行区间都算 DTW”变成“只有下界低于 $\theta$ 的区间才算”，并且 span 枚举由 $O(s^2)$ 降到 $O(s)$。

## 5. 与基线的差异（必须用隔离实验证明）

| 对比 | 只允许改变的部件 | 期望结果 |
|---|---|---|
| B2 → 本方法 | 只加 span 枚举与下界 | 召回不变（1.0），DTW 次数显著下降 |
| B4 → 本方法 | 只把候选生成换成 S2+S3 | 相同召回下候选数下降或延迟下降 |
| 同预算 | 固定候选数 $C$ | 本方法 recall 更高 |

若召回不变而 DTW 次数不降，说明下界无效；若 DTW 下降但延迟不降，说明验证不是瓶颈。

## 6. 第一版实现计划（MVP）

1. **建 S1**：对每条轨迹的段数组建前缀摘要（时间、bbox、段数、向量均值与最大范数），先不做树，用前缀数组做 $O(1)$ 区间摘要；span 枚举用双指针。
2. **建 S2**：时间桶 $\Delta_T$=30 天，空间网格 $\Delta_S$=0.05°；桶内保存轨迹 id 与段的 bbox。
3. **查询**：S2 取候选 → S1 双指针枚举 → 范数下界剪枝 → 精确 DTW。
4. **度量**：与 B2 同候选集对比 DTW 次数；与 B4 同召回对比候选数。
5. **第二阶段**：把前缀摘要换成区间树；把范数下界换成 $B$ 簇中心下界；加入 S3 语义路由。

## 7. 风险

1. **下界太松**：高维单位向量上范数下界接近 0；需实测 $\mathrm{LB}/D$ 分布，必要时改用簇中心或 PCA 投影。
2. **span 枚举退化**：若 $\delta_\Delta$ 很大，$v$ 区间变宽，候选区间数仍接近 $O(s^2)$；需要用下界或长度带进一步限制。
3. **时间桶粒度**：桶太粗则候选多，太细则跨桶查询成本高；需报告 $\Delta_T$ 敏感性。
4. **近似模式的召回**：S3 与候选截断都会漏解；必须给召回-延迟曲线，不能只报单点。
5. **工程化陷阱**：若收益只来自“更快的 DTW 实现”或“更小的候选预算”，不算结构贡献；隔离实验必须固定这两者。
