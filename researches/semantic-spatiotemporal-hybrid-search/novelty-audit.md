# 新颖性审计：时间窗语义 episode 检索

更新日期：2026-10-23。状态：**初步审计，未完成系统查重**。本文回答两个问题：

1. 当前问题是否已经有直接同问题工作？
2. 如果没有，是否只需要自建简单基线，而不必改造他人方案？

结论先行：**目前只能称为“候选新问题”，不能声称“别人未曾解决”。** 初步检索未发现同时覆盖“稠密语义序列 + 绝对时间窗/持续时间 + 空间范围 + top-k episode 区间 + DTW 排序”的直接工作；但存在多篇强相邻工作，其中 ETQ（ICDE 2017）在“查询点序列 → top-k 轨迹”上最接近。是否构成新问题，取决于我们能否把差异收敛到时间可行性与 episode 定位，而不是泛泛的“轨迹检索”。

## 1. 逐篇对照

|---|---|---|---|---|---|---|---|

## 3. 判定

**支持“新问题”的证据**：

- 没有一篇工作同时要求“绝对时间窗 + 持续时间容差 + 空间范围”下，对**连续语义 episode** 做 top-k DTW 检索并返回区间。
- ETQ 的查询是点序列+关键词，时间不是查询约束；TISIS* 不做 episode 定位与时间窗；SimSub 不做稠密语义+时间窗。

**反对“全新”的证据**：

- ETQ 已经形式化“查询点序列 → top-k 轨迹”的点级匹配与 top-k 聚合；如果只把关键词换成 embedding，容易被审稿人视为 ETQ 的 embedding 变体。
- SimSub 已经研究“查询轨迹 → 子轨迹”的 top-k/代表子轨迹；只是几何/学习距离，不是时间窗语义 episode。
- TANNS/TANGO 已经覆盖时间向量检索；时间本身不是新意。
- 我们的索引（城市+季度 HNSW + 候选验证）是系统组合，不是新的 ANN 理论。

**结论**：当前应定位为 **“时间可行、可解释的语义 episode 检索”**，新意在问题约束与输出语义，而不是“轨迹检索”或“ANN 索引”本身。必须通过系统查重证明 ETQ/SimSub/TISIS* 都不能表达这三个硬约束；否则应收缩为“在 ETQ/SimSub 上增加时间可行性”的聚焦扩展。

## 4. 基线策略（按“新问题”假设）

如果审计确认没有直接同问题工作，**不需要改造所有他人方案**。合理基线是：

1. **精确 oracle**：全用户扫描 + 枚举可行 episode + DTW。必须。
2. **时间/空间过滤 + 扫描**：证明索引不是靠过滤本身取得的收益。
3. **类别倒排 + 精确验证**：硬过滤基线。
4. **整轨迹均值 kNN + 精确验证**：粗表示基线。
5. **点级 ANN + 精确验证**：当前最强简单基线。
6. **消融**：城市/季度分区、有序命中排序、DTW early abandon。

外部方法只在两种情况下需要：

- 审计发现直接同问题工作（此时必须至少一个外部对照）；
- 外部方法可以被**无歧义地**映射到本查询（例如把 ETQ 的关键词相似度替换为 embedding 相似度），且不会引入不公平的调参。

不建议为了“看起来完整”而重实现 ACORN、Filtered-DiskANN、TISIS*、TrajPrism 等；它们的查询/输出语义不同，强行改造会产生不可比的结果。
