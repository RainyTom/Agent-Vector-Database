## 问题与形式化目标

单路径前缀scope彼此嵌套或互斥；TrieHI解决资格范围，并不直接修补合法向量点之间的导航边。拟研究的是：能否将子前缀必要的连接复用于祖先，以比独立局部图更少的字节改善合法范围内搜索。不是将HNSW随机层号与业务目录深度强行对应。

**定义1（范围诱导图）。** 固定底层对象图 $G_0=(D,E_0)$，对前缀p取合法点 $D_p$ 及两端均合法的边。先按无向连通分量分析缺口；底图有向边仍按原方向搜索，新加修补边一律双向。弱连通不代表原有有向路径连通。

**定义2（可复用修补边）。** 新增双向对象边 $\{u,v\}$，其共同前缀深度为 $h_{uv}$。它对所有满足 $p\preceq\operatorname{LCP}(s_u,s_v)$ 的查询均合法，物理端点对只保存一次。

**定义3（修补目标）。** 为避免把弱连通误当可搜索，构造时在可选修补视图中将参与分析的底边也作为双向边保存；若不增加反向边，则应改用强连通分量并双向连接其代表。MVP选择前者，并计入反向边字节。对该双向视图，记范围分量数为 $\kappa_p(A)$，A为已装修补边。按训练查询频率w及字节预算B，优化代理目标

$$
\max_A\sum_{p\in P} w_p
\bigl[\kappa_p(\varnothing)-\kappa_p(A)\bigr],
\qquad
\operatorname{bytes}(G_0,A,\text{反向视图},\text{元数据},\text{入口})\le B.
$$

这是明确可实现的启发式目标，不宣称最优，不把减少分量直接等同减少ANN延迟。

## 构建方案

1. **从深到浅生成候选。** 初始A为空，每轮在当前已装边上，从深到浅扫描选定前缀族P，复用此前轮次选中的后代修补边，再求scope分量。每个分量选几何代表；首版取离分量均值最近的对象。对代表构造欧氏MST候选，连接不同分量；代表过多时使用近邻候选加确定性链补全，不能把近邻图默认当连通图。
2. **估计跨祖先收益。** 一条候选若连接多个祖先范围中仍不同的分量，获得这些范围加权分量减少之和。每轮对去重候选按收益/新增实际字节选最佳可容纳边，安装后重新生成候选与收益；无正收益可容纳边或预算耗尽则停止。候选原已存在则不重复收费。训练w来自独立训练查询；另跑均匀w，测试查询不能参与选择。
3. **生成查询认证状态。** 对最终图精确重算每个P内非空scope的连通性，记录“连通/未连通”及合法入口。入口可直接从scope选点，不承诺一个代表能覆盖多模态几何。未纳入P的前缀不能借用别人的连通认证。
4. **布局共享邻接。** 对每个合法源u，修补邻居按 $h_{uv}$ 降序存储，查询深度l可停止扫描深度不足的后缀。物理边、偏移、深度标签与反向视图全计入空间；该排序压缩只是支撑组件。

首版全量重算候选收益，适合10K–50K验证；大规模再考虑Trie上的回滚并查集，不能预先声称构建接近线性。底图内存已占满B时须降低底图度数，并重新比较同字节基线。

## 查询算法与保证边界

对最终确认为双向连通的scope，从合法入口在包含反向视图与修补边的图上做限定范围best-first搜索；边仅在目标合法时扩展。认证所用边必须全部可被实际遍历消费。连通性只说明**穷尽搜索可访问全部合法点**，不保证有限ef下找到top-k，也不提供对数级时间界。预算不足、未认证的scope使用相同总图上的通用过滤遍历，允许合法性不符的桥；小scope回退精确扫描。

当源已合法时，目标合法等价于 $|p|\le h_{uv}$。源不合法时不能套该条件，必须直接测试目标路径；查询AB、边AX→ABC是反例。若回退路径进入不合法桥，原有邻接不能被错误按LCP后缀截断。

局部内部节点对象与后代共同构成scope，构图不只覆盖叶子。空范围立即返回；合法点不足k时扫描全部合法集合。任何fallback、反向视图、连接认证和入口成本均计入端到端指标。

## 前序与候选创新

| 最近前序 | 已有机制 | 本方案的具体比较点 |
|---|---|---|
| [Filtered-DiskANN](https://doi.org/10.1145/3543507.3583552) | 标签感知构图、拼接局部图 | 是否只是换成前缀标签？必须对照同字节的标签图和局部图拼接 |
| [Packing](https://doi.org/10.1109/ICDE65448.2025.00272) | 按标签频率分预算并共享结构 | 此处代理是多祖先范围的边际分量缺口，不是仅分配标签度；需逐步骤核是否已有等价修补 |
| [iRangeGraph §3](https://arxiv.org/abs/2409.02571) | 范围专用图共享 | 静态DFS给出强归约；必须测受限层状族是否减少额外构建/边字节 |
| [ELI §3–4](https://www.vldb.org/pvldb/vol19/p617-yang.pdf) | 部分物化、索引覆盖路由 | 不另建完整子树图，而选跨前缀共享的对象级修补边；入口/元数据均收费 |
| UNG作者海报/代码；原论文待补 | 包含组导航 | 连通缺口与组间路由的差异需原文排查，不能以缺全文推出空白 |
| [PathSeer](https://doi.org/10.1145/3802098) | 双区融合图、邻居调度 | 不把双图/局部调度当新意；先固定搜索策略测修补结构 |

候选贡献是**以层状scope的连通缺口为预算收益、复用后代修补边的构建规则**。MST、并查集、LCP标记本身都不新。需进一步排查graph augmentation、hierarchical filtered graph与共享生成树；若已有等价规则，则撤回算法新颖性。

## 最小实验与停止条件

MVP只支持静态单路径，先构造共享修补视图并穷举认证连通，再接hnswlib对象向量与修改后的底层遍历。分别比较底图、只加同数量随机/几何短边、每前缀独立修补、只按频率分预算、跨祖先边际收益完整方案。外部强基线为TrieHI+ACORN/PathSeer、DFS+iRangeGraph、ELI/局部图；原生实现与组件实验分开。

控制原型构建规模：首轮10K点、32个训练前缀、至多64条新增双向修补边。分量代表数不超过128时可计算完整代表MST；更大时近邻候选加确定性链，只承诺生成连通候选。先报告候选重算的实际构建成本，再扩至50K、128个前缀和更大预算，不让全量收益重算成为未计费预处理。

数据改变目录深度/倾斜、几何相关性、跨目录混合程度和scope大小，额外设置宽前缀以检测局部边挤占全局导航的损失。报告同字节/同召回P95、距离数、边扫描、认证比例、分量数、修补边跨前缀复用次数及构建时间；所有额外反向边都计数。

若分量数下降却搜索不快、同字节减少底图边后收益消失、DFS范围图已完全覆盖，或只在人工断连数据有效，则停止主张一般加速。当前只有构图提案，没有算法收益证明。
