## 1. 研究问题层面

待判定问题 P 的五要素：

| 要素 | 取值 |
|---|---|
| 约束结构 | **多父 DAG**（1,929 节点 / 2,040 边 / 103 个 ≥2 父） |
| item 归属 | 每个 item **一个直属属性**（单 owner） |
| 查询语义 | 显式区分 `direct`（owner∈A）与 `recursive`（owner∈A 的全部后代） |
| 执行形态 | **一张共享图 + 单一优先队列** |
| 目标 | **同召回**下延迟低于每属性独立 HNSW；变更维护代价与子树规模解耦 |

### 1.3 多父依赖的实测占比（本轮新增，决定性）

`work/dag-scope/workload-run1/`（1,234 条查询；1,929 属性 / 103 多父），比较精确 DAG 闭包与"每节点只保留一个父"的 canonical 树：[脚本](experiments/dag_multiparent_impact.py)、[数据](data/multiparent-impact.json)。

| 指标 | 数值 |
|---|---|
| item 层面合格集有差异的查询 | **9 / 1,234（0.73%）** |
| 属性层面闭包有差异的查询 | 34（2.8%） |
| DAG 合格 item 总数 | 1,006,763 |
| 树化后漏掉的 item | 2,460（**0.24%**） |
| 多出的伪合格 item | 0 |
| 换一个父后闭包改变的查询 | 436（35.3%） |

最坏单例：查询 `{1155}`，DAG 合格 2,032 item，树化后 1,152，漏 880（43.3%）。

**读数**：多父在平均意义上几乎不改合格集，但在个别查询上是决定性的；canonical 父选择本身极不稳定。因此"支持多父 DAG"**不足以撑起 L2**（只有 9 条受影响查询），而"树化损失通常很小、却在少数查询漏掉近半合格集、且依赖任意父选择"是**可发表的测量结果（L3）**。

### 1.4 问题层面结论

问题整体属**设定变化（L2 候选）**，不是新问题；可主张的 delta 只有三处同时出现才有意义：

1. 作用域是**多父 DAG**（树是特例，不是等价）且 item 单 owner；
2. 作用域是**属性集合 A**（TrieHI 是单锚点）；
3. 在**层级作用域**上做**共享单图 vs 每属性 HNSW** 的**同召回**对照。

不能写的表述：✗"首次研究层级/目录约束的向量检索"；✗"首次区分递归/非递归"；✗"首次考虑过滤下的动态更新"；✗"首次讨论 per-label 物化代价"；✗"首次提出共享 vs 每子集索引的对比"；✗"首次提出多父 DAG 可表达为标签集合"（可表达性等价已验证，索引/成本等价未验证）。

**阻断关系**：TrieHI 阻断 L1 与树版 L2；Curator/SIEVE/RNSG 阻断"对比范式"本身的新颖性。**未被阻断**的只有"多父 DAG + 属性集合 + 层级域上的同召回对照"这一组合，且其可测差异目前只有 0.24% item / 0.73% 查询——这是本节最重要的风险。

## 2. 机制层面

### 2.1 T：覆盖终止（核验完成）

机制句：停止条件改为"每个可枚举属性组都至少命中一次、且第 k 名不劣于未展候选"，不用 GT。

**判定：`同类但设定不同` → L2，不是 L1，也不是已重复。**

| VADER: Filtered Vector Search with Declarative Recall | 2026 | arXiv:2609.38053v2 | `已接收`（PDF 首页 "appeared in VLDB 2027"） | 预测 recall ≥ 目标即停 | 否（任意谓词） | 否 | **是** |

**必查三项**：
1. 非 ef 终止已有四类（结果数+单调性 VBase；声明式召回 DARTH/VADER；预测计算量 E2E；k 名阈值 Uemura）。作用在**过滤**搜索上的两篇都依赖离线 GT。
2. "谓词是可枚举组的并"已被利用，但**用途是建子图/路由/配额，不是终止**。没有一篇把"每个析取项都已命中"当停止信号。
3. 按组预算已有（MAFair-KNN 的 `k_π`、JIR 的比例预算、ELI 的索引选择、LBGraph 的 round-robin），覆盖保证只有**公平性配额**，是结果集约束，非遍历终止。

**风险**：T 的动机（小编组在预算耗尽前一次未被访问）已被记录为现象（LBGraph 的"低频标签形成结构上欠连通子图"、ACORN 低选择性坍塌）。若 delta 只是把"按组预算"从构造搬到终止，属`窄化变体`；只有保留"每组至多一次命中 + 第 k 名不劣"的耦合，才是实质设定改动。

**最近邻**：E2E（同一终止插槽、同一过滤设定、有开源 `github.com/gegeji/E2E`）与 GAAF（任何 match 的析取谓词拆分）。两问指向不同最近邻 → 最近邻身份不稳定，但"不是同设定工作"的判断一致。

### 2.2 M：代表树（核验完成）

机制句：每属性一代表，代表沿 DAG 边连子代表，item 只连自己属性的代表。

**判定：`同类但设定不同` → L2。按 L1 写会被两篇已发表工作直接挡住。**

| 工作 | 状态（证据） | 机制 | 与 M 的差别 |
|---|---|---|---|
| **RNSG/RRNG**，PVLDB 19(10):2839–2852，DOI 10.14778/3828612.3828636 | `已发表`（Crossref，2026-06-01） | 证明"结构遗传"：任意范围诱导子图仍是合法 RRNG；强连通 + 单调可搜 | 保证**比 M 强**；但其定理依赖"边含数值属性邻近约束"，M 的层级边不含任何向量信息，**定理不可移植** |
| **UNIFY/SIG**，PVLDB 18(4):1118–1130，DOI 10.14778/3717755.3717770 | `已发表`（Crossref） | 任意段组合的 PG 仍是 SIG 子图 | 同样是"子图仍可搜"的更强保证，作用于单值数值属性 |
| **TrieHI**，arXiv:2606.16903v1 | `预印本` | 层级作原生前缀树，节点存 inclusive 候选位图 | 作用域**集合精确**（位图并/差），不依赖连通性；且明确"目录语义只作 scope 解析模块" |
| **FLANN**，IEEE TPAMI 36(11):2227–2240，DOI 10.1109/TPAMI.2014.2321376 | `已发表` | 每内部节点一个代表（簇中心），沿层级下降，点只在叶子 | 机制原型同型；层次来自聚类而非标签，无边数压缩主张 |
| Curator，PACMMOD 4(1) Art.21，DOI 10.1145/3786635 | `已发表` | 低选择性下"连通崩坏"，修法是**扩大度数** | 与"稀疏骨架"方向相反 |
| LBGraph，SSDBM'26，DOI 10.1145/3828820.3828830 | `已发表`（摘要 + 片段，全文 403） | 用 iLaD 度量标签诱导子图连通度，并与召回挂钩 | **"连通度 ↔ 召回"的测量已存在**，M 若只报连通性会被要求给同类度量 |
| Navigable Graphs for High-Dimensional NN Search，NeurIPS 2024 | `已发表` | 可导航性定义 + 下界：随机点集上平均度 \(O(n^{\alpha}),\alpha<1/2\) 无可导航图 | **连通 ≠ 可导航**，且可导航需平均度 \(\Omega(\sqrt{n\log n})\) 量级；M 中 item 度为 1，远低于此 |
| Attribute Filtering in ANNS: An In-depth Experimental Study，DOI 10.1145/3769763 | `已发表`（PACMMOD 3(6) Art.298） | 把 index structure / pruning / **entry point selection** 作为独立轴度量 | "改入口"本身已是被人测过的设计维度，不能当新洞见 |

**必须修正的声称**：M 现在的表述"任何下闭集合的诱导子图连通"**在数学上不成立**——多极大元下闭集（如 `A={a,b}` 且 a、b 不可比、无共祖）在该边集下可以是两个互不连通的星形簇。可证形式只有两种：
- 限定到**主下集**（单个极大元的 down-set）；
- 或限定到"存在共同祖先"的集合族。

两种限定都使 M 的适用范围窄于查询语义（查询属性集合 A 可以任意不可比），因此 M 不能单独作为索引方案，必须与跨组边并存——这与当前实现（桥 + MST）一致。

**最近邻**：RNSG（保证类）、TrieHI（设定类）、FLANN（机制原型）。三问一致，判定稳定。

### 2.3 U：维护解耦（未启动）

机制句：桥维护单位降到代表槽 `(c,slot,item)`，变更代价与子树成员数无关。依赖 M 或"只给代表建桥"先落地；EMA（`未确认`）与 TrieHI（`预印本`，DSM）阻断"便宜更新"单独成贡献。

## 3. 汇总判定与可写/不可写

| 层级 | 对象 | 判定 | 阻断者 |
|---|---|---|---|
| 问题 | 层级约束的 ANN 检索 | 已定义 | TrieHI（DSM/DSQ） |

| 问题 | **多父 DAG + 属性集合 + 层级域上的同召回对照** | `未确认`，且可测差异仅 0.24% item / 0.73% 查询 | — |
| 机制 M | 代表树 + 下闭连通 | **L2**（且原声称需限定到主下集） | RNSG、TrieHI、FLANN、Navigable Graphs |
| 机制 T | 覆盖终止（每组命中 + 第 k 名耦合，不用 GT） | **L2** | E2E、VADER、DARTH、MAFair-KNN、LBGraph |
| 机制 U | 槽级维护 | 未核验 | EMA、TrieHI |

可写：
- "在真实多父 DAG 上量化树化损失：0.73% 查询受影响、0.24% item 漏检，但单查询最坏漏 43%，且损失取决于任意父选择"——**L3 测量**，需补齐受影响查询对 Recall 均值的影响。
- "层级作用域下共享单图与每属性子图的同召回边界（G=1 全负、G=2 胜、G≥3 混）"——**L2/L3**，需先补 S0 与同召回前沿。

不可写：任何形式的"首次提出层级过滤""首次区分递归语义""首次共享单图对比""首次便宜更新""新机制（L1）"。
