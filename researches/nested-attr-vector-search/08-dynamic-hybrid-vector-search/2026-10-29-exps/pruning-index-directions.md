# 从维护策略转向表示与过滤剪枝索引

日期：2026-10-29。用户最新要求是有实质研究机制的过滤剪枝索引，可独立存在或接入既有ANN；不是围绕维护阈值、延迟迁移和工程布局继续优化。旧owner/place任务书不再是默认执行路线。本文是问题与机制推导，不是已经成立的新颖索引。

## 1. 先纠正研究标准

方案有效是必要的证据之一，不是CCF-A贡献的充分条件；性能变好可以来自普通优化。论文主张应先给出：已有抽象忽略了什么信息、新表示/结构如何利用它、为什么不是最近前序的直接实例，以及预期可测的新行为。故事性应来自这个因果链，而不是包装或人为添加复杂度。小而深的机制仍可能成立，但本项目不再把单纯维护调参作为核心目标。

本轮保留：NodeANN为主实验基线、有限合理调参、不要求先复现全部外部ANN。改变的是研究对象：从“怎样少重建”转为“怎样形成更强、可查询的过滤剪枝信息”。属性更新是约束和压力源，不再独自承担创新叙事。

## 2. FlyHash相关例子的准确机制

已定位BioVSS/BioVSS++，完整作者为Yiqi Li、Sheng Wang、Zhiyu Chen、Shangfeng Chen、Zhiyong Peng。正式版为ICDE 2025《Approximate Vector Set Search: A Bio-Inspired Approach for High-Dimensional Spaces》，pp.891–903，DOI [10.1109/ICDE65448.2025.00072](https://doi.org/10.1109/ICDE65448.2025.00072)。[arXiv v2](https://arxiv.org/abs/2412.03301v2)改题《Approximate Vector Set Search Inspired by Fly Olfactory Neural System》，是扩展稿，不将占位Journal:x当正式期刊。

原文v2 §§3–5：主要问题是对称Hausdorff下的vector-set top-k，不是ColBERT MaxSim。采用BioHash学习型扩维＋WTA稀疏二进制码；基础BioVSS仍扫全部集合，BioVSS++用激活计数倒排和OR sketch构成两层筛选，再算原Hausdorff。其改变的是候选空间和比较代数，不只是存储格式。

不能误迁移：
- 集合OR sketch不是属性OR谓词；倒排候选并集不是属性AND。
- `H({q},V)=max_{v∈V}||q-v||`，不能用它给scope内最近单向量打分。
- 单对象退化singleton会失去集合聚合的主要意义；普通hash ANN＋bitmap不是自然的新贡献。
- 论文理论依赖碰撞模型、归一化和强分离等条件，不能声称OR-Hamming是Hausdorff安全界或BioVSS++端到端无损。
- 不为套理论归一化当前raw L2数据；这可能改变近邻顺序。

详证：[本地逐节阅读](../../../../papers/multi-vector-search/2412.03301-biovss/paper.report-2026-10-29.md)、[按PDF页定位的全文](../../../../papers/multi-vector-search/2412.03301-biovss/paper.md)。正式版与v2差异未逐字符比对，作者性能未复现。

## 3. 当前最值得推导：过滤条件化几何证书索引

### 3.1 论文问题与故事

常规处理回答“对象是否满足F”或“整块B离q是否足够远”；当整块几何摘要被已过滤对象撑大时，这两个单独判断都可能很弱。要研究的是：**过滤条件能否成为收紧距离界的信息，而不只是一个资格位？**

目标接口：给定q、精确谓词F、几何块/候选组B，在不枚举全部`B∩F`、不按每种谓词组合物化图的前提下，取得其可验证的距离下界。索引的研究实体是共享的“条件极值/区间排除证书”，不是换一个图或多加一个Bloom。

### 3.2 一个正确但尚非新颖的起点

令`S=B∩F`，U为r行正交归一投影（`UU^T=I`）。若区间`[l_j(S),h_j(S)]`覆盖S的第j个投影坐标，令`y=Uq`，则

`LB(q,S)=Σ_j max(l_j(S)-y_j, 0, y_j-h_j(S))² <= min_{x∈S} ||q-x||²`。

S为空时可以直接排除；在当前第k个**合法**结果距离平方为tau且已有k项时，`LB>tau`允许排除整个S的结果资格。相等时需保留tie规则。投影/舍入实现必须保守；非正交独立投影的平方差不能直接相加。

如果条件区间包含于整块区间，则条件界不弱于整块界。这是经典几何事实，本身不是论文贡献。一个普通eligible witness只提供距离上界，不能当作“再没有更近点”的下界证据。

### 3.3 要真正设计的索引结构

可研究的最小结构：稳定几何块＋每块少量投影值的共享排序/分段结构＋动态属性成员索引；查询用F在各排序中查首尾或最近边界的有效对象，并为被跳过区间提供空交集证书，逐级收紧界。条件区间可保守而非完全精确，但不能靠扫描所有合格对象后才计算，否则可能比直接距离更贵。

必须回答的核心问题：
1. 任意eligible bitmap与投影顺序之间如何低成本求条件extrema/successor/predecessor？经典range searching、VA-file、位图/排序集合已有何能力？
2. 能否共享同一份几何排序，避免为每个属性/祖先/复合谓词复制摘要？查询扫描postings或生成bitmap的成本不能隐藏。
3. 复合谓词必须约束同一对象；“有一个红色对象”且“有一个大对象”不证明存在既红且大的对象。独立维度极值也可能来自不同对象，使界仍很松。
4. 属性变更不改变投影值，但改变条件成员。删除留下的superset界可能仍安全但变松；插入/重分类到新集合必须在可见前扩展失效界。所谓可回收/局部更新须有明确代价。
5. 若为了快速取条件界维护大量交叉摘要，空间与维护是否抵消收益？不能把交叉积隐去。

**这些问题尚未解决。因此当前交付的是有明确目标接口和边界的索引研究假设，而不是一个已经设计完成、已确认新颖的算法。**

### 3.4 独立与外挂两种形态

- 独立：几何分块与可覆盖全体eligible对象的调度器，用证书跳组，再原L2验证。只有完整覆盖及有效界时才有整体安全性，不能先遗漏未探测块再称exact。
- 外挂：接到NodeANN的局部块调度，或ANN的候选精排/距离计算层。必须区分结果资格淘汰与图导航淘汰：一个对象不能成为结果，不代表可以不经它到达其他近邻。若改HNSW frontier，需另证与beam门槛/路径覆盖的关系；仅用于结果精排则不能冒称减少相同数量的导航访问。

### 3.5 现有证据与失败边界

旧球probe只研究一条query的整块包围球，不能否定`B∩F`的条件界；也不能据此推断条件界一定紧。若属性与几何独立、每块仍有大量合格对象，条件extrema可能与全块几乎相同。高维稀疏投影也可能界很松。

最先测的不是QPS，而是：固定合法tau下条件界相对整块界多排除了哪些对象/块；取得这些证书需访问多少元数据；是否需要近似扫完整个eligible集合。用GT阈值的结果仅是离线上限；之后必须换成在线合法候选阈值并计启动成本。

## 4. 次候选：谓词可分离的稀疏表示索引

### 4.1 借鉴的是候选生成代数，不照搬FlyHash

保持原向量和原L2排序，把几何表示转为稀疏激活/系数，属性保留精确逻辑层；按激活坐标建倒排。探索能否在候选生成阶段把谓词限制和几何贡献结合，而不是先产生海量候选再callback。

允许两种诚实合同：
- 近似候选索引：证明/校准候选覆盖或报告经验误差，原L2精排不能修复漏召回；
- 有证书索引：为被忽略坐标、未碰撞对象和整段posting提供保守界，覆盖性另证。

### 4.2 天真版本已被前序覆盖

给稀疏近似z(x)保存残差`e(x)=||x-z(x)||`，则经典三角不等式给
`max(0,||q-z(x)||-e(x))² <= ||q-x||²`。
这是正确的安全下界，但不是新意，且dense数据保留很少坐标时残差可能巨大、界接近零。query-to-code也未必免费；零碰撞对象不在postings中时，仍要有完整覆盖或剩余界，不能只验证已经被召回的对象。

[L2AP原文](https://davidanastasiu.net/pdf/papers/2014-AnastasiuK-ICDE-l2ap.pdf) §IV/V已给部分坐标倒排、prefix L2 norm、候选覆盖和残差上界；[Seismic](https://arxiv.org/abs/2404.18812) §5已给几何分组posting与块max摘要。普通稀疏码＋bitmap＋残差范数/WAND不足以立项。

真正待查证的是：带符号、不同范数的原始dense L2能否得到短posting而不丢失必要候选；过滤是否能系统性缩小原距离近似误差/剩余贡献界；动态谓词下覆盖如何维持且不用重编码几何。若没有新表示/新覆盖机制，停止这条独立论文线。

## 7. 下一轮门禁与论文贡献

1. **机制门**：先画索引/查询/更新路径并列最近前序。如果只剩普通posting AND、经典残差界、阈值调参或lazy维护，停止独立主张。
2. **信息门**：少量真实query比较全块界与条件界的oracle潜力，属性—几何相关和打乱绑定分开；保持scope/eligible基数可比，不偷用测试GT在线决策。
3. **索引门**：构造可计算条件界的最小结构，计投影、谓词求值、posting访问、证书获取、额外空间及更新成本。取得界接近全量距离成本即否决这个结构，不用QPS掩盖。
4. **质量门**：宏/非空/分层质量、pair recall和非法输出分开。保留既有0.999主门，不为新哈希任意降门；如研究另一质量档，明确独立曲线而非同质量胜负。
5. **贡献门**：新共享表示/证书生成/覆盖机制＋明确适用假设＋跨过滤强度和更新的实证，才可能支撑索引论文；普通Bloom回收、延迟迁移和固定阈值成本图仍只是工程/维护结果。
