## 认识前序，而非模仿表面

用户举的例子是BioVSS/BioVSS++：BioHash扩维WTA→稀疏码→集合计数/OR sketch→倒排候选→Hausdorff精排；正式版ICDE2025、v2为扩展稿。它不是普通MaxSim，集合OR不等于属性OR。它的价值是表示改变后有了新的候选生成方式，而不是“换格式”。

禁止直接宣布下列组合是新意：
- FlyHash/BioHash＋属性bitmap；
- 稀疏倒排＋残差范数（L2AP已有直接机制）；
- 几何posting分块＋max摘要/WAND（Seismic已有）；
- 共享树＋临时谓词子树（Curator已有）；
- HNSW邻居距离估计（FINGER已有）。

但不因已有部件就否定组合：必须明确组合解决了哪个原来未解决的表示/覆盖/动态维护问题，并证明不是直接替换组件。

## 首选理论/结构问题：过滤条件化几何证书

设物理几何块B、精确过滤F、query q。普通界看B，我们需要便宜取得B∩F的距离下界，以“过滤后几何形状”剪掉整组候选。

正确起点：正交归一投影U，若区间覆盖B∩F投影坐标，query投影到区间盒的平方距离是原L2安全下界。条件区间比全块区间小时界可变紧。这个不等式是经典事实，不是创新。

真正任务：设计可共享的条件极值/区间排除证书索引，避免扫描全部eligible，也避免给每种谓词组合复制几何结构。可以探索稳定投影排序/分段结构、动态属性成员索引以及查询时逐级收紧；但要先查range searching、VA-file、bitmap/wavelet/successor/extrema前序。

必须给出：
- 索引存什么，不存什么；每对象/每块/每属性的空间；
- 任意组合谓词如何约束同一个对象，不用不同对象的边际存在性冒充交集；
- 查询怎样找到界，如何证明被跳过区间没有eligible witness；单个近对象不是下界证书；
- 属性更新/重分类/插删后界何时生效，插入不能沿用过紧旧界；
- 若条件界只靠全量扫描才取得，判这个结构不合格，不包装成索引；
- 是否仅当属性与几何相关时有效，随机绑定和高维界松的反例是什么。

独立索引要覆盖所有eligible块；ANN外挂要区分结果淘汰与导航淘汰。节点不可能成为结果，不等于可不经它到达近邻。若改变HNSW frontier，要另证/另测导航损失，不能拿结果第k阈值直接剪桥接点后声称无损。

## 次候选：保持硬谓词的稀疏表示与候选覆盖

若有比经典方法实质不同的表示，可以探索dense→稀疏候选空间，但必须保留原FP32 squared-L2排序与精确属性资格，不能改成软属性融合分数。

重点不是加bitmap，而是：
1. 原始dense、有正负值和不同范数时，什么变换能得到足够短的posting？
2. 零碰撞对象怎么处理？近似模式明确漏召回；安全模式必须有覆盖或剩余界。
3. 原距离误差能否按F收紧，而不仅是全局残差范数？
4. 属性改变时怎样不重编码所有几何数据，同时保持证书有效？

L2AP已覆盖部分坐标索引＋prefix L2 bound＋阈值候选完整性，Seismic已覆盖整块摘要。没有新覆盖/表示机制，就暂停此路线，不硬做原型。

## 本轮执行顺序与停止条件

阶段1：给出最多两个机制草案和最近前序差异表。至少明确一个非平凡待证性质、一种直接反例、一项区分新机制与普通优化的消融。查重和推导不可用AI摘要替原文。

阶段2：做小型信息价值诊断。先用已有WIKI scope和SIFT控制，比较全块界、条件界的理想潜力与实际索引取得界的代价。原始GT阈值只用于离线上限，不是在线性能。保留属性相关/随机绑定、宽窄scope，样本不足标证据不足。

阶段3：只有结构具有明确差异且阶段2有机会，才实现一个C++小原型。先不做大规模多数据网格、学习模型、并发、持久化和多路主线。若都无机会，交付清晰否证和剩余科学问题；不回退到维护调参凑正结果。

评估至少拆分：谓词处理、条件证书获取、候选/块数量、完整距离次数、路由/导航工作、精排、更新和空间。不能只报QPS，也不能只报剪枝率；bound本身成本可能比被省距离更高。

## 不变的实验合同

- C++在线、固定hnswlib、统一raw_l2_space.h，k=10；Python只离线分析。
- 保留当前raw FP32 squared-L2，不能为了套BioHash/MUVERA理论任意归一化或改目标为Hausdorff/MaxSim。
- 主质量门macro/pair recall≥0.999、非法/重复/状态错误0，另报非空及分层。若研究其他质量点，单独曲线，不冒充同质量胜出。
- 属性hard predicate精确；近似候选充分性与结果合法性分开。
- 小节点扫描允许，大scope扫描不作主算法或暗中兜底；几何证书诊断可用exact，但不能称在线索引已实现。
- 维护、初建、查询、最终必要回收及峰值空间全部计入。单纯延后工作不能当整体收益。
- 量化实现仍受已有IGP-style约束；稀疏代理研究不意味着获准以任意PQ替换正式路径。需要改变硬约束时先明确提出，不能静默改协议。
- 保存负结果和版本；不把历史反复查看过的query重新随机split后称独立测试。
