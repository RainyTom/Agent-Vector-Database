# 实验服务器任务书：拓宽层级多属性过滤索引的机制与实验范围

更新：2026-10-30，用户最新纠偏。此任务书取代“所有下一步只做E0→E1联合几何证书”的安排，也不恢复以维护阈值/延迟搬运为默认论文主线。最新详细协议：[跨机制族研究方案](../../2026-10-30-exps/index-mechanism-portfolio.md)。

## 1. 目标与不可改变的问题

仍做带层级特性的多属性向量混合过滤：外部树的subtree/祖先后代语义，与类别、范围、多值标签等谓词共同决定同一对象的资格；在合法集合按原始向量距离取top-k。不是HNSW层级，不改为多向量聚合、soft属性距离、DAG授权或LLM谓词。

允许使用Trie、bitmap/Roaring、倒排、范围树、图、几何分区、局部索引、哈希/投影和查询优化。组件已有不等于不能用；正确引用与许可合规不同于论文新颖性。创新可以在共享表示、构建/组织、候选生成/导航、查询算法及结构与更新协同，不要求发明新的基础原语，也不要求所有方法产生更紧的安全L2界。

先说清新增状态或操作如何减少工作，再做小实验。探索阶段新颖性可以待查，但必须有最近前序和具体差异；论文主张阶段必须有实质增量和同质量证据。不以“用了Trie/bitmap/图”直接判抄袭，也不以“换场景＋拼组件”直接认创新。

## 3. 先覆盖六个机制族

- **F1 联合资格表示与索引接口：** Trie＋倒排/bitmap/范围索引；如何按搜索消费粒度组织层级和多属性资格，减少全scope展开与重复判断。
- **F2 共享查询视图与子索引：** 一份向量/几何结构，多种层级和交叉属性搜索视图；研究共享粒度、局部导航和更新扇出。
- **F3 过滤感知图导航：** 结果资格与导航中介分离；研究候选恢复、入口、邻接组织与必要的局部补充机制，不止测合法诱导图连通性。
- **F4 属性—几何双空间分区与组织：** 语义层级不变，几何微分区/局部图/布局如何配合属性分布；属性须在布局对比前固定。
- **F5 代理表示与近似候选：** 稀疏码、哈希、投影等改变候选发现方式；保持原距离精排及精确资格，单列候选漏报与更新成本。
- **F6 条件几何证书：** 保留已有box/gap和E0/E1作为一族，不让其成败决定F1–F5是否可研究。

每族写一张机制卡：存储/共享粒度、查询、更新、最近前序、具体差异、预测、失败反例、最小控制、状态。没有设计完成的部分直说，不造算法名充当方案。

特别注意：ACORN §5.2已明确指出遮挡点被过滤后原剪枝替代路径失效；这不是新发现。Curator已有位图/倒排输入与虚拟谓词树；ELI/SIEVE已有索引集合选择。可以在这些基础上发展新机制，不可直接认领其核心，也不能据此关闭整个家族。

## 4. 最小筛选而非六套完整实现

### 阶段A：机制卡与一次瓶颈检查

基于现有NodeANN分项与必要的小型插桩，判断主要成本在资格处理、导航、局部搜索、距离还是数据搬运。不要重复跑已知失败以确认用户报告，不因没有新安全界拒绝其他候选。

### 阶段B：至少三个非证书族的有限诊断

首选F1/F2/F3，可按已知瓶颈以F4替换之一；不是同时写完整系统。F1可固定访问trace测准备/消费；F2用少量局部视图测机会与共享代价；F3在同图/边预算下测导航候选恢复。离线模型或oracle只标机会，不冒称在线胜出。

固定现有WIKI/SIFT小切片，覆盖六种现象：仅scope、宽scope＋强AND、窄scope＋弱过滤、同合法数不同分散程度、父子/兄弟scope与不同属性组合、短更新窗口前后。不要展开全参数笛卡尔网格；不要随K改变属性定义再作索引因果比较。多值标签若当前数据缺失，明确缺口或另列有记录的合成控制，不冒称真实业务属性。

旧query可用于探索，不能重新split后当独立测试。确认阶段核验未参与方案选择的query/谓词；没有独立输入时明确说明。预测、失败判据与分项见最新协议§5。

### 阶段C：最多保留两个机制不同的小原型

探索门是明确、可证伪的差异，不是提前拿到完整新颖性证明。允许小型C++原型检验不确定机制，所有重合风险写明。单因素证据成立后才组合；不把同族box/gap变体当两个独立方向，不堆六个部件掩盖因果。

## 5. 同质量、资源和维护合同

- NodeANN为主要性能基线，只做必要正确性修复与有限合理校准；不要求先复现所有ACORN/Curator等系统。每族有一个最近机制的简洁资源匹配对照，避免只打弱post-filter。
- 在线C++、固定hnswlib、统一raw FP32 squared-L2、k=10；Python限离线分析。FAISS仅既定k-means用途；量化仍受原IGP约束，不因F5授权任意PQ。
- macro/pair recall≥0.999，非法/重复/状态错误0；零/不足k与分层另报。资格精确不等于候选生成必须精确无漏；只有声称安全/精确剪枝时才要求对应保证。
- 计初建/训练/投影、全部查询、属性/目录/向量更新及必要回收；空间计Trie、位图、倒排、所有图/视图、原向量、代理/路由状态、日志及峰值。禁止免费缓存命中、免费oracle或无期限拖欠维护。
- 小scope扫描是公共合理策略，大scope全扫不能暗中成为主方案。最近前序采用扫描fallback时注明其与本任务约束的差别。
- 不承诺CCF-A，不把模型预测或局部计数改善写成端到端性能；保留负结果与未完成状态。

## 6. 交付

在实际日期目录保存六张机制卡、最近前序差异、已执行的至少三个非证书族小诊断及其限制，按证据选择最多两个不同机制的小原型。数据不可达时完成可达分析，列准确缺口，不以随机替代冒充真实复现。更新研究日志及小体积源码/数据；不提交大向量/索引。
