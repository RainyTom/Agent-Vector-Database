# 方案 v2：按局部 ρ 分配的双类边预算（ACE）

> 迭代自 v1（纯下闭锥图）。v1 的问题：下闭边保留 100% 度数，但当 `ρ` 低时只能连到远处后代，变成"连通但无导航"。v2 用闭式规则在几何边与下行边之间按节点分配预算。

## 1. 结构

- **节点**：每个 item 一个，全局唯一 ID。
- **边**：每节点总预算 `M`，分为两类，均按距离升序保留。
  - `G` 边（几何，无限制）：连向全库最近邻，不看 owner。
  - `D` 边（下行，poset 受限）：连向 `Desc⁺(own(u)) \ {own(u)}` 中最近的对象，按 poset 距离 `ℓ = 1, 2, …` 分桶。
- **辅助**：概念闭包位图 `Desc⁺/Anc⁺`；`items(c)` 倒排；属性子树计数 `match(c, P)`；每节点 `ρ_u`。

## 2. 构建

```text
1. 概念闭包、owner 倒排、属性子树计数（自底向上）
2. 对每个 item u：
     取全库 M 近邻 N(u)，得 ρ_u = |{v∈N(u): own(v) ∈ Desc⁺(own(u))}| / M
3. 计算该节点需要保留的度数
     R_u = max(k, ⌈ln S_u⌉)              # S_u = 该 owner 所在锥的典型 item 数
     闭式分配：g_u = clamp((M - R_u)/(1 - ρ_u), 0, M)，d_u = M - g_u
     校验：ρ_u·g_u + d_u ≥ R_u
4. G 边：从 N(u) 取前 g_u 个
5. D 边：把 d_u 条按 poset 距离分桶（默认几何递减：ℓ=1 占一半，其余按 2 的幂衰减），
   每桶在 Desc⁺(own(u)) 内取最近对象
6. 断言：每节点出度 = M；D 边满足 own(v) ⪯ own(u)
```

`ρ_u = 1` 时 `g_u = M`，退化为 HNSW；`ρ_u = 0` 时 `g_u = M − R_u`，退化为纯下闭。`ρ_u` 由构建期精确统计得到，不需训练。

## 3. 查询

```text
D ← ⋂_组 ⋃ Desc⁺；属性子树 0 命中 → 整概念剔除；D = ∅ 返回空
E ← D ∪ Anc(min(D))；同样做属性剔除
种子 ← E 中无"带 item 祖先"的概念的 item
单队列 best-first：
  弹出最近者；若 |R| = k 且 d > 第 k 名 → 停；去重；距离每 item 只算一次
  合格且过属性 → 进结果堆
  对每个邻居：own ∉ E → 跳过且不算距离；否则算距离入队
卡住回退：队列空且 |R| < min(k, |F_Q|) 时，改用 E := Ant(D) 重跑一次（取消严格剪枝）
```

`Ant(D)` 是 L1 级可访问集（被剪概念整棵子树与 D 不相交），其剪枝只需单向边，不需要覆盖假设，作为回退层。

## 4. 保证与代价

| 项 | 内容 |
|---|---|
| 保留度 | 每节点在合格集内的保留度 `≥ R_u`（构造保证） |
| 距离上界 | 距离计算 ≤ `|items(E)|`（每个 item 最多一次） |
| 精确项 | `D`、`E`、属性子树剪枝、去重、并列 `(distance, id)` |
| 非精确项 | 第 k 界停止、边选择是否几何最优、`ρ_u` 是否代表查询分布 |
| 空间 | 每节点 M 条边，与 HNSW 同阶；额外 `ρ_u` 一个 float |
| 构建 | 每节点一次全库近邻（可用现成 ANN 近似）→ 与 HNSW 同阶 |
| 维护 | owner 变更：重算 `ρ_u`、重选 G/D 边；属性变更：更新祖先计数 |

**最坏反例**：`ρ_u` 由均值估计但在长尾分布下偏低（某节点实际邻居全在锥外），`d_u` 不足；`S_u` 估计过小导致 `R_u` 不足；D 边桶内后代全为长边时导航退化。回退层只保证不漏，不保证时间。

## 5. 12-item 走查（结构，无真实向量）

`R→A,B；A→C,F；B→E,F`，每概念 2 个 item。设 `M=4`、`k=2`、`R_u=2`。

- F 的 item：`Desc⁺(F)={F}`，锥内只有同概念的 1 个对象 → `ρ≈1/4`；`g=(4-2)/(1-0.25)≈2.7→3`，`d=1`；D 边在此为空（F 无后代），实际退化为 G 边。
- A 的 item：`Desc⁺(A)={A,C,F}` 共 6 个对象，`ρ` 较高；若 `ρ=0.5`，`g=(4-2)/0.5=4`，`d=0`，即全几何边。
- 查询 `U={A}`：`D={A,C,F}`、`E={R,A,C,F}`，种子 `r1,r2`；`b1` 因 `B∉E` 被跳过且不算距离。
- 查询 `A AND B`：`D={F}`，只 `f1,f2` 合格，`k=2` 刚好；若 `k>2` 不补。

## 6. 与 v1 的差别

| 项 | v1 | v2 |
|---|---|---|
| 边类型 | 只下行 | 几何 + 下行，按节点闭式分配 |
| 度数保留 | 恒为 1 | 目标 `R_u`，用 `ρ_u` 换算 |
| 纯下闭的失败模式 | 无对策 | `ρ` 低时自动退回几何边 |
| 参数 | 全局 `(p_i)` | 每节点 `(g_u, d_u)`，由 `ρ_u`、`S_u`、`k` 决定 |
| 大 scope | `Σ_c log n_c` | 单图，无此项 |

## 7. 待验证

- 中间带（`ρ≈0.2` 可控合成）三臂：无限制 / 纯下闭 / ACE，同 Recall 比距离数与端到端时间。
- 失败判据：ACE 在中间带不优于无限制图 → 分配规则作废。
- `ρ_u` 用采样估计（每节点 64 个近邻）与全量统计的差异是否影响分配。
