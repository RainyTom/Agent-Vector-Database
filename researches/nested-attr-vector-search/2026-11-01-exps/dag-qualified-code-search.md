# DAG资格驱动的单队列编码搜索

状态：**编码树替代图的路线已被用户驳回**。本文是未实施的历史理论候选，未获性能或新颖性认证，不记为实验失败；不得据此启动实现或实验。

本文及其后续[统一整体方案](dag-unified-search-plan.md)均保留为历史记录。无论先生成eligible bitmap还是按需求交，均不能消除量化候选排序质量与大规模候选成本的问题；两者都不再是主线。

## 决策

不再以每owner图独立top-k再合并为主搜索架构。保留DAG-JBF作为精确资格组件，连接一个全局量化编码Trie；查询使用同一优先队列和候选预算。ANN图不参与该候选的主搜索路径。

改变的是逻辑近邻索引与算法，不是向量存放位置、SIMD或把多张图包装成一个函数。底层原始向量保持原位置，通过ID读取。

## 1. 全局向量编码索引

向量分为M个互不重叠子空间，所有原始维度都参与编码，每子空间学习K个码字。对象x编码为(c1,...,cM)，重构向量由各子空间码字拼接。量化有误差，不等于保留原始距离，也不是WIKI先前失败的64维安全投影。

将存在的编码组织成压缩Trie：每层一个子码，边为该层码字ID；不存在的编码路径不建节点。相同完整编码的对象进入同一个叶端posting，内部节点不建立局部图。每个对象在全局编码索引中只有一个叶归属。

叶对象分配逻辑ordinal，前缀对应连续ordinal区间[l,r)。ordinal只是索引键，不移动原向量。物理排序不是创新主张。

## 2. 层级和普通属性索引

DAG可达性保留完整多父关系。owner posting与普通字段posting采用相同逻辑ordinal；联合属性结构可以采用既有DAG-JBF，输出精确合法bitmap E_q。构建或物化E_q、区间基数查询和bitmap操作均计时，不把资格交集当作免费。

主机制是每个几何编码前缀都必须通过同对象资格检查：

active(v,q) iff |E_q ∩ [l_v,r_v)| > 0。

这里E_q已经是scope与Extra在对象层面的精确联合，不从“某owner分别有人满足两个字段”推断联合存在性。内部几何节点可附加DAG双边界做早期scope全拒绝/全接受，但混合节点仍以精确联合资格为准；节点scope全合法不能省略Extra。

每个对象只占一个ordinal，故DAG多父路径不会造成资格或候选重复计数。多个recursive scope先在概念域求共同后代/并集，不能按路径重复搜索。

## 3. 单一best-first候选枚举

对查询q，建立距离表a_j(t)=||q_j-centroid_j(t)||²。对于深度d的前缀v=(c1,...,cd)，定义

B(v)=sum(j<=d) a_j(c_j) + sum(j>d) min_t a_j(t)。

该界仅对完整量化重构距离ADC有效；未赋值子空间的全码本最小值可以包含索引中未出现或不合格码字，因此界可能松，但不会超过v中任意叶编码的ADC。**绝不拿它当作FP32原向量距离下界。**

算法：

1. 求精确资格E_q，空集合直接结束。
2. 将root加入唯一优先队列，键为B。
3. 弹出最小B的节点，对孩子先做active检查；无合法对象的孩子不入队，其他孩子以B入队。
4. 叶节点的B等于完整ADC。按此顺序输出其中合法对象，所有叶共享一个候选计数R和同一个队列。
5. 收集R个候选后，统一读取原向量计算FP32距离，返回其中top-k。所有完整编码并列需规定稳定tie-break或处理完整并列桶；候选预算成本如实记录。

这是量化重构空间上的best-first。若输出条件和并列规则完整，可以按ADC顺序枚举合法候选；只取前R再原空间重排不能保证原空间精确top-k。R决定质量/时间折中，应以同Recall比较；不能用R小造成的漏召回冒充速度胜出。

## 4. 过滤真正改变搜索的地方

普通后过滤会展开当前几何最近的编码路径，再发现对象不合法。本方案在内部前缀上先证明该分支没有合法对象，整个分支不进入搜索队列；因此过滤改变的是几何展开序列和候选预算消耗，而不只是决定启动哪些局部图。

若最近的两个编码前缀没有合法对象，它们全部跳过；从下一个有合法对象的前缀继续。无需给每个owner分配至少k个返回、不做多图入口下降、不合并g份局部top-k。所有合法owner共享一次几何竞争。

但其优势不是绝对的：过滤若在每个编码前缀都高度混合，直到深层才可排除，则active检查可能纯增成本；PQ排序质量差时R大，可能输给全局HNSW。高维重构编码包含全部维度不等于没有量化信息损失。

## 5. 新颖性边界

本轮核对原始网页确认[VA-Trie, 2005](https://crad.ict.ac.cn/en/article/id/1470)已经采用量化并用Trie组织近似向量。因此“PQ/量化+Trie”不是新贡献。本轮只读了该工作的原始摘要，未精读全文，不将其局限或实验扩展为已核事实。

DAG闭包、bitmap、条件范围求交、best-first和原向量rerank也不是可直接宣称的新点。潜在组合点是：DAG多父与多属性同对象资格在编码前缀上提供精确分支存活证据，驱动单队列几何搜索，替代owner分图搜索。是否超出已有filtered IVF/PQ、VA索引、wavelet/range emptiness与约束NN，需要具体查重；本轮窄检索不能证明新颖性。

因此本方案理论上可执行且消除了多图独立合并机制，但尚不能宣称“已经具有足够论文新颖性”。它是明确候选，不是靠新名称认证贡献。

## 6. 当前可证明与不能证明的结果

可证明：精确资格不因DAG多父重复；active空前缀安全省略；B对ADC有效；无需每owner独立top-k；候选只统一rerank一次。

不能证明：固定R下原向量Recall达标；WIKI安全距离剪枝问题已解决；位图和Trie成本小于HNSW；端到端必胜；前序不存在。

维护边界：对象owner/普通属性变更只更新逻辑posting与计数，向量编码不变；向量变更需要重编码与叶归属更新；DAG关系变化更新闭包及失效摘要。Trie区间ordinal的动态维护并非免费，静态ordinal+delta或重建会有额外代价，不能在未定义稳定序维护前承诺动态高效。本轮用户优先查询效率，因此不将动态索引工程伪装成已完成设计或动态优势。
