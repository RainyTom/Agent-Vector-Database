# 方案 v4：ESG——入口选择型全局图

> 迭代自 v3。v3 靠"簇纯净"换取保留度，但纯净与簇少不可兼得。v4 换机制：**不改边，改入口**。全局图保留几何最优的边（无限制），资格只用来选入口。

## 1. 为什么换

v3 的保留度依赖 `Σ(C) ⊆ D`。合并越多，纯净越低，退化为簇内过滤搜索；不合并就是 NodeANN。理论上的两难（`Mρ` 对 `M`）说明：`ρ` 低时任何改边方案都只能"连通但无导航"。而如果搜索**一开始就在合格集内部**，就不需要靠边来进入合格集——问题从"边保留度"变成"入口质量"。

## 2. 结构（全静态）

| 组件 | 内容 | 规模 |
|---|---|---|
| 全局图 | 一张 HNSW，边无 owner 限制（标准构建） | `n·M` |
| 概念闭包 | `Desc⁺/Anc⁺` 位图 | `O(V²/8)` |
| 概念倒排 | `items(c)`、属性子树计数 `match(c,P)` | `O(n)`、`O(V·p)` |
| 入口表 | 每概念 `k_e` 个入口 item + 组质心 + PQ 码（可选） | `O(V·k_e)` |
| 资格位图 | 查询期 `D`、`E`；节点→owner 数组 | `O(V/64 + n)` |

## 3. 构建

```text
1. 闭包位图、概念倒排、属性子树计数
2. 入口选择（每概念独立）：
     c 的 item 用 farthest-point sampling 取 k_e 个入口（或 k-means 中心最近点）
     记录质心 μ_c；若用 PQ，记录入口与质心的量化码
3. 全局 HNSW：标准 M、efConstruction，边不做任何 owner 限制
4. （可选）入口互相连通：把 k_e·V 个入口自身再建一张粗图 G_in
```

## 4. 查询

```text
1. D ← ⋂_组 ⋃ Desc⁺；属性子树 0 命中剔除；D=∅ 返回空
2. E ← D ∪ Anc(min D)；属性同理
3. 候选入口组 ← {c : Σ(c) ∩ E ≠ ∅}                 # 位图判定，精确
4. 粗排：按 μ_c（或 PQ 码估算）到 q 的距离排序，取前 t 组
5. 种子 = 这 t 组的入口 item
6. 单队列 best-first（同一张全局图）：
     弹出最近者；|R|=k 且 d>第 k 名 → 停；visited 去重；距离每 item ≤1 次
     合格且过属性 → 结果堆；邻居 own ∉ E → 跳过且不算距离
7. 回退：结果不足 min(k,|F_Q|) 时，把 t 扩到全部候选入口组重跑一次
```

无每概念 top-k、无归并、无簇间桥。`t` 是全局固定参数（默认 4–8）。

## 5. 组件职责

| 组件 | 职责 | 不做 |
|---|---|---|
| 闭包位图 | 解析 `D`、`E` | 不算距离 |
| Trie | 多概念条件归约为祖先/后代枚举 | 多父需多入口补齐 |
| 位图 | `Σ(c) ∩ E ≠ ∅` 的入口组筛选 | 不排序 |
| Bloom | `V` 大时代替入口组的成员位图 | 只做否定 |
| 聚类（入口选取） | 每概念取代表性入口 | 不切分搜索任务 |
| 量化 | 入口粗排（`t` 个候选） | 不参与最终排序与剪枝 |
| HNSW | 唯一近邻导航核心 | 边不受 owner 约束 |

## 6. 保证与代价

| 项 | 内容 |
|---|---|
| 精确 | `D`、`E`、入口组筛选、属性子树剪枝、去重、并列 |
| 近似 | 第 k 界；入口粗排（可能漏掉正确入口组）；回退可兜底 |
| 距离上界 | ≤ `|items(E)|`（剪枝到 E 后每 item 最多一次） |
| 额外空间 | `V·k_e` 个入口 ID + 质心 + 可选 PQ 码 |
| 额外查询成本 | `t` 次粗距离（量化域，非原始距离） |
| 构建 | 与一次全局 HNSW 同阶 + 入口选取 |
| 维护 | item 变更只影响其概念的入口表；概念边变更重算闭包 |

**最坏反例**：
1. `t` 太小 → 正确入口组未入选，退化为远离 E 的搜索；
2. 概念半径大（`ρ` 低）→ 入口与真实近邻无关，粗排失效；
3. 大 scope（`E=V`）→ 入口组 = 全部，退化为全局图搜索；
4. 单概念大数据 → 一个概念的入口只有 `k_e` 个，等价于普通 HNSW 入口。

## 7. 12-item

概念 `R→A,B；A→C,F；B→E,F`，每概念 2 item，设 `k_e=1`、`t=2`。

| 步骤 | 结果 |
|---|---|
| 入口表 | R:r1 A:a1 B:b1 C:c1 E:e1 F:f1（每个概念 1 个入口，示意） |
| `U={A}` | `D={A,C,F}`，`E={R,A,C,F}`；候选入口组 = 有 Σ∩E≠∅ 的概念 → {R,A,C,F} |
| 粗排 | 按质心距离取前 2 → 例如 {A,C} |
| 搜索 | 从 a1、c1 入队；`b1`、`e1` 所在 owner ∉ E → 跳过且不算距离 |
| `A AND B` | `D={F}`，候选入口组 = {R,A,B,F}，取前 2；结果只收 F 的 item |

## 8. 与 v3 的差别

| 项 | v3 CGP | v4 ESG |
|---|---|---|
| 机制 | 改边 + 簇纯净 | 不改边，选入口 |
| 图数量 | 每簇一张 | 一张全局图 |
| 失败依赖 | 簇纯度 `τ` | 入口代表性（`k_e`、`t`） |
| 量化用途 | 簇粗排 | 入口粗排 |
| 退化极限 | `τ=1` → NodeANN | `t=1` → 普通 HNSW 入口 |

## 9. 待验证

- 合成数据控制 `ρ`：固定 HNSW，只比较"全局入口"与"概念入口 + 粗排"，测同 Recall 的距离数与端到端时间；
- 关键对照：入口数 `k_e ∈ {1,4,16}` × `t ∈ {1,4,8}`，观察是否在 `ρ` 低时仍有收益；
- 失败判据：若入口方案在 `ρ` 低时与随机入口无差别，则入口机制无效，v4 作废。
