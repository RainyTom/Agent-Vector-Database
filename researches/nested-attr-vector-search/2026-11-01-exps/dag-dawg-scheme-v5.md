# 方案 v5：DAG-骨架（DAWG）+ 可测区间压缩 + 图导航

> 响应"前缀树对 DAG 是逻辑必然"的判断。结论：**trie 的服务是必然的，trie 的形状不是**。有精确判据，也有可测的压缩开关。

## 1. 先把判断拆成两层

| 命题 | 是否成立 | 依据 |
|---|---|---|
| 层级属性需要"嵌套集合 + 前缀式范围解析" | 成立 | 这是 scope 可被 O(深度) 解析的必要条件 |
| 该机制必须是一棵前缀树 | **不成立** | 反例：`A→D, B→D, C→D`（D 有三个父）。`Desc⁺(A)={A,D}`、`Desc⁺(B)={B,D}`、`Desc⁺(C)={C,D}` 都要求 D 与彼此相邻，线性序里 D 最多两个邻位 |

### 1.1 穷举结果（枚举全部 DAG，暴力检查是否存在使所有 `Desc⁺` 成为区间的线性序）

| 概念数 | DAG 总数 | 无区间序 | 占比 | 最小反例 |
|---:|---:|---:|---:|---|
| 3 | 8 | 0 | 0% | — |
| 4 | 64 | 1 | 1.6% | `A→D, B→D, C→D` |
| 5 | 1,024 | 69 | 6.7% | 同上 |
| 6 | 32,768 | 5,347 | 16.3% | 同上 |

**结论：trie 是"森林 + 大多数小 DAG"的特例，不是 DAG 的必然结构。** 反例的触发条件是"某概念有 ≥3 个父且其祖先的 scope 都需为区间"。

### 1.2 真实数据集正好落在反例一侧

CCS/SciHTC DAG 的父数分布：最大 **18** 个父，**310 个概念有 ≥3 个父**（父数直方图 `1:44, 2:59, 3:53, 4:63, …, 18:1`）。所以真实 DAG 不能用单棵前缀树精确表示——用一棵树就必然复制共享后代或丢成员。

## 2. 方案

三层，全部静态：

| 层 | 内容 | 说明 |
|---|---|---|
| 骨架 | **概念 DAG 本身 = 其路径集合的最小 DAWG** | 多父节点只有一份，item 集合挂在节点上，不复制 |
| 资格 | 闭包位图 `Desc⁺/Anc⁺`（通用精确）；若 1.1 的检查通过，额外存**区间序**，scope 退化为区间并集 | 区间序是可选压缩，不是必需结构 |
| 图 | 全局 HNSW + 概念入口（v4）或下闭锥边（v1） | 唯一近邻核心 |

### 2.1 构建

```text
1. 概念 DAG、闭包位图、owner 倒排、属性子树计数
2. 区间化检查（consecutive-ones）：尝试求一个线性序 σ，使每个 Desc⁺(c) 在 σ 下连续
     成功 → 记 σ 与每个概念的 [l_c, r_c]，posting 按 σ 排列
     失败 → 只用位图，删除 σ 相关结构
3. 入口表（每概念 k_e 个代表点 + 质心/可选 PQ 码）
4. 全局 HNSW（M、efConstruction 同基线），边不做 owner 限制
```

区间化成功的收益：scope 解析从"位图 word 扫描"变为"区间并集"，且 posting 顺序自带局部性；失败则完全退回位图，**不影响正确性**。

### 2.2 查询

```text
1. D ← ⋂_组 ⋃ Desc⁺        （位图；有 σ 时可用区间并集）
2. E ← D ∪ Anc(min D)
3. 候选入口组 ← {c : Σ(c) ∩ E ≠ ∅}；按质心/PQ 粗排取前 t
4. 单队列 best-first：第 k 名界、visited 去重、距离每 item ≤1 次
   邻居 own ∉ E → 跳过且不算距离
5. 结果不足 → t 扩到全部候选组重跑
```

### 2.3 组件职责

| 组件 | 职责 |
|---|---|
| DAWG/DAG 骨架 | 共享多父后代，唯一物理节点 |
| Trie（区间序） | 当且仅当可区间化时，把 scope 变连续区间；否则不建 |
| 位图 | 通用精确资格 |
| Bloom | `V` 很大时的成员否定测试 |
| 聚类 | 每概念入口选取 |
| 量化 | 入口粗排 |
| HNSW | 唯一导航核心 |

## 3. 保证与代价

| 项 | 内容 |
|---|---|
| 精确 | 骨架共享、`D`/`E`、入口组筛选、属性子树剪枝、去重、并列 |
| 近似 | 第 k 名界；入口粗排 |
| 区间压缩 | 仅在检查通过时启用；失败不影响正确性 |
| 额外空间 | 入口表 `V·k_e`；位图 `O(V²/8)`；区间序仅 2 个整数/概念 |
| 构建 | 一次区间化检查（可启发式，失败即放弃）+ 全局 HNSW |

**最坏反例**：真实数据落在反例侧（本例即是），trie 层不可用，只剩位图；`V` 极大时 `V²/8` 位图不可接受，需换稀疏闭包或按需遍历。

## 4. 与 v4 的差别

| 项 | v4 | v5 |
|---|---|---|
| 多父处理 | 隐含在位图里 | 显式：骨架 = DAWG，唯一节点 |
| Trie | 未涉及 | 作为**可测的压缩层**，有通过/失败判据 |
| 真实数据 | — | 已测：310 个 ≥3 父概念 → 区间层不启用 |

## 5. 待验证

- 在真实 DAG 上跑一次区间化启发式（贪心 + 局部修正），确认失败，并统计"多少概念的 scope 在最优序下仍非区间"；
- 若能区间化的子集很大（例如 95% 的概念），则区间层仍可用于多数查询，需要计命中率；
- 失败判据：区间层启用率 < 10% 时，删除该层，避免无效复杂度。
