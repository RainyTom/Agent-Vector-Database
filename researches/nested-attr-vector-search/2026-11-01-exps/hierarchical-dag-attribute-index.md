# 层级属性约束下的向量近邻检索

## 摘要

学科分类、商品品类等场景中的属性概念构成有向无环图：一个概念可以有多个父概念，对象的细粒度标签使其满足全部祖先属性，而粗粒度标签不能确定其属于某个特定后代。多父结构使不同分支的对象集合相互交叠，属性集合族不再是树状划分。本文研究这类 DAG 层级属性约束下的向量近邻检索：在严格满足继承匹配、对象去重与召回要求的前提下降低查询时间，并把标签变化所触及的索引状态限制在祖先方向上。

主张的核心是一个索引选择问题：**向上闭包小、向下闭包大**，因此按祖先传播维护的信息（精确基数、可选物化集合）更新便宜，而按后代展开的查询昂贵；索引应按这一不对称性决定在哪些概念上保留派生状态。

## 1. 数据模型

属性层级为有向无环图 G=(V,E)，边由一般概念指向细化概念，ρ为根。u≼v 表示 u=v 或存在 u 到 v 的有向路径。祖先与后代集合按可达闭包定义：

\[
\operatorname{Anc}^{+}(v)=\{u\mid u\preccurlyeq v\},\qquad
\operatorname{Desc}^{+}(v)=\{w\mid v\preccurlyeq w\}.
\]

多父概念使 |Anc⁺(v)| 可超过图的深度，两个集合必须去重后使用；同一概念可经多条路径到达同一祖先。

对象 i 表示为

\[
o_i=(id_i,\;x_i,\;L_i,\;a_i),
\]

x_i∈R^d 为向量，L_i⊆V 为**直接**标注的标签集（可为多个，可位于内部概念），a_i 为其他属性。逻辑对象唯一，多个标签不产生多个对象。继承标签集为

\[
A_i=\bigcup_{\ell\in L_i}\operatorname{Anc}^{+}(\ell).
\]

## 2. 查询语义

概念条件 u 的继承匹配为

\[
h_u(i)=[\exists\ell\in L_i:\;u\preccurlyeq\ell]=[u\in A_i],
\]

对应成员集合 S(u)={i : live_i ∧ h_u(i)}。直接标注条件为 d_u(i)=[u∈L_i]。两者不同：内部概念的直接标注者满足其全部祖先，但不能推出它属于任何特定后代。

多个查询概念 U 的条件为并集，可规范化为 antichain（删除被祖先条件覆盖的节点）：

\[
S(U)=\{i\mid live_i\land L_i\cap\!\!\bigcup_{u\in U}\operatorname{Desc}^{+}(u)\neq\varnothing\}.
\]

过滤与去重精确，近似性只允许出现在最近邻选择。查询 Q=(q,U,φ,k) 的合格集合 F_Q={i∈S(U) : φ(a_i)}，精确答案为 F_Q 中按原始 FP32 squared-L2 与对象 ID 次序取前 k_Q=min(k,|F_Q|) 个对象；非空查询按

\[
\operatorname{Recall}(Q)=\frac{|R(Q)\cap R^{*}(Q)|}{k_Q}
\]

计算，未填满不缩小分母，空结果单列，macro 与 pair 两种口径分别报告。查询时间包含层级解析、候选生成、向量搜索、去重与合并；构建与维护单独计量。

### 2.1 集合族的结构性质

- **祖先包含**：u≼v ⇒ S(v)⊆S(u)。
- **非层状**：u、v 互非祖先时 S(u)∩S(v) 仍可非空。多父概念 c 的对象若直接标注 c，则同时属于 c 的所有父概念，而这些父概念之间可以互非祖先。
- **内部标注不对称**：直接标注粗概念不产生任何后代成员，因此 S(u) 通常远大于 D(u)。
- **去重来源**：对象可经多条路径进入同一祖先，展开时须按概念去重、按对象去重。

## 3. 索引方案

### 3.1 存储组件

| 组件 | 内容 | 规模 |
|---|---|---|
| 直接成员倒排表 | 每个概念 c 的位图 P(c)={i : c∈L_i}，存为按 word 排序的稀疏条目 | Σ_c \|P(c)\|/8 字节 |
| 概念闭包 | Desc⁺(v) 的概念位图，\|\V\|≤D₀ 时物化，否则查询时按 DFS 加访问戳计算 | D²/8 字节 或 O(1) |
| 精确基数 | 每个概念的 \|S(c)\| 计数 | 8 字节 × D |
| 派生 scope 位图 | 部分概念的 M(u)=∪_{c∈Desc⁺(u)}P(c) | \|M(u)\|/8 字节 |
| 向量结构 | 对象唯一物理位置 + 分区 HNSW + 资格过滤 | 与对象数成比例 |

闭包位图只在概念数较小时物化。CCS 为 1,928 个概念，闭包位图合计约 0.5 MB；概念数达到十万级时改用访问戳在线遍历。

### 3.2 向上维护、向下查询的不对称

设对象在概念 c 处增删一个直接标签。继承集合的变化落在 Anc⁺(c) 上：

\[
\forall u\in\operatorname{Anc}^{+}(c):\quad |S(u)|\mathrel{+}=\pm 1,
\]

若 u 有派生位图则同时修改 P(c) 落在 u 的第 \lfloor i/64 \rfloor 个 word 的 1 个 bit。**更新代价为 O(|Anc⁺(c)|) 次计数与位写**，即沿祖先方向传播，与后代数量无关。

查询方向相反：概念 u 的 scope 需要展开 Desc⁺(u)。定义展开代价

\[
E(u)=\sum_{c\in\operatorname{Desc}^{+}(u)} \operatorname{words}\bigl(P(c)\bigr),
\]

在大范围概念上可远大于一次位图读取的 n/64。

两个方向的不对称是本方案的结构基础：**能按祖先维护的状态更新便宜，按后代展开的查询昂贵**，因此把昂贵的部分在构建期按预算选择性地物化。

### 3.3 物化选择规则

对概念 u，在线展开与读取派生位图的查询工作量分别为 E(u) 与 n/64（n 为对象数）。仅当物化确实减少查询工作且不超预算时才物化：

\[
u\in\mathcal M \iff E(u)>\frac{n}{64}
\ \text{且}\
\sum_{v\in\mathcal M}\frac{n}{8}\le B_{\mathrm{m}} .
\]

按 E(u) 从大到小选取，直到预算 B_m 用尽。该规则只依赖构建期可算的量，不使用测试查询真值。

选中节点的派生位图在标签变化时按 3.2 就地修改，无需重建；未选中节点保持精确基数计数，供计划判断使用。

### 3.4 查询算法

```text
Query(q, U, predicate, k):
    U ← normalize to antichain
    if cardinality_bound(U) ≤ τ:           # exact counter, no bitmap needed
        return ExactScan(F(U))             # 枚举并精确计算
    S ← ∅
    for u in U:
        if u ∈ M: S ← S ∪ M(u)             # one bitmap read
        else:     for c in Desc⁺(u): S ← S ∪ P(c)
        if |U| > 1 and popcount(S) ≥ k·Θ:  # early saturation guard
            break
    S ← S ∩ live
    E ← filter_by_attributes(S)
    if |E| == 0: return ∅
    if |E| ≤ τ:  return ExactScan(E)
    return MergeAndDedup(FilteredHNSW(q, E, k), k)
```

基数上限用精确计数取 U 中各概念 |S(u)| 的最大值，因祖先包含而无需展开即可得到上界；小范围查询因此可跳过位图构造。τ 为既有协议的扫描阈值，需按数据实测确定，不作为理论最优值。

### 3.5 更新算法

| 事件 | 操作 | 代价 |
|---|---|---|
| 对象增加标签 c | 对 Anc⁺(c) 中每个概念：基数+1、置 P(c) 的 bit、更新 \mathcal M 中的位图与计数 | O(\|Anc⁺(c)\|) |
| 对象删除标签 c | 对称执行，删除一个标签不影响其他标签仍支持的匹配 | O(\|Anc⁺(c)\|) |
| 对象删除 | 对其全部标签执行上述操作，另在物理结构中标记删除 | O(\|L_i\|·\|Anc⁺\|) |
| 对象插入 | 建立标签、置位、加入物理位置 | 同上加图插入 |
| 普通属性修改 | 写属性记录 | O(1)，不触及层级位图 |
| 概念显示名修改 | 改名称映射，稳定 ID 不变 | 不影响成员语义 |
| 分类边增删 | 重算受影响祖先的闭包；派生位图需重新聚合 | O(D²/64) 或按闭包影响的子集，代价显著高于标签增删 |

DAG 下删除一条边不能消除仍由其他路径支持的继承关系，因此边更新必须按重算闭包处理，不能按单路径指针调整。若概念数较大、闭包在线计算，边更新只影响可达性查询的缓存，不触发位图重聚合。

### 3.6 成本模型

记号：d=|Desc⁺(U)|、w=Σ_{c∈Desc⁺(U)}words(P(c))、n 为对象数、ρ=|S(U)|、e=|F_Q|、p 为启用的属性谓词组数、m=|Anc⁺(c)|。

\[
T_{\text{在线}}\approx c_1 w+c_2\frac{n}{64}+c_3\rho p,
\qquad
T_{\text{物化}}\approx c_2\frac{n}{64}+c_3\rho p .
\]

在 |F_Q|≤τ 时查询退化为

\[
T_{\text{scan}}\approx c_2\frac{n}{64}+c_4 e d_{\text{vec}},
\]

其中 d_vec 为向量维度。图路径的额外成本来自各作用图的搜索，受资格密度与图结构影响，不给出未经证明的对数最坏界。

驻留空间为

\[
M=\underbrace{\sum_c \tfrac{|P(c)|}{8}}_{\text{倒排}}
+\underbrace{\frac{D^2}{8}}_{\text{闭包(可选)}}
+\underbrace{8D}_{\text{基数}}
+\underbrace{\sum_{u\in\mathcal M}\frac{n}{8}}_{\text{派生位图}}
+M_{\text{向量}} .
\]

派生位图是主要可控项，预算 B_m 直接对应质量-时间权衡：物化越多查询越便宜，标签更新触及的位图越多。

## 4. 与既有工作的边界

[TrieHI](https://arxiv.org/pdf/2606.16903v1) 以稳定节点与按节点物化的成员集合解析层级范围，属于同一物化谱系。本方案的可检验差异在于：(i) 物化粒度由每概念展开代价与预算决定，而非对所有节点物化；(ii) 目标结构是 DAG，多父使同级 scope 相交，单路径物化不足以表示成员关系；(iii) 精确基数按祖先方向维护，用于免物化的范围判定。这些差异需要实测，不能仅凭设计陈述成立。

[Curator](https://arxiv.org/pdf/2601.01291v3) 在共享几何聚类树上按标签分布自适应分区粒度；本方案的分区依据属性概念图而非向量几何。[ACORN](https://arxiv.org/pdf/2403.04871v1) 改变谓词下的图遍历，[iRangeGraph](https://arxiv.org/pdf/2409.02571v1) 按数值范围组合邻接；本方案不改变图邻接，只改变候选集合的取得方式。与这些工作的比较必须固定候选生成方式后进行。

需要明确否定的说法：概念层级本身、倒排表、位图物化、小集合精确扫描都不是本方案的新贡献；候选集合精确也不意味着 ANN 结果精确。

## 5. 可检验假设

1. **H1（展开不对称）**：在真实 DAG 上，查询侧触及的对象数随概念粗细的变化幅度显著大于 |Anc⁺(c)|。**结构上已成立**（最大 scope 168,937 对最大祖先集 16），但尚未测出它对端到端时间的影响。
2. **H2（选择性物化）**：在相同驻留预算 B 下，按 E(u) 选点物化比全部物化或完全不物化获得更低的平均查询时间，且标签更新代价不高于全部物化。**元数据层成立**（1.394 µs 对 3.028/7.461 µs；更新 0.212 µs 对 0.773 µs），**端到端不成立**：范围解析只占 0.1–0.4%，主要价值在维护与内存。
3. **H3（交叠成本）**：多父概念占比提高时，在线展开的合并代价随之上升，而物化读取的代价基本不变。**结构上已确认交叠存在**（父概念 scope 交并比 p50 0.013、p95 0.53、最大 0.90），其对时间的贡献待测。
4. **H4（质量中立）**：上述选择不改变过滤语义与最终 Recall，只改变候选取得的成本；须以逐查询结果比对验证。

否证条件分别是：H1 中两方向幅度相近；H2 中选点物化不优于两种极端；H3 中差值不随多父比例变化；H4 中出现结果或 Recall 差异。

| 量 | 实测 |
|---|---|
| 概念/边 | 1,929（含虚拟根 CCS）/ 2,040 |
| 重复出现的概念 ID | 159；其中**有 ≥2 个不同父**的 103（5.3%） |
| 标注行 | 186,160；可用 168,937；含 `~` 而剔除 17,223；路径无法解析 0 |
| 每篇论文的 \|Anc⁺\| | 均值 4.21，最大 11 |

| 最大 scope / 最大祖先数 | 10,559× |

**更新与查询的不对称得到结构支持**：任何标签变化只触及不超过 16 个概念（每篇论文 4.21 个），而单个概念范围可达 168,937 个对象。

**多父带来的非层状交叠**

12,913 篇论文（可用行的 7.6%，全体行的 6.9%）的继承集合包含至少一个多父概念；12,446 篇的终点概念本身即为多父。对 101 个有非空范围的多父概念，计算其父概念 scope 的交并比 |∩|/|∪|：

| 分位 | 值 |
|---|---|
| p50 | 0.013 |
| p95 | 0.53 |
| max | 0.90 |

尾部情形说明"兄弟分支互不相交"不成立：Personalization 的两个父概念 scope 交集 82、并集 91（0.90）；Computer supported cooperative work 为 953/1,202（0.79）。多数多父概念的交叠很小，因此交叠成本由少数概念主导，而不是均匀分布。

需要注意的度量陷阱：Σ|Anc⁺| 与 Σ|Desc⁺| 恒等（每个可比对从两侧各计一次），因此不能用二者的均值差论证不对称；有效比较是**概念数**与**对象数**。

**物化预算的输入**：按 §3.3 规则在 n=168,937 上取 E(u)>n/64，选中 39 个概念（2.0%），位图合计 824 KB。该集合是 H2 实验的预算基线，不是已经验证的最优选择。

### 6.1 索引层探针

按上述规则实现三种范围解析策略并逐查询比对：[dag_scope_probe.cpp](../../../codes/directory-aware-vector-attr-search/src/dag_scope_probe.cpp)。对象 ID 经固定种子打散，postings 不是连续区间；1,234 条查询（834 单概念 + 400 兄弟 antichain）。

|---|---:|---:|---:|---:|---:|---:|
| 168,937 | 在线展开 | 0.651 | 1.633 | 0 | — | — |
| 168,937 | 全部物化 | 1.348 | 3.126 | 17.6 MB | 0.318 | 0.691 |
| 168,937 | **按规则选点** | **0.297** | **1.123** | **0.82 MB** | **0.080** | **0.140** |
| 168,937 | 重建基线 | — | — | — | 110.4 | 172.1 |
| 1,013,622 | 在线展开 | 3.028 | 9.137 | 0 | — | — |
| 1,013,622 | 全部物化 | 7.461 | 15.138 | 105.7 MB | 0.773 | 1.213 |
| 1,013,622 | **按规则选点** | **1.394** | **6.803** | **4.94 MB** | **0.212** | **0.521** |
| 1,013,622 | 重建基线 | — | — | — | 646.6 | 895.5 |

三个策略在全部 1,234 条查询上返回逐位相同的成员位图（探针在不等时直接失败）。1,013,622 对象由 168,937 条真实标注复制 6 份得到，只用于放大位图，不增加新标签。

结论与限制：

- **选点物化优于两种极端**：比在线展开快 2.2×，比全部物化快 5.4× 且只占 1/21 的空间。全部物化在窄范围上仍复制整张位图，是这段代码里最差的组合。
- **祖先方向传播优于重建**：单次重标注 0.21 µs 对 646.6 µs（约 3,000×）；重标注落在高祖先数对象上时比例不变。
- 这些是**元数据解析**数字，不含向量与 ANN 调用；范围解析只占端到端时间的一部分，不能据此宣称查询总时间收益。
- 重标注目标概念为随机选取，不是真实工作负载；仅测维护代价随 |Anc⁺| 的变化。

### 6.2 端到端：范围解析 + 过滤 HNSW

把同一范围解析接到一张全局 HNSW（M16、efConstruction200、ef20、k10）上，候选集固定后按 |E|≤512 精确扫描、否则图搜索。[dag_scope_ann.cpp](../../../codes/directory-aware-vector-attr-search/src/dag_scope_ann.cpp)。168,937 个对象，1,234 条查询，策略顺序逐查询轮换以消除缓存先后差异。

| 策略 | 范围解析 µs | 搜索 µs | 端到端 µs | p95 µs | macro Recall | 精确/图 |
|---|---:|---:|---:|---:|---:|---:|
| 在线展开 | 0.84 | 426.1 | 426.9 | 3,248 | .999838 | 844 / 234 |
| 全部物化 | 1.61 | 431.9 | 433.5 | 3,412 | .999838 | 844 / 234 |
| 按规则选点 | 0.53 | 435.6 | 436.2 | 3,311 | .999838 | 844 / 234 |

三种策略的合格集合相同，Recall 因此完全一致；搜索时间在轮换后收敛到 426–436 µs，此前非轮换运行的差异（521 对 383 µs）来自执行顺序而非策略。

**结论**：在这个规模上范围解析只占端到端的 0.1–0.4%，选点物化**没有**带来端到端的查询收益。它的价值在维护与内存侧（§6.1：更新快约 3,000×、空间小 21×），不在查询时间。此前观察到资格计算占 82% 的情形来自在百万对象上做平坦属性过滤，与本节的 DAG 范围解析不是同一项成本，不能互相外推。

### 6.3 按一级概念分区

把对象按所属**一级概念**（根的直接子节点）分区，每个对象只存一份，查询只搜索含合格对象的分区并归并。同一查询集的对照：

| ef | 全局过滤 端到端 µs | Recall | 分区 端到端 µs | Recall | 分区/全局 |
|---:|---:|---:|---:|---:|---:|
| 10 | 238.2 | .998703 | 118.7 | .995624 | 0.50 |
| 20 | 445.4 | .999838 | 182.1 | .998947 | 0.41 |
| 40 | 799.7 | 1.000000 | 279.7 | .999676 | 0.35 |

分区后 p95 从 3,309 µs 降到 1,057 µs（ef20）。

**同 Recall 比较**：分区 ef20 的 Recall（.998947）高于全局 ef10（.998703），端到端为 182.1 对 238.2 µs，即同等质量下快 1.31×；分区 ef40（.999676）对全局 ef20（.999838）差 0.00016，时间 279.7 对 445.4 µs，快 1.59×。

这是标准的按类目建索引，不是新机制；它的作用是在本工作负载上把"全局图 + 资格过滤"里被过滤节点浪费的距离计算换成更小的图。与更早的分块实验对照：那里的 P-node（每目录一图）相对另有预选与扫描回退的混合基线并不占优，而这里的对照是单张全局图，两者不能互相引用为收益证据。

**仍缺**：SciHTC 不含向量，文本需申请或按 ACM proceedings 重建，当前不可得，因此质量-时间联合评估尚不能进行。索引侧代价实验可用 SIFT 向量复制绑定到上述标签（明确标注无语义对应），仅用于测量结构与成本。

## 7. 实现现状

现有 C++ 原型为单亲树、每对象单一 owner、模板化标签集缺失，且已停止维护矩阵。实现本方案需要的改动：

- 概念图改为多父邻接，Anc⁺/Desc⁺ 按可达闭包计算并去重。
- 对象由单一 owner 改为标签集 L_i。
- 增加按概念维护的精确基数与可选派生位图。
- 标签增删事件按祖先方向更新，替代当前的 owner 移动语义。

未完成上述改动前，已存的 SIFT/WIKI 结果只对应受限的单标签树形负载，不能作为 DAG 或交叠场景的证据。既有数据的口径、限制与原始配置见 [分区HNSW实测数据](../2026-10-31-exps/data/query-first-dense2.csv) 与[对应报告](../2026-10-31-exps/packed-query-first-local-report.md)。
