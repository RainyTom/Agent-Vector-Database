# 方案 v7：DAG 划分 + 合并策略矩阵 + 三类过滤结构

> 实验协议与索引方案。基线固定为"随机顺序建全局图 + top-k 过滤搜索"。

## 1. 划分

- 按 owner 精确划分：`items(c) = {i : own(i)=c}`，每个 item 只属一组，多父概念一份。
- 概念层用稳定整数 ID；名字只在入口字典（§11）。

## 2. 合并策略矩阵（2×2）

两个正交因子，各两水平：

| 因子 | 水平 A | 水平 B |
|---|---|---|
| **插入顺序** | 随机 | 概念拓扑序（父先子后，同层按子树大小降序） |
| **合并规则** | 重插（HNSW `addPoint`，会重选邻居并剪旧边） | 保边合并（子图边原样保留，只加门户桥） |

| 策略 | 插入序 | 合并规则 |
|---|---|---|
| **S0（基线）** | 随机 | 重插 |
| S1 | 拓扑序 | 重插 |
| S2 | 随机 | 保边合并 |
| S3 | 拓扑序 | 保边合并 |

四个策略**参数完全相同**：`M=16`、`efConstruction=200`、`k=10`、`ef∈{15,20,40}`、门户 `q=2`、`pcap=2`。唯一差异是上表两列。

保边合并的门户就是该子图的入口集；桥只沿 `p→c` 单向；桥数受 `pcap` 配额约束。

## 3. 过滤结构（各自职责固定）

| 结构 | 粒度 | 回答什么 | 何时用 |
|---|---|---|---|
| **Trie** | 概念名 → 概念 ID；DAG 用多父入口 | 查询条件解析 | 入口一次性 |
| **位图（概念级）** | `Desc⁺/Anc⁺` | `D`、`E` 的位运算 | 每次查询开始 |
| **位图（item 级）** | 每 item 一条 `owner ∪ attr` 位 | 结果资格判定 | 每次弹出/入队 |
| **Bloom（邻接级）** | 每节点一个 Bloom，装其邻接的 owner 集合 | "本节点的邻居里可能存在 E 中的 owner 吗" | 每次展开前 |
| **Bloom（簇级）** | `V` 大时替代"某概念是否在某子树"的位图 | 否定式准入 | 划分很细时 |

**Bloom 的用途是邻接级否定**：`E` 通常很小，多数节点的邻接与 `E` 无交集。Bloom 命中失败时整条邻接表跳过，省掉 `M` 次 owner 查表；假阳性只多扫一次，不影响正确性。Bloom 位宽 64、`k=2`（可按 `M` 调）。

## 4. 遍历规则：两种"跳过"必须分开

| 跳过类型 | 判据 | 后果 |
|---|---|---|
| **结构跳过** | `own(v) ∉ E` | 不访问、不算距离。合法性由单向边保证（后代仍在 `E` 内） |
| **谓词跳过** | `own(v) ∈ E` 但 `P(a_v)` 不成立 | **仍可入队参与导航**，只是不进结果堆 |
| 邻接表跳过 | Bloom 否定 | 整条邻接不展开 |

这三条是方案的全部过滤动作；除此之外不做任何"先算全量合法集"的前置。

## 5. 查询

```text
D ← ⋂_组 ⋃ Desc⁺（位图）；property 子树 0 命中整概念剔除
E ← D ∪ Anc(min D)
种子：S2/S3 用门户；S0/S1 用全局入口
单队列 best-first：
  弹出最近者；|R|=k 且 d>第 k 名 → 停；visited 去重；距离每 item ≤1 次
  展开前查 Bloom：否定则整条邻接跳过
  逐条边：own(v) ∉ E → 跳过；否则算距离入队
  own(v) ∈ D 且过属性 → 进结果堆
回退：结果不足 → 放宽到 Ant(D) 重跑
```

## 6. 基线为什么公平

S0 = 随机顺序 `addPoint` 到一张全局 HNSW + bitmap callback，等价于 hnswlib 默认行为加过滤，不裁剪 `ef`、不改停止规则、不降 `M`。四个策略共用同一 `raw_l2_space`、同一 `efConstruction`、同一查询集与真值。

## 7. 评价

| 指标 | 用途 |
|---|---|
| 端到端均值 / p95 | 主指标 |
| 非空 macro Recall、pair Recall | 质量；空查询单列，不计 Recall=1 |
| 距离计算数 | 机制归因 |
| 邻接扫描边数 | Bloom 与剪枝的实际效果 |
| 访问节点数、启动子图数 | 结构归因 |
| 构建时间、索引大小 | 代价 |

所有比较必须在**同 Recall 层**：把每条臂的 `ef` 扫到与对手相近的实际 Recall，再比时间与工作量。

## 8. 预测与失败判据

- 预测：`s ≤ 2%` 时 S2/S3 的距离数与端到端优于 S0；S1 居中；`s → 100%` 四者收敛；概念-几何不相关（`ρ≈1/n`）时 S2/S3 优势消失。
- 失败判据：S2 或 S3 在同 Recall 下不优于 S0 → "保边合并"这一因子无效；S1 不优于 S0 → 插入顺序因子无效。两个因子可分开放弃。
