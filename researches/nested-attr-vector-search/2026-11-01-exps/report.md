# DAG 层级属性内存检索：局部图基线与有限查询核验

## 当日目标与结论

研究条件为向量和索引全部驻留内存，目标是利用 DAG 属性语义减少范围推导、图搜索、节点扩展或距离计算，同时限制更新工作。当前验证的是**概念闭包＋直接成员倒排＋可选 scope 物化集合＋对象到局部图映射＋每组普通 HNSW**这一常规基线。[正文与 SVG](hierarchical-dag-attribute-index.md)给出算法、样例和研究边界。数据排布、缓存友好访问、SIMD、预取或内存重排不作为贡献。

有限时间—质量观察使用同批随机 20 条查询、每臂驻留三遍。三级分组在该样本中 macro/pair Recall 均为 1，完整均值 39.74 µs，全局过滤图 241.83 µs，均值比 6.09。样本只有三条图路径查询；未取得完整节点/边扩展和距离计算数，因此不能据耗时差证明算法工作量减少，也不作访存归因或纯 NodeANN 主基线胜出结论。

| 重复与顺序 | 每个配置 3 遍；四臂逐查询/逐遍轮换；同配置只构建一次全局图及一次分区图集合 |

## 3. 分区粒度与成本位置

| 量 | 一级分组 | 三级分组 |
|---|---:|---:|
| 分区槽数 / 实际非空图数 | 14 / 13 | 607 / 364 |
| 非空分区对象数均值 / 中位数 | 12,995.2 / 9,565 | 464.1 / 177 |
| 非空分区对象数 p95 / 最大 | 29,642 / 31,505 | 1,636 / 9,823 |
| 合格分区数均值 / p95，含空与扫描查询 | 1.05 / 2 | 1.50 / 4 |
| 分区臂范围解析 / 定位均值 µs | 1.34 / 15.13 | 1.36 / 15.73 |
| 分区臂搜索均值 µs | 80.54 | 22.52 |
| 全局建图 s / 分区图集合建图 s | 43.54 / 29.84 | 43.34 / 13.77 |

分组键来自最短深度与最小稳定祖先 ID；深度小于分组深度的概念保留自己的键。DAG 的最短深度层不是分隔全部路径的 frontier，逻辑成员仍由完整可达闭包判断。

主要观察：

- 三级分组把图搜索放到更小的图中，scope 行 161 涉及的合格分区数由 2 增至 8，搜索仍更快；这不能推导 fanout 越大越好。
- 搜索降到 22.52 µs 后，定位已占完整均值约 40%。继续仅缩小图，收益会受到这段开销限制。
- 小集合路径上三级分区均值 22.76 µs，全局臂 14.24 µs；分区的总体收益由三条图路径查询贡献，不是所有查询都更快。
- 同次三级配置的三种全局图臂完整均值为 227.55–241.83 µs，使用同一张图与相同成员集合。20 条样本不支持把这段时间差因果归于物化。
- 两配置串行运行 wall time 131.18 s；四个建图阶段合计 130.49 s，约占 99.5%。驻留重复没有重建图；耗时主要在首次图构建，不在重复查询。

没有测每种方案的独立 RSS；全局图与分区图同时驻留，不能以进程峰值推断单方案空间。本文不将多图等同为省内存，也不将小图上的 ef20 与大图 ef20 解释成相同相对搜索努力。

## 4. 更新约束与实际检查

标签变化按旧、新继承集合差分维护基数与选中物化集合。多个直接标签支持同一祖先时，仅在成员关系 0↔1 转换时增减。保留对象所属的局部图可避免仅因标签变化重建图，但可能使后续查询调用更多图。排序 posting 的插删成本仍需计入，祖先状态触及数不是完整更新时间界。

实际执行 32 次固定种子单标签重标注，每 8 次及初始状态核验。三种策略各有独立标签、posting、基数和物化位图；参考从重放标签与原始 child 边重建。5 个检查点共核对 28,935 个 scope 成员集合和同数基数、15 次 posting 状态，差异 0。[实测 JSON](data/dag-scope-maintenance-check32/probe.json)。

该检查不是维护矩阵。计时字段 `bitmap_counter_update_kernel_us` 仅含祖先集合差分、计数与位写，排除 posting 插删、标签赋值、独立核验和几何图维护；32 次不足以建立更新性能结论。未测一般多直接标签、边更新、插删容量扩张、并发或恢复。

SciHTC 为 Sadat、Caragea，EMNLP 2022，pp.8923–8937；正式 PDF 给出 1,233 topics，主实验只用 83 个前两级主题。作者将使用全部相关分支列为 future work。原文以 tree 描述标签层级，项目的多父闭包不是作者已验证的 ANN 数据协议。[书目与核读记录](../../../papers/hierarchical-classification/2022-scihtc/paper.report.md)已进入总索引，不增加推测引用边。

CCS 本体测得 103 个不同父数 ≥2 的概念（5.34%）；159 是重复出现的 ID 数。168,937 可用标签行中，12,913 篇继承集合包含多父概念，12,446 篇终点本身多父。结构统计与交叠数据见 [scihtc-dag-structure.json](data/scihtc-dag-structure.json)。结构上的小祖先集合与大对象 scope 不能直接证明时间加速。

官方 [Weaviate filtering](https://docs.weaviate.io/weaviate/concepts/filtering)、[Qdrant indexing](https://qdrant.tech/documentation/manage-data/indexing/)用于核对 inverted index、allow-list、flat-search cutoff、filterable HNSW 的含义，不引用其性能作为本项目实测。已有原始摘录见 [official-filtering-terminology.json](data/official-filtering-terminology.json)。

## 7. 局限与可调整位置

1. 当前性能对照是全局过滤图，不是用户指定的纯 NodeANN 三臂比较；不能混用两者的胜出结论。
2. 只有 20 个不同 query，其中 3 个图路径；需要更有覆盖性的质量—时间比较才能选定分区深度，当前不扩规模或 ef 矩阵。
3. 先在小集合处跳过不必要的分区定位；对图路径，考察如何降低精确分区定位的候选枚举成本，同时保持覆盖与标签更新局部性。
4. 自然文本/embedding 仍需授权数据；无语义相关性的绑定实验不能证明真实学术论文检索收益。
5. 图成员归属不随标签改变时的 fanout 漂移、多图状态成本及一般多标签维护仍需实测；不能以布局优化、空间聚集或内存访问顺序代替算法工作量的减少。

## 9. 全驻内存的算法研究口径

索引与向量均在内存中，所有比较固定距离核和实现条件。机制评价记录概念/posting 枚举量、实际图调用数、节点/边扩展数、向量距离计算数及更新状态操作数；不以连续排布、缓存局部性、SIMD、预取或重排作为研究增量。

八对象例子验证语义覆盖、可跳过的局部图及标签更新后的图结构不变性。普通属性分组 HNSW 属于基线；现有小样本耗时不足以建立 DAG 专有算法贡献。当前仍缺完整工作量计数、与纯 NodeANN 的同质量归因及自然向量—标签关联验证。本轮仅明确研究口径与图文表意，不修改查询算法、不扩展性能矩阵。
