# 方案 v3：静态分簇图（CGP）——图为主导航，常规组件各司其职

> 静态构造，无查询期自适应。替换 v2 的逐节点动态分配。

## 1. 三层结构

| 层 | 内容 | 构造 |
|---|---|---|
| 概念层 | DAG 闭包位图 `Desc⁺/Anc⁺`；概念 → item 倒排 | 一次性 |
| 簇层 | 簇 → item 列表；簇 → 概念集合（位图，`V` 大时用 Bloom）；簇质心 | 静态聚类 + 静态合并 |
| 图内层 | 每簇一张 HNSW；簇间仅连"可比簇"的桥 | 静态 |

**簇纯净性**是核心参数：簇 `C` 的概念集合 `Σ(C)`。若 `Σ(C) ⊆ D`，该簇对本次查询**整体合格**；此时簇内每条边都在 `E` 内，保留度 = 100%。

## 2. 构建

```text
1. 概念层：闭包位图、owner 倒排、属性子树计数
2. 初始簇：每个非空概念一个簇（纯净，数量 = 非空概念数）
3. 静态合并（唯一需要调参的步骤）：
   反复选取概念 DAG 中"同一父下、且查询共访高"的相邻簇对 (A,B)，
   若 |A|+|B| ≤ Bmax 且 purity(A∪B) ≥ τ 则合并。
   purity 由静态估计给出：Σ(A∪B) 的共同祖先在查询概念分布中的覆盖比例；
   无查询日志时用结构代理——同父兄弟的共访概率下界 = 该父的 scope 占比。
4. 每簇建 HNSW（M、efConstruction 与基线相同）
5. 簇间桥：若 Σ(A) 与 Σ(B) 可比（存在 c∈Σ(A), c'∈Σ(B) 使 c' ⪯ c），
   在 A、B 间加 M_bridge 对最近端点边。只连接可比簇，保证桥在合格集内可用。
6. 对每个簇记录：概念位图、item 数、质心、（可选）PQ 码
```

### 组件职责（不用它们做别的）

| 组件 | 唯一职责 | 明确不做 |
|---|---|---|
| 闭包位图 | 把查询条件解析成 `D`、`E`（精确） | 不做距离 |
| 位图（每簇概念集） | 判定 `Σ(C) ⊆ D`（整体合格）、`Σ(C) ∩ E ≠ ∅`（可访问） | 不做排序 |
| Bloom | `V` 很大时替代"某概念是否在某簇内"的判定位图 | 允许假阳性，故只用于**否定式准入**，不用于精确计数 |
| Trie | 把多概念条件归约为祖先/后代枚举；DAG 多父用"多入口 + 闭包位图"补齐 | 单路径 Trie 不能表示多父，不单独承担资格 |
| 量化（PQ 码 + 簇质心） | 决定**进入簇的顺序**（粗排） | 不作最终排序、不作安全剪枝、不替代图导航 |
| 聚类 | 生成纯净簇，决定"哪些 item 一起被搜" | 不改变向量、不做物理布局创新 |
| HNSW | 簇内主导航 | 仍是唯一的近邻搜索核心 |

## 3. 查询

```text
1. D ← ⋂_组 ⋃ Desc⁺；属性子树 0 命中整概念剔除；D=∅ 返回空
2. 准入簇 ← {C : Σ(C) ⊆ D}                    # 整体合格
   可访问簇 ← {C : Σ(C) ∩ E ≠ ∅}               # 含祖先：提供入口
3. 入口排序：按簇质心到 q 的距离（量化粗排，仅排序，不剪枝）
4. 单队列 best-first：
   种子 = 可访问簇中"无带 item 祖先簇"的入口 item
   弹出最近者；|R|=k 且 d>第 k 名 → 停；visited 去重；距离每 item 最多一次
   邻居属于 不可访问簇 → 跳过且不算距离
   邻居属于 准入簇 且合格 → 进结果堆
   邻居属于 可访问但非准入簇 → 入队（导航层），不进结果
5. 卡住回退：队列空且结果不足 → 取消簇级剪枝重跑一次
```

## 4. 保证与代价

| 项 | 内容 |
|---|---|
| 精确 | `D`、`E`、簇准入（位图/精确集合）、属性子树剪枝、去重、并列 `(distance,id)` |
| 近似 | 第 k 界停止；量化只影响进入顺序；Bloom 只做否定 |
| 保留度 | 准入簇内为 100%（`Σ(C) ⊆ D` ⇒ 簇内所有边留在 `E`） |
| 距离上界 | ≤ 可访问簇的 item 总数 |
| 空间 | 簇内 HNSW（与全局同阶）+ 簇概念位图 `O(G·V/64)` + 桥 |
| 构建 | 概念聚类 + 合并 + 每簇 HNSW + 桥 |
| 维护 | item→簇归属变更需重连该簇；概念边变更需重算闭包与簇概念集 |

**最坏反例**：
1. `τ=1`（不合并）→ 退化为 NodeANN，簇数 = 概念数；
2. 合并过度 → 簇不纯净，保留度降为簇内合格比例，回到 `ρ` 问题；
3. 簇粒度过小 → 每簇图退化为近线性扫描；
4. 查询 scope 与任何簇都不整体重合（跨簇散布）→ 全部走"可访问"层，等价全局过滤。

## 5. 12-item 走查

概念 `R→A,B；A→C,F；B→E,F`，每概念 2 item。

| 步骤 | 结果 |
|---|---|
| 初始簇 | 6 个纯净簇：{r1,r2} {a1,a2} {b1,b2} {c1,c2} {e1,e2} {f1,f2} |
| 合并候选 | A 与 C、A 与 F、B 与 E、B 与 F 同父兄弟关系；按 `τ` 合并 |
| 设 `τ` 只允许合并 A+C | 簇 α={a1,a2,c1,c2}，Σ(α)={A,C} |
| 查询 `U={A}` | `D={A,C,F}`；Σ(α)={A,C}⊆D → α 准入；{f1,f2} 准入；{r1,r2} 可访问 |
| 剪枝 | {b1,b2}、{e1,e2} 的 Σ 与 E 不相交 → 不访问、不算距离 |
| 查询 `A AND B` | `D={F}`；只有 {f1,f2} 准入；α 不可准入但可访问（含 F 的祖先？Σ(α)={A,C}∩E≠∅ 视 E 而定） |

## 6. 与 v2 的差别

| 项 | v2（ACE） | v3（CGP） |
|---|---|---|
| 分配依据 | 每节点实测 `ρ_u` | 静态簇 + 纯度阈值 `τ` |
| 参数 | `(g_u,d_u)` 逐节点不同 | `Bmax`、`τ`、`M_bridge` 全局固定 |
| 量化用途 | 无 | 簇粗排（仅排序） |
| Bloom/位图/Trie | 未使用 | 明确定义职责 |
| 结构变更 | 需重算 `ρ_u` | 仅簇合并/拆分 |

## 7. 待验证

- 合成数据控制纯度（`τ` 从 1 到 0.5），观察保留度与同 Recall 距离数；
- 与"全局过滤 HNSW"和"不合并的 NodeANN"对照；
- 失败判据：`τ=1` 时若 CGP 与 NodeANN 等价且无改善，则本方案的价值全部落在"合并"上，需要单独证明合并收益。
