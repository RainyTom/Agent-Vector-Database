# 下闭锥图（DCG）：DAG 层级多属性过滤的完整索引与搜索规格

> 状态：**完整规格 + 参考实现控制流核验；未做 ANN 性能实验**。
> 12-item 例中的二维坐标是**示意坐标**，只用于检验顺序、去重、第 k 界与停止规则，不是真实向量，也不是实验结果。
> PQ 编码 Trie 属用户定位驳回且从未实施；本方案与它无关，也不使用每概念独立 top-k 合并。

---

## 1. 数据与查询语义

### 1.1 数据

- 概念 DAG：`V`、直接边 `E_c ⊆ V×V`（父 → 子）；`Desc⁺(c)`、`Anc⁺(c)` 为含自身的可达闭包。
- item `i`：唯一 ID、原始向量 `x_i ∈ R^d`、**唯一 direct owner** `own(i) ∈ V`、独立普通属性元组 `a_i`。
- owner 可在根、内部或叶节点；多父是**概念继承**，不是对象多标签。
- 共享后代只存一份：`f1/f2` 的 owner 是 `F`，不会在 `A`、`B` 下各复制。

### 1.2 查询

查询为 `Q = (q, G, P, k)`：

- `G = [g_1, …, g_t]`：概念条件，**组间 AND，组内 OR**；每个 `g_j ⊆ V`。
- `P`：普通属性硬过滤（同一 item 必须同时满足所有分量）。
- 返回 scope 内按 `(squared-L2, id)` 排序的前 `min(k, |F_Q|)` 个 item。

概念域精确求解：

\[
D=\bigcap_{j=1}^{t}\ \bigcup_{u\in g_j}\mathrm{Desc}^+(u),
\qquad
F_Q=\{i : own(i)\in D \ \land\ P(a_i)\}.
\]

单组时退化为 `D = ↓U`。`A AND B` 即 `Desc⁺(A) ∩ Desc⁺(B)`；12-item 例中等于 `{F}`，`F` 只计一次。

**关键性质（本方案的基础）**

> **P1：`D` 在 poset 上下闭。** 若 `c ∈ D` 且 `c′` 是 `c` 的后代，则 `c′ ∈ D`。

因为 `D` 由后代闭包生成或求交：后代闭包下闭，下闭集的交仍下闭。普通标量属性没有此性质——这是 DAG 独有。

## 2. 索引

### 2.1 图

**节点**：每个 item 一个节点（`n` 个），全局唯一 ID。

**边**：只保留两类有向边，均满足 `own(v) ⪯ own(u)`（目标 owner 是源 owner 的同节点或后代）：

| 类 | 定义 | 数量上界 | 作用 |
|---|---|---|---|
| `S` | 端点同 owner | 由概念内图决定，≈ `n·M_s` | 概念内部导航；保证概念内连通 |
| `D` | 目标 owner 是源 owner 的**直接子概念**，成对选取 | `M_bridge × |E_c|` | 沿 poset 下行 |

**不存在**：向上边、跨不可比概念的边、全局入口边。这是与全局 HNSW 的根本差别：全局图按几何选边，邻接可连接任意 owner，因此任何资格剪枝都会切断路径；DCG 的邻接被约束在 poset 方向上，才使剪枝可证。

### 2.2 辅助结构（只判定，不导航）

| 结构 | 内容 | 规模 |
|---|---|---|
| 概念闭包位图 | `Desc⁺`、`Anc⁺`，每概念一个 `V/64` 字位图 | `O(V²/8)` 字节 |
| owner 倒排 | `items(c)`：owner 为 `c` 的 item 列表 | `O(n)` |
| 属性子树计数 | `match(c, P)`：`Desc⁺(c)` 内满足谓词分量的 item 数；按 `(概念, 属性分量)` 存 | `O(V·p)` |
| 查询期 | `D`、`E`、`visited`、`dist` 缓存、候选堆、结果堆 | `O(V/64 + n_seen)` |

其中 `p` 为属性谓词分量数（等值、区间、标签）。属性计数是 zone map / inclusive count 的常规做法（与 TrieHI 的 `Inc(v)` 同类），**不是本方案的贡献**，它只是"多属性参与剪枝"的落点。

### 2.3 构建不变量

后续定理只依赖这三条：

- **I1 概念内连通**：`items(c)` 在 `S` 子图上连通。
- **I2 桥完备**：概念 DAG 的每条边 `(p → c)` 至少有一对 `p-item → c-item` 的 `D` 边。
- **I3 单向**：所有边满足 `own(v) ⪯ own(u)`。

## 3. 构建算法

```text
BUILD(items, V, E_c, params):
    # 1. 概念域结构
    for c in V:
        Desc⁺(c) ← BFS/DFS 沿 children
        Anc⁺(c)  ← BFS/DFS 沿 parents
        items(c) ← {i : own(i) = c}

    # 2. 概念内图（S 边），每概念独立
    for c in V with |items(c)| > 1:
        G_c ← HNSW(items(c), M_s, efConstruction)     # 复用现成实现
        for (u → v) in G_c.edges:
            add_edge(u, v, S)                           # 双向
        assert I1 by checking connected components

    # 3. 概念边桥（D 边），父 → 子
    for (p → c) in E_c with items(p) and items(c):
        # 选取 M_bridge 对最近端点；可用 (a) 精确最近点对
        # (b) 采样近似 (c) 以 child 侧质心找 parent 侧近点
        pairs ← nearest_pairs(items(p), items(c), M_bridge)
        for (u, v) in pairs:
            add_edge(u, v, D)                           # 单向 p → c
        assert I2

    # 4. 属性子树计数，自底向上
    for c in reverse_topological_order(V):
        for each attribute component a:
            match(c, a) ← [own = c 且满足 a 的 item 数]
                          + Σ_{child} match(child, a)
    assert I3 by checking own(v) ⪯ own(u) on every edge
```

参数与基线对齐：`M_s = 16`、`efConstruction = 200`；`M_bridge` 是新增参数，默认取 2–4（1 只保证覆盖，不保证几何质量）。

**构建复杂度**

- 闭包：`O(V·(V+E_c))` 或按需遍历；位图内存 `O(V²/8)`。
- 概念内图：与"在同样总数上建 HNSW"同阶。
- 桥：每条概念边一次 `|items(p)| × |items(c)|` 的最近点对；可用采样降到 `O(M_bridge · sample)`。
- 属性计数：`O(n + V·p)`。

## 4. 搜索算法

```text
SEARCH(q, G, P, k, B, B_anc):
  # ---------- 阶段 1：概念域（不算任何向量距离） ----------
  D ← ⋂_j (⋃_{u∈g_j} Desc⁺(u))                       # 位图求交/并，精确
  if P ≠ ∅:
      D ← {c ∈ D : match(c, P) > 0}                  # 子树 0 命中 → 整概念剪掉
  if D = ∅: return ∅                                  # 空结果，不补

  # ---------- 阶段 2：入口最小锥 ----------
  Mset ← {d ∈ D : Anc⁺(d) ∩ D = {d}}                  # D 中的极小元
  E ← D ∪ (⋃_{m∈Mset} Anc⁺(m))
  if P ≠ ∅:
      E ← {c ∈ E : match(c, P) > 0} ∪ Mset

  # ---------- 阶段 3：种子 ----------
  seeds ← { i : own(i) ∈ E
                and 没有祖先 c′ ∈ E \ {own(i)} 满足 items(c′) ≠ ∅ }

  # ---------- 阶段 4：单队列 best-first ----------
  H ← min-heap of (dist, id)
  dist ← empty map                    # 每个 item 的距离最多计算一次
  visited ← empty set
  R ← max-heap of size k, ordered by (dist, -id)
  exp ← 0 ; exp_anc ← 0
  for s in seeds:
      dist[s] ← ‖q − x_s‖² ; push (dist[s], s)

  while H ≠ ∅ and exp < B:
      (d, v) ← pop min(H)
      if |R| = k and d > max(R).dist: break            # 第 k 名前界
      if v ∈ visited: continue                          # 去重（同 id 只处理一次）
      visited.add(v) ; exp += 1
      if own(v) ∉ D:
          exp_anc += 1
          if exp_anc > B_anc: continue                  # 祖先层单独限额，仍可入队但不扩展
      if own(v) ∈ D and passes(v, P):
          offer(R, (d, v))                              # 满 k 时替换最差
      for (w, class) in out(v):
          if own(w) ∉ E: continue                       # 精确剪枝，不算距离
          if w ∈ visited or w ∈ dist: continue          # 已处理或已入队
          dist[w] ← ‖q − x_w‖²                          # 唯一的距离计算位置
          push (dist[w], w)
  return top-k of R sorted by (dist, id)
```

### 4.1 规则要点

| 规则 | 内容 | 理由 |
|---|---|---|
| 距离计算位置 | 只在入队时算一次，`dist` 缓存去重 | **每个 item 至多一次距离**，总距离数 ≤ `|items(E)|` |
| 剪枝 | `own(w) ∉ E` 时跳过，且不算距离 | 见 §5 的充分性定理 |
| 结果资格 | `own(v) ∈ D` 且过属性 | 属性是 item 级，必须逐 item 判 |
| 停止 | 第 k 名距离 < 弹出距离，或 `exp ≥ B` | 标准 best-first；`B` 与 HNSW 的 ef 同类，不是 R |
| 祖先限额 | `own(v) ∉ D` 的扩展单独计数 `B_anc` | 防止近而无用的祖先顶住 frontier |
| 并列 | `(distance, id)` | 与真值口径一致 |
| 不足 k | 返回实际数量，不补不合格项 | 与协议一致 |

### 4.2 边界情况

- `D = ∅`（含属性全不命中）：直接返回空，不启动搜索。
- `k > |F_Q|`：返回全部合格项，不填充。
- 重复入队：同一 item 可被多条边写入 `H`，`visited`/`dist` 保证只处理一次、只算一次距离。
- 多父共享 item：只有一个节点，`D` 中只出现一次，不会重复计数。
- 根查询：`D = V`、`E = V`，退化为"全下闭图"搜索，无剪枝收益。
- 深链：`E` 含全部祖先链，`exp` 受 `B` 限制。
- 属性与 DAG 同 item 满足：谓词在 item 上求值，不做"两字段各自有人满足"的推断。

## 5. 正确性

### 5.1 两级可访问集

| 级别 | 集合 | 剪枝依据 | 是否需要构建假设 |
|---|---|---|---|
| L1 | `V1 = Ant(D) = {c : Desc⁺(c) ∩ D ≠ ∅}` | 被剪概念的**整个子树与 D 不相交** | 只需 I3 |
| L2 | `E = D ∪ Anc(min D)` | 被剪概念的子树**可能仍含 D**，但 D 可由 `min(D)` 独立到达 | 需 I1 + I2 |

`E ⊆ V1` 恒成立。L2 更紧，但它的正确性不是"子树为空"，而是"存在替代路径"——这一点必须写清楚，否则会误判。

### 5.2 定理

**T1（L1 精确）。** 若 `own(v) ∉ V1`，则 `Desc⁺(own(v)) ∩ D = ∅`；由 I3，从 `v` 沿边只能到达其子树内节点，因此**任何合格 item 都不在 `v` 之后**，剪掉不损失候选空间。

**T2（L2 充分）。** 若 I1、I2 成立，则对任意 `d ∈ D`，都存在从种子出发、**只经过 `E` 中节点**的路径到达 `d`。

证明：由 P1，`D` 下闭。取 `d ∈ D`，其祖先链在 `D` 内终止于某个 `m ∈ min(D)`，故 `d ∈ Desc⁺(m)`。`Anc⁺(m) ⊆ E`，且 `E` 中沿概念边向下的链由 I2 的桥逐段连通；`D` 内从 `m` 到 `d` 的中间概念都属于 `D ⊆ E`，每个概念内部由 I1 连通。故该路径存在。∎

**T3（距离上界）。** 由 T2 与剪枝规则，搜索只会把 `E` 中的 item 入队；`dist` 缓存保证每个 item 至多算一次距离，因此**距离计算次数 ≤ `|{i : own(i) ∈ E}|`**，与 `k`、`B` 无关（`B` 只限制扩展数）。

这解释了为什么该方案值得测：真实 DAG 上这个上界的中位数是全部 item 的 0.86%，而全局过滤图没有上界。

### 5.3 什么是精确的、什么不是

| 项 | 性质 |
|---|---|
| 概念域 `D`、`E`、属性子树 0 命中剪枝 | **精确**（位图与计数，无近似） |
| 剪枝后候选空间完整性 | **精确**（T1/T2） |
| 属性逐 item 判定 | **精确** |
| 去重、并列、空结果、不足 k | **精确** |
| 第 k 名前界停止 | 依赖图的可导航性；**不是**精确保证 |
| 桥的几何质量 → 是否能在 `B` 内找到近邻 | **启发式** |
| 最终 Recall | **不保证**，损失来自扩展预算与桥质量 |

## 6. 12-item 例完整走查

概念：`R→A、R→B、A→C、A→F、B→E、B→F`。每概念 2 个直属 item：`r1 r2 | a1 a2 | b1 b2 | c1 c2 | e1 e2 | f1 f2`。

### 6.1 索引形态（示意坐标，仅用于控制流）

`r1(0,0) r2(.1,.1) | a1(1,0) a2(1.1,.1) | b1(-1,0) b2(-1.1,.1) | c1(2,0) c2(2.1,.1) | e1(-2,0) e2(-2.1,.1) | f1(0,1) f2(.1,1.1)`

| 边类 | 内容 |
|---|---|
| S（概念内，双向） | r1–r2，a1–a2，b1–b2，c1–c2，e1–e2，f1–f2 |
| D（父→子，最近端点对） | R→A: `r2→a1`；R→B: `r1→b1`；A→C: `a1→c1`；A→F: `a1→f1`；B→E: `b1→e1`；B→F: `b1→f1` |

桥由**示意图距离**选取（例如 `r2→a1` 距离 0.82 < `r1→a1` 的 1.0），仅说明"桥端点由几何决定"这一机制，不是真实数据结论。三条不变量均通过检查。

### 6.2 查询 `U={A}`，`q=(1,0.5)`，`k=3`

1. `D = {A,C,F}`；合格 item = `{a1,a2,c1,c2,f1,f2}`。
2. `min(D) = {A}`（`R ∉ D`）；`E = {R,A,C,F}`。
3. 种子：`E` 中无"带 item 祖先"的概念 → `R`，种子 `r1,r2`。
4. 队列展开（预算不限）：
   - `r1` → `S` 到 `r2`；`D` 到 `b1`，**`B ∉ E`，直接丢弃且不算距离**。
   - `r2` → `D` 到 `a1`。
   - `a1` → `a2`；`D` 到 `c1`、`f1`。
   - 依次展开 `c1→c2`、`f1→f2`。
5. 结果（参考实现实际输出）：`a2(0.17), a1(0.25), f2(1.17)`，与暴力一致。

**距离只算在 8 个 item 上**（`E` 的全部 item）；`b1 b2 e1 e2` 从未进入队列。全局过滤图没有规则能排除它们。

### 6.3 查询 `U={C,E}`（散开的多条件），`q=(0,0)`，`k=3`

1. `D={C,E}`；合格 `{c1,c2,e1,e2}`。
2. `min(D)={C,E}`；`E={R,A,B,C,E}`。
3. 种子 `r1,r2`；展开 `r1→b1`、`r2→a1`（均在 `E`），再下行到 `C`、`E`。
4. `F ∉ E`：`Desc⁺(F)={F}` 与 `D` 不相交，且 F 无后代 → `f1,f2` 被剪。
5. 实际输出：`c1(4.0), e1(4.0), c2(4.42)`，与暴力一致；访问 10 个 item（`E` 全部）。

### 6.4 查询 `A AND B`，`q=(0,1)`，`k=3`

1. `D = Desc⁺(A) ∩ Desc⁺(B) = {F}`。
2. `min(D)={F}`；`E={R,A,B,F}`（`F` 的两个父都保留为入口路径）。
3. 合格只有 `f1,f2`；`k=3` 时只返回 2 个，不补 `C/E` 的对象。
4. 实际输出：`f1(0.0), f2(0.02)`，与暴力一致；`c/e` 的 4 个 item 被剪。

### 6.5 参考实现的核验结果

| 查询 | `|D|` | `|E|` | 被剪 item | T2 可达 | 第 k 界 == 暴力 | 穷尽 == 暴力 | 穷尽扩展数 |
|---|---:|---:|---:|---|---|---|---:|
| `{A}` | 3 | 4 | 4 | ✓ | ✓ | ✓ | 8 |
| `{B}` | 3 | 4 | 4 | ✓ | ✓ | ✓ | 8 |
| `A OR B` | 5 | 6 | 0 | ✓ | ✓ | ✓ | 12 |
| `A AND B` | 1 | 4 | 4 | ✓ | ✓ | ✓ | 8 |
| `{C,E}` | 2 | 5 | 2 | ✓ | ✓ | ✓ | 10 |
| `R` | 6 | 6 | 0 | ✓ | ✓ | ✓ | 12 |

穷尽扩展数恰等于 `E` 的 item 数，验证 T3 的上界在该例上取等号。

## 7. 维护

| 事件 | 操作 | 代价 |
|---|---|---|
| item 增加 | 插入概念内图 `S`；更新 owner 倒排与属性计数 | `O(log n_c)` + 计数 |
| item 删除 | 概念内图删除；桥端点失效时补选；更新计数 | 同插入 + 局部桥修复 |
| owner 变更 `c→c′` | 从 `G_c` 删除、插入 `G_c′`；重选涉及 `(p,c)`、`(c,·)`、`(p,c′)`、`(c′,·)` 的桥；更新计数 | 两张概念图 + 常数条桥；**闭包不变** |
| 属性值变更 | 只更新 `match(c, a)` 沿祖先链 | `O(|Anc⁺(c)|)` |
| 概念边增加 `p→c` | 闭包增量更新；新增一组桥；属性计数不变 | 闭包 + `M_bridge` 对 |
| 概念边删除 | 闭包重算；桥删除；可能使 `E` 变大 | 高代价，需离线或标脏 |
| 全量重分区 | 不适用：本方案不做物理重分组 | — |

## 8. 最坏反例

1. **概念与几何不连贯**：`S` 边与桥都很长，下行路径失去指引；`B` 小时内漏近邻，此时不如全局过滤图。
2. **近而无用的祖先**：祖先 item 距 `q` 很近但子树中合格 item 很远；它持续占据 frontier，第 k 界不生效。`B_anc` 只为缓解，不是修复。
3. **深而窄的链**：每层只有 1 个 item，深度 `d` 需要 `d` 次下行；分支因子大时每层要扫全部子概念桥。
4. **单概念大 scope**：`D` 只含一个大概念，`E ≈ D`，剪枝收益趋零，退化为概念内 HNSW（NodeANN 的单图情形）。
5. **根查询**：`E = V`，无剪枝。
6. **桥端点选坏**：`M_bridge=1` 且最近点对恰好几何偏远时，整条下行路径质量差；这是 `M_bridge` 需要 >1 的实证理由（尚未实验验证）。

## 9. 前序与新增

| 前序 | 迁移 | 差异 |
|---|---|---|
| HNSW（Malkov & Yashunin） | 单队列 best-first、`M`/`efConstruction`、第 k 界 | 邻接被约束为 poset 下行，不能连任意 owner |
| ACORN §5 | 谓词子图需额外边才连通 | ACORN 用一/二跳扩展**启发式**维持连通；DCG 用 I1+I2 使剪枝**可证**，剪的是整种子树 |
| Filtered-DiskANN §3 | 标签参与建图 | 它叠加标签图边；DCG 按 poset 方向建桥，覆盖任意 down-set |
| TrieHI §III–IV | 闭包、inclusive 集合、scope 解析 | 该文是元数据层、执行器仍是单全局图，且 WIKI-Dir 把 DAG 压成 canonical tree；DCG 保留多父并让闭包参与遍历剪枝 |
| Curator / IVF 树 | 层级路由 | 它们是树/分区且在分区内做 ANN；DCG 是一张图 |
| NodeANN（本项目基线） | 每概念局部图 | DCG 用下行桥接成一张图、单队列，不各自 top-k 再合并 |
| zone map / inclusive count | 子树计数剪枝 | 常规组件，仅作辅助判定 |

**候选新增点（未认证）**：把"资格是下闭集"变成可证的整种子树剪枝；据此定义入口最小锥并反推图构造不变量 I1–I3；单队列跨整条锥。新颖性需查重，不排除"层级图索引 + 谓词剪枝"的组合已有人做。

## 10. 下一步（唯一判别实验）

三臂：**A** 全局过滤 HNSW、**B** NodeANN（每概念图 + 各自 top-k + 归并）、**C** DCG。同数据、`M_s=16`、`efConstruction=200`、`k=10`、`B ∈ {15,20,40}`、单线程、全驻内存；数据须**概念与几何相关**（按概念生成簇、共享后代由两父共同构成、多父比例对齐 SciHTC 的 ~5%），并附**打乱绑定**对照。

**预测**：`s ≤ 2%` 时 C 在同 Recall 下距离数与端到端时间优于 A、B；`s → 100%` 三者收敛；打乱绑定后 C 的优势消失。

**失败标准**：概念相关数据、`s ≤ 2%`、同 Recall 下端到端不优于 A → 否决；靠调小 `B` 或放宽停止取胜 → 视为劣化基线，否决；任何预算下 Recall 都接近不了 A → 桥质量不足，改桥选择而非调参。
