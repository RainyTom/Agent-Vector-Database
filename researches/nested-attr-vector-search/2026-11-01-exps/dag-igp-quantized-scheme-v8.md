# 方案 v8：概念纯净聚类 + 质心图 + 残差 SQ（IGP 式）

> 在 v7 的 DAG 划分上引入 IGP 的压缩思路：先聚类、残差标量量化、**图节点是质心**。过滤仍在 item 级，但剪枝多出一级（质心级）。

## 1. 与 IGP 的关系

IGP（SIGIR'25）的表示：每条向量存 `(FP32 质心, uint32 质心 ID, 2bit/维 残差 SQ 码)`，图建在**质心**上，查询时沿质心图导航、用码重建候选再打分。

本方案的差异只有一处，但很关键：**质心按概念训练（概念纯净）**。IGP 的质心跨文档、无属性；我们要求一个质心的全部 item 同属一个 owner，于是"质心合格"与"item 合格"等价，质心级剪枝是精确的。

## 2. 结构

| 层 | 内容 | 规模 |
|---|---|---|
| L2 质心图 | HNSW，节点 = 质心，FP32 向量 | `K·M` 边 |
| L1 质心表 | 质心 ID → (FP32 质心, owner 概念, item 倒排表头) | `K` |
| L0 编码 | item → (质心 ID uint32, 2bit/维 残差码) | `n·(d/4 + 4)` 字节 |
| 倒排 | 质心 → item 列表 | `n·4` 字节 |
| 概念层 | 闭包位图、owner 倒排、属性子树计数、Trie | 同 v7 |

`K = n / B`，`B` 为每质心平均 item 数（唯一新增的结构参数）。

**item 不再进图。** 图节点数从 `n` 降到 `n/B`。

## 3. 构建

```text
1. DAG 划分：items(c) = {i : own(i) = c}
2. 每个概念内部 k-means：簇数 k_c = max(1, round(n_c / B))
   质心记 owner = c（概念纯净，这是精确剪枝的前提）
3. 残差编码：r = x - μ_c；按 IGP 的共享分位点做 2bit 标量量化
   存 (μ 的 ID, r 的码)；重建权重共享，不逐维存
4. 质心图（保边合并，同 v7 的合并规则）：
   概念内质心先建小图 → 按 DAG 加父→子桥，不重剪
5. 倒排：质心 → item 列表，按 item ID 升序
6. 概念层：闭包位图、属性子树计数、Trie
```

## 4. 查询

```text
1. D ← ⋂_组 ⋃ Desc⁺；属性子树 0 命中整概念剔除
2. E ← D ∪ Anc(min D)
3. 质心级资格：owner(μ) ∈ E 才可访问；owner(μ) ∈ D 才是"可出结果"的质心
4. 质心图 best-first：
     第 k 名界（用当前候选的重建距离）；visited 去重
     展开前查 Bloom（质心邻接的 owner 集合），否定则跳过整条邻接
5. 访问质心 μ 时：取其倒排，用重建距离（μ + 反量化残差）逐 item 打分
     只保留前 k 个候选进入候选缓冲；item 级再查 owner ∈ D 与属性 P
6. refine：对候选缓冲按配置做一次 FP32 或高精度重算（可关）
7. 结果堆收 top-k；不足 min(k,|F_Q|) 时回退到 Ant(D) 重跑
```

两种距离必须分开记账：**重建距离（ADC，便宜）** 与 **精确距离（FP32，贵）**。IGP 用前者排序、后者（可选）精排；本方案沿用。

## 5. 精确性与近似性的分界

| 项 | 性质 |
|---|---|
| 概念纯净质心 → 质心级剪枝 | **精确**（质心合格 ⟺ 其 item 全合格） |
| `D`、`E`、属性子树剪枝 | **精确** |
| 重建距离 | 近似（2bit/维 + 共享分位点） |
| 质心图导航 | 近似（与 HNSW 同性质） |
| 倒排扫描时只留前 k 个 | **近似**（可能漏掉该质心内的真近邻） |

最后一条是新增的近似来源，必须与 HNSW 的 `ef` 一起报告；`k` 在此是"每质心保留数"，不是全局 k。

## 6. 代价

`d=128`、2bit/维、`B` 为每质心 item 数：

| 项 | 字节/item |
|---|---|
| FP32 原向量 | 512 |
| 本方案编码（码 32 + 质心 ID 4 + 倒排 4） | **40** |
| 质心（摊到 item） | `128·4/B` |
| 质心图（摊到 item） | `M·4/B` |

`B=64` 时约 40 + 8 + 1 ≈ 49 字节/item，约 **10×** 压缩；原始 FP32 是否保留取决于是否启用 refine。

**查询代价的结构性变化**：
- 图规模降 `B` 倍 → 导航更快；
- 每次访问质心要扫 `B` 个 item 的倒排 → 代价从"逐节点遍历"转为"逐质心批量扫描"；
- 重建距离比 FP32 便宜（查表 + 位运算），但倒排扫描是顺序读，访存友好。

## 7. 与 v7 的合并策略矩阵的关系

| 项 | v7 | v8 |
|---|---|---|
| 图节点 | item | 质心 |
| 合并单位 | 概念小图 | 概念内质心小图 |
| 过滤粒度 | item 位图 + Bloom | 质心位图 + item 位图 + Bloom |
| 近似来源 | HNSW 截断 | HNSW 截断 + 2bit 量化 + 每质心 top-k |

2×2 因子（插入顺序 × 合并规则）原样保留，只是作用在质心图上。

## 8. 12-item

每概念 2 个 item，`B=2` ⇒ 每概念 1 个质心，`K=6`。

| 质心 | owner | 成员 |
|---|---|---|
| μ_R | R | r1,r2 |
| μ_A | A | a1,a2 |
| μ_B | B | b1,b2 |
| μ_C | C | c1,c2 |
| μ_E | E | e1,e2 |
| μ_F | F | f1,f2 |

质心图：概念内无兄弟质心，跨概念按 DAG 加桥 `μ_R→μ_A`、`μ_R→μ_B`、`μ_A→μ_C`、`μ_A→μ_F`、`μ_B→μ_E`、`μ_B→μ_F`。

查询 `U={A}`：`D={A,C,F}`、`E={R,A,C,F}`。

- 可访问质心 `{R,A,C,F}`；`μ_B`、`μ_E` 因 owner ∉ E 被剪，**连它们的倒排都不打开**。
- 命中 `μ_A`、`μ_C`、`μ_F` 时各扫 2 个 item，共 6 个候选。
- 结果只收 owner ∈ D 的 item；`μ_R` 可访问但不可出结果。

`A AND B`：`D={F}`，只 `μ_F` 可出结果。

## 9. 待验证

1. **概念纯净 vs 全局质心**：同一 `B` 下，比较"每概念 k-means"与"全局 k-means"的召回与剪枝率；前者剪枝精确但簇更小。
2. **2bit vs 4bit**：IGP 推荐 2bit；本项目 `d=128`、SIFT 分布下 2bit 重建误差是否可接受，必须实测，不照搬。
3. **`B` 的取舍**：`B ∈ {16,64,256}`，看倒排扫描与图规模的交叉点。
4. 失败判据：若 2bit 重建在相同实际 Recall 下不优于 FP32 基线的时间，则压缩层不引入。
