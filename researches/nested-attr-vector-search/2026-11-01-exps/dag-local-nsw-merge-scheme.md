# 当前方案：直属 NSW 图 → DAG 自底向上保边合并 → 跨层跳转

## 目标与语义

不做聚类、量化或残差编码，所有 item 均保留 SIFT128 FP32 向量。每个概念 c 的直属集合为 `I(c)={i:owner(i)=c}`，先建局部 HNSW；查询的主要几何导航由合并后的 item 图承担。

“子树挨得更近”指通过新增连接缩短图路径，不改变原始向量距离、不做物理排布优化。结构可达不等于低 ef 下可导航，短路径也不自动等于低延迟。

## 1. 局部图

对非空 I(c) 使用固定版本 hnswlib 构建 HNSW：M=16、efConstruction=200。保留所有 level-0 边，并添加反向边，得到用于合并的无向 NSW 层。原生局部 HNSW 连同高层保留为 NodeANN 参考执行器；新方案不分别查询这些局部索引再归并。

每个概念从直属 item 中确定性选至多 8 个门户：最小 item ID 起始，随后 farthest-point sampling。距离统一经过 `raw_l2_space.h`。门户是真实 item，不是质心。

## 2. 子图连接：自底向上合并

逆拓扑序处理每个概念 c，输入是 I(c) 的局部图（若非空）和每个直接子概念的子图句柄。

1. 收集这些输入图各自至多 8 个代表门户。
2. 两个输入组的边权取门户之间最小 FP32 squared-L2，对门户组运行 Prim MST。
3. 每条 MST 边落为对应两个真实 item 之间的双向连接；已有边不删除。同一 item 同时代表两组时无需自环。
4. 每个门户再连接其他输入组中最近的门户，形成多入口几何连接，而非仅靠 MST 的一条桥。
5. 对 I(c) 及各直接子概念的直属 item，分别在每个输入组中选择最近的异 owner 门户，加 item→门户有向边。跨所有合并上下文，门户仅保留距离最近的至多 16 个反向接入候选，再加门户→item 边。候选可在不同合并上下文重复，最终邻接去重；不宣称得到 16 个不同来源。
6. 对候选门户并集去重，再用同一 farthest-point 规则选至多 8 个子树代表，供上层合并。

父概念没有直属 item 时仍对各子图做连接，不依赖一个不存在的“父 item”。共享后代只存一份，多个父节点引用同一子图；合并是集合并集加边，不是重插、复制或压成单路径树。

MST 是稀疏连通骨架，不要求某个 item 必须承担所有连接。若输入子图连通，则连接后的并集连通；局部 HNSW 不凭名称假设连通，运行时用穷尽搜索对照 GT 检查当前工作负载。

## 3. 跨层跳转

完成子树合并后，将概念 c 的直属门户与 c 的子树代表相连（双向、去重、无自环）。代表可能属于较深后代，从而形成绕过逐层中转的显式捷径。

跳转规则是静态的，不按查询动态重连。当前没有 O(log 深度) 跳数保证；代表可能集中在少数分支，需要后续消融检验。

对称局部边、MST、门户连接与跳转允许同一合格锥内横向移动；分散 item→门户连接及其限额反向边不保证对称。边不满足“只能指向后代”的限制，因此查询必须逐目标检查 owner 资格；不能沿用“任何边天然合格”的结论。单独的对称连接骨架保留，新增有向连接不会破坏其可达性。

## 4. 查询

当前实验只覆盖 DAG 单概念与多概念 OR：`D=union Desc+(u)`。完整多属性/AND 扩展不属于当前实测。

- 计算合格概念位集合 D 与其中的极小概念集 min(D)。
- 从 min(D) 的子树代表初始化一个 best-first frontier。
- 邻居 owner 不在 D 则不访问、不计算距离。其余节点全局 visited 去重，共用一个 ef 候选堆。
- 全程只有一个搜索队列、一个结果堆，返回合格 top-10；不做每概念独立 top-k 归并。

D 是下闭集。若每个子树构建连通，则每个 min(D) 的锥内连通；所有这些锥均有入口，共享部分按 item ID 去重。该性质支持穷尽搜索恢复全部合格 item，不保证有限 ef 的召回。

## 5. 构建与空间口径

局部图与原生 HNSW 共用 M/efConstruction，但实际边数不强行宣称相同：反向局部边、MST 与门户/分散连接、跳转全部计入。当前最优保留配置的有向邻接共 4,065,272 条，不是同内存预算比较。

门户选择包含对直属 item 的距离评估；MST 在一个概念的 d 个输入组上需 O(d²q²) 次门户距离，q≤8。分散连接还要把父概念与各直接子概念的直属 item 对每组 q 个门户打分；多父 item 可参与多个合并上下文。不能把整套建桥成本简写为 O(q)/概念边。

每概念最多 q² 条直属门户—子树代表候选跳转。反向接入候选数上限 16 只约束分散连接这一类边；其正向边数随合并上下文和输入组数增长，MST/门户/跳转也可共享端点，故总度数仍不保证常数上限。

## 6. 固定 SIFT benchmark

入口：仓库根目录 `bash autoresearch.sh`。无网络、固定种子、单线程、固定编译选项；运行结果写入 ignored 的 `work/autoresearch-dag-merge/`。脚本记录五个离线输入的 SHA256，并核对 hnswlib revision `ca426729609b3221563047ceb269cc1213e0d376`。

- 向量：已有 SIFT base 的前 168,937 行，128 维；前 24 个 SIFT query。
- DAG：已有 SciHTC/CCS 工作负载，1,929 概念、2,040 边；使用该快照，不与其他 CCS 解析版本混用。
- owner：原计数保持不变，以 mt19937 seed=20261101 打乱 owner 数组，消除按概念顺序与 SIFT 行顺序对齐的伪相关。是人工绑定控制组，不是真实语义标注。
- scope：从既有 1,234 行查询中均匀选取 24 行，覆盖单概念及 antichain OR；同一行绑定固定 SIFT query。
- GT：扫描合格 item，使用共同 FP32 L2。Recall@10 采用距离边界 ties-aware 定义：任意距离不大于第 min(10,|S|) 名的返回 item 均可命中；分母 min(10,|S|)。空结果查询从 recall 与延迟均值中排除。
- 搜索预算：ef={32,128,512,2048,168937}。合并图、NodeANN与旧后置参考在最大预算校验GT；ACORN-1搜索移植及严格前置控制的最大预算漏答分别记录，不假设其谓词子图必然连通。
- 主比较为本方案、`global_acorn1`搜索策略移植、owner-local NodeANN。ACORN臂在原hnswlib各层收集全一/二跳邻居，局部去重、谓词过滤后截断M，不计算不合格item距离；保留原RNG图及合格owner入口，故不是作者完整ACORN索引复现。`global_prefilter`严格跳过控制和`global_result_filter`原生后置参考继续单列。
- 计时：各ef/查询预热1次、运行3次取中位数，再对非空查询取均值；包含scope、入口、搜索和结果提取，排除GT、构建、CSV输出。主搜索均为单底层队列；NodeANN仅作为独立检索归并参考。
- 主指标`merged_query_us`仍为合并图在平均Recall≥0.95下的最快已测点。全局策略仅在过门槛时输出`global_acorn1_us`；未过时输出`global_acorn1_quality_gate=0`与`global_acorn1_recall_max`，不把低召回延迟当作同质量成绩。严格控制与旧后置参考的指标不混名。
- 次指标保留NodeANN延迟、构建、邻接数及`reference_exhaustive_errors`，另列`global_acorn1_exhaustive_miss_queries`和严格控制漏答。ACORN还测邻接检查/二跳展开/合格候选，其他臂未测的邻接工作不填0。原文、后端差异及完整实测见[ACORN报告](../2026-11-02-exps/report.md#8-acorn-1-搜索策略全一二跳邻域扩展)；历史观察不改名覆盖。

## 7. 证据边界与下一项机制检查

该小规模固定 workload 用于建立可运行基线，不能代替 256+ 查询、选择率分层和多次独立构建。首轮不通过改变 owner 绑定来制造几何相关性，也不根据距离计算次数宣称时间收益。

已完成 12 次固定工作负载运行（含正式基线与保留配置复跑），见[报告 §19](report.md#19-静态合并与跳转的12次固定工作负载实验)。跳转消融、门户几何连接及分散桥起点均已实测；最终保留 q=8、分散正向连接、反向候选上限 16。尚未直接测量最短路或到真实近邻的路径长度，不把有限 ef 的 recall 改善等同于最短路证明。

保留配置两次运行的 query-average Recall 为 0.95652，最差单查询 Recall=0.5，3/23 条非空查询未达到 Recall=1；均值门槛不能解释成逐查询质量保证。仍慢于 owner-local NodeANN 参考。后续需独立扩大查询集、按选择率和逐查询 recall 分层，并在统一边/内存预算下比较；新颖性尚未充分排查。

### 7.1 组合顺序、邻居与跳转的定向实验

[2026-11-02 组合实验](../2026-11-02-exps/dag-composition-report.md) 在统一 ef 口径下重测了这一节的四个可调维：

- 组合顺序：反向桥按距离准入时与顺序无关（升序/降序建出逐边相同的图）；改成先到先得后顺序可观测，但 ef=512 召回从 .9565 降到 .9391。不调顺序。
- 邻居：portal 8 已是合理点（4/16/32 无稳定收益）；出度 diverse 剪枝到 16–24 是唯一同时改善召回与延迟的调整；分布式桥与反向桥是召回的来源，不能删。
- 高速跳转：jump0/1/2/3 召回曲线完全相同，延迟差异落在 ±8–15% 噪声带内；本负载不支持增加跳转边。
- 执行：21 KB visited 位图替代 675 KB 数组，配对中位 −7.6%；CSR 扁平邻接反而更慢，不作为改进。

上述结论只覆盖本 fixture 与本搜索器；大 scope 上合并图召回降到 .55 属质量缺陷，不能与 NodeANN 的均值延迟直接对比。
