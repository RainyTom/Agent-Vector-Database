# 方案评估门（先论证，后实验）

流程：任何新方案在写第一行实验代码前，必须依次通过四道门，并把结论写成可核对的文字。任一门不过，不进入实验阶段——先改方案或改目标。

| 门 | 问题 | 通过标准 |
|---|---|---|
| G1 新颖性 | 最近前序是谁？逐维差在哪？ | 至少一维（数据/谓词/保证/预算）无人覆盖，且前序的发表状态已核 |
| G2 创新性 | 属 L1 新机制 / L2 新设定 / L3 更强证据 / L4 工程 | 明确级别；L2 及以下不得写成"提出新方法" |
| G3 理论有效性 | 能证什么？正确性、界、或可证伪的否证结论 | 至少一条非平凡结论；不能只有 soundness 的同义反复 |
| G4 长论文承载力 | 贡献数、必要实验矩阵、强基线可得性 | 能列出"若做完这些实验就能投 X"的清单，且基线可实现 |

## 本次受检方案：谓词块 × 几何下界（在品类兼容块上做球界剪枝）

### G1 新颖性：**部分通过**

| 组成 | 最近前序 | 差别 | 判定 |
|---|---|---|---|
| 块级几何下界做阈值 join | ε-kdB-tree（ICDE'97/TKDE'02）、M-tree join（EDBT'98）、Dohnal 2003、EGO（SIGMOD'01）、Super-EGO（VLDB J'13）、DAA（MDM'12） | 这些全部只用几何、无谓词 | **不新** |
| 谓词优先分块 | Li et al. SIGMOD'15 多属性前缀树 | 其属性缺失即判失败，**没有"未知=通配"** | 组合处有新意 |
| 层级可比较谓词 | TrieHI（预印本）为单查询 top-k；LSSG/UNG 为扁平标签集合 | 无 join、无可比较品类 | 组合处非空白 |
| 通配语义下 PPJoin 族失效 | PPJoin/PPJoin+（WWW'08/TODS'11）的长度与前缀过滤依赖"缺失=不含" | 本问题缺失=通配，判据方向相反 | **新，且可写反例** |

结论：单看"块级几何剪枝"不新；"拓扑品类 × 通配属性 × 精确全对枚举"这个组合在检到的范围内空白。

### G2 创新性：**L2（新设定下套用已有机制）**

- 若主张"在兼容块上加球界"：机制是 ε-kdB-tree 的，换了个分块依据，属 L2。
- 若主张"通配语义下的安全判据 + 该族过滤器失效的反例"：这是 L1 级语义结论，但作用范围窄（只影响过滤器正确性，不影响渐近代价）。
- 若主张"成本模型 + 三个比值 + 块粒度负结果"：L3。

### G3 理论有效性：**弱**

能证的：
1. 兼容判据的 soundness（已知值冲突 ⇒ 必不匹配）——同义反复，只值一个 lemma。
2. **否证性结论（可解析算出）**：块级球界只在半径 \(r\le\varepsilon\) 时才有机会排除；而块半径随块规模增长。取 d=128、块内 m≈50、各维独立同方差 \(\sigma^2\)，块半径期望
   \[
   \mathbb E[r^2]\approx 2d\sigma^2\bigl(1-m^{-2/d}\bigr)\approx 2\cdot128\cdot\sigma^2\cdot0.060\Rightarrow \mathbb E[r]\approx 3.9\sigma ,
   \]
   与 1% 分位下的 ε 同量级（实测 ε 落在候选距离分布低端），因此**整块排除的理论上限很低**。
   这条可以写成"给定分块依据，块级几何剪枝的可行域"的命题，并用实测半径/ε 比值验证。

不能证的：
- 任何"本方法更快"的正向保证。阈值连接的代价依赖数据分布；高维精确剪枝不存在亚线性保证，这一点前序（DAA/EGO）也只是经验收益。

结论：只有一条 soundness 与一条负结果，**没有正向界**。G3 不通过。

### G4 长论文承载力：**不通过**

| 长论文需要的 | 现状 |
|---|---|
| 新定义 | 有（通配兼容 + 可比较品类），但窄 |
| 新算法 + 保证 | 无保证；机制来自前序 |
| 理论 | 仅 soundness + 负结果 |
| 实验矩阵 | 可做（n、ε、缺失率、属性-几何相关性） |
| 强基线 | **缺**：需移植 ε-kdB-tree / M-tree join / EGO 并公平接入谓词；只与自建 B0/B2 比会被判缺基线 |

结论：以当前形态无法支撑长论文。

## 可升级的三条改法（每条都需重新过门，先不写代码）

**改法 A：把"通配语义"做成核心，提出有保证的连接算子。**
问题从"精确全对枚举"改为"在通配兼容语义下给出输出完备性的 \((1-\delta)\) 保证"。理论点：按属性签名分组后，未访问块的上界可用抽样给出置信界，配合树的父子块结构做分层估计。需证：估计无偏 + 集中不等式 + 总代价界。这条能把 G3 从"只有 soundness"拉到"有界"，但会改变问题定义（从 exact 到 approximate），需与 `final/problem-formulation.md` 对齐或另立一节。

**改法 B：做测量与方法学长文。** 贡献 = 四段成本分解 + 三个比值（4.25× / 23.5% / 100:1）+ 块粒度剪枝的负结果 + 通配语义使 PPJoin 族失效的订正。仍需补：经典 join 的可比适配、n≥200k 规模、相关性参数扫描。审稿风险：被判"只是 benchmark"。

**改法 C：加可证的结构假设再拿速度。** 例如假设内在维度有界、或属性与几何相关（同品类对象聚拢），在该假设下给出精确算法的复杂度界。风险：假设若不成立，结论不迁移；且与动机（跨平台目录）需要论证该假设的现实性。

## 本轮决定

**不执行"在兼容块上算球界"的实验。** 理由：G3 已用解析给出上限很低的预期，G4 缺少可比基线；即便实测剪枝率 3%，也无法支撑论文，属于消耗预算的低信息实验。
