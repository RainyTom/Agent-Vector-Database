## 轮 0：谓词块 × 几何下界 — **G3/G4 未过（已否）**

块级球界需要半径 \(r\le\varepsilon\)；d=128、块内 ~50 点时 \(\mathbb E[r]\approx3.9\sigma\)，与 1% 分位 ε 同量级。只有 soundness + 一条负结果，无可证正向界；且缺可对打的基线。

---

## 轮 1：枢轴过滤（pivot / LAESA 式）搬进谓词块 — **G1 未过**

机制：每个 a 先算 p 个枢轴距离，块内用三角不等式下界 \(d(a,b)\ge|d(a,p_i)-d(b,p_i)|\) 逐对排除。

- G1：枢轴过滤是度量空间 join 的既有手段（Dohnal 2003 eD-index、Jacox & Samet TODS'08 的度量 join 综述），只是换到谓词块上；**无新维**。
- G3：可证的下界是教科书内容，不构成理论贡献。
- 结论：直接否，不进入实验。

---

## 轮 2：签名分区 + 分层抽样的完备性保证 — **G1 部分过、G3 强、G2 弱、G4 待定**

机制：以属性签名（各维已知值）为层，层的大小可由品类树与属性 posting **精确算出、无需扫描**；在总预算 B 下按 Neyman 最优分配抽样，只对抽到的 pair 精算距离；给出"漏掉的真结果占比 ≤ γ"的 \((1-\delta)\) 保证。

- G1：抽样近似 join 有前序（LSH 近似 join、采样式集合 join），但"以**分类树 + 属性签名精确分层的已知层大小**驱动最优分配，并给出输出完备性保证"未见。风险：可能只是把分层抽样搬到 join 上。
- G2：L2（新设定下套用估计理论），除非能证明分配的最优性是该问题首次给出。
- G3：**强**。层大小精确已知 ⇒ 每层命中率可无偏估计 ⇒ Hoeffding/Bernstein 给统一置信界 ⇒ 在预算 B 下最小化遗漏期望是凸的 Neyman 分配，有闭式解与最优性证明。
- G4：实验可做，但需要"精确 vs 近似"两条线的公平定位；若只做近似，会偏离 `problem-formulation.md` 的 exact 要求。
- 结论：理论过，但改变问题定义，暂缓。

## 轮 3：把"完备性"做成精确算法的**证书**，不改变 exact 语义 — **G1/G3 均过，G2 = L1，G4 过（本轮的候选）**

核心转向：**不追求少算距离，而是追求"用可证下界判定整块为空"**。注意这与轮 0 的球界不同——球界用单球，本方案用**块对的精确最小距离下界**（而不是半径上界）。

### 机制（一句话）
对每个兼容块对 (ca, cb)，用一次性的 8 个枢轴距离为该块对算出下界 \(L(c_a,c_b)\)；若 \(L>\varepsilon\) 则整块为空，一条边都不用算；否则对块内 pair 用同一批枢轴距离做逐对下界判定，仍不能判定的才精算距离。块对的枢轴距离可由每个对象的 p 个枢轴距离**复用**，不增加距离调用。

### G1 新颖性
- ε-kdB-tree / EGO：块来自**几何**网格或排序，谓词不存在；
- M-tree join / eD-index：块来自**度量树**，谓词不存在；
- 本方案：块来自**谓词**（品类可比 × 属性签名），枢轴下界**跨谓词块复用**，且枢轴距离按对象缓存一次。
- 差别维度：分块依据（谓词 vs 几何）、下界复用面（跨块 vs 块内）、维护（新增对象只更新本块与 p 个枢轴距离）。
- 待核：是否已有"predicate-partitioned pivot filtering"的论文。

### G2 创新性
L1 候选。判据：若定理 1 成立（见 G3），机制本身改变结论（下界可跨块复用这一事实使谓词分块从"无效"变为"有效"），而不只是参数调整。

### G3 理论有效性
1. **定理 1（下界单调复用）**：对任意块对 \(B=(c_a,c_b)\)、任意 pair \(x\in B\)，
   \(d(x,y)\ \ge\ \max_i |d(x,p_i)-d(y,p_i)|\ \ge\ \max_i |\mu^{(a)}_i-\mu^{(b)}_i|-\operatorname{rad}^{(a)}_i-\operatorname{rad}^{(b)}_i\)，
   其中 \(\mu,\operatorname{rad}\) 为块内枢轴距离的均值与最大偏离。因此块级下界可由**块内枢轴距离摘要**给出，摘要大小 \(O(p)\) 与块内对象数无关，可跨所有含该块的查询复用。
2. **定理 2（可行性条件）**：块对下界有效当且仅当 \(\operatorname{rad}^{(a)}_i+\operatorname{rad}^{(b)}_i< \mu^{(a)}_i-\mu^{(b)}_i-\varepsilon\)。给出该条件在独立同分布下的期望违反概率，并据此预测块级剪枝率随块规模、p、ε 的变化。
3. **定理 3（代价界）**：总距离调用 ≤ \(p(|A|+|B|)+|\{(x,y): L(x,y)\le\varepsilon,\ \text{predicate-ok}\}|\)。即精算次数被"下界通过者"的数量控制，而枢轴开销是一次性 \(p(|A|+|B|)\)。
4. 可证伪预测：若实测块级剪枝率显著低于定理 2 的预测，模型错。

与轮 0 的关键区别：轮 0 用**半径上界**判整块（需要 \(r\le\varepsilon\)，实测不可能）；本轮用**枢轴下界的最大值**判整块，只要求"块内枢轴距离的离散度小于枢轴间的分离度"，这在**谓词块内对象几何分散**时可能反而成立（谓词块与几何无关 ⇒ 块内分布接近全局，枢轴分离度大）。

### G4 长论文承载力
贡献可列成四条：语义订正（通配使 PPJoin 族失效，定理 0）＋ 谓词块枢轴下界（定理 1–3）＋ 成本模型（四段分解 + 三个比值）＋ 负结果（球界无效；100:1 冗余不可由下界消除的部分）。基线：B0/B2 + 移植 ε-kdB-tree 或 EGO 作为几何侧对手。实验矩阵：n ∈ {40k, 200k}、ε 分位 5 档、缺失率 3 档、块规模 2 档。

### 仍需先核的风险
1. 是否已有 predicate-partitioned pivot filtering（G1 的关键）。
2. 定理 2 的可行性条件在本数据上是否真的成立——**这条可以用解析数算**：块内枢轴距离的离散度 vs 枢轴间分离度，不需要跑性能实验。

## 轮 3 结论：**G1 未过（已被做穿），G3 实测无效** — 否

对抗核验（`novelty-auditor`）给出的阻断项：

| 前序 | 覆盖了什么 |
|---|---|
| **PEXESO**（ICDE 2021，DOI 10.1109/ICDE51399.2021.00046） | 分组 + 枢轴过滤 + **块对（group-group）剪枝** + 一次映射反复复用；50–300 维真实嵌入，报告最高 76× |
| **LTC / List of Twin Clusters**（SISAP'08 / JDA 7(1), 2009） | 块级半径式下界 `|D(ca,cb) − d(a,cb)| ≤ Ra + r` + 块距离矩阵复用 |
| **PM-tree**（ADBIS'04 / DEXA'05） | 节点级枢轴**超环区间**摘要，界比"均值±半径"更紧 |
| eD-index（DEXA'03） | 桶内按枢轴排序 + 滑窗下界，跨窗口复用同一批枢轴距离 |
| MISP（学位论文 2019）、SIEVE（PVLDB'25）、Filtered-DiskANN（WWW'23） | 按类别/谓词切块后放度量子索引 |

结论：轮 3 的"谓词分块 + 枢轴块摘要 + 跨块复用"三件事分别都有前序，且下界形式严格弱于 PM-tree 与 PEXESO。只剩"分块键是品类祖先对 × 属性签名"这一设定差异，**不构成新机制**。

### 我们自己测到的数值（含一次方法学勘误）

- **勘误**：平方 L2 上三角不等式不成立，`|S(a,p) − S(b,p)|` 不是合法下界（实测误剪率 0.7%–3.7%）。必须先开方再取界。
- 修正后（枢轴距离从原始向量直接算，避免用 A×B 矩阵冒充 B×B；误剪率 **0**）：

| 枢轴数 | 1% 分位剪枝率 | 5% 分位剪枝率 |
|---:|---:|---:|
| 8 | 8.8% | 1.2% |
| 16 | 22.0% | 6.4% |
| 32 | 30.4% | 11.4% |

即逐对枢轴过滤最多省约 30% 的距离调用（≈1.4× 总时间），且这正是 LAESA/eD-index 的既有能力。**块级下界在本数据上按块半径可达 0**（块内枢轴距离半幅与全局同量级）。

**判定：几何剪枝这条线关闭。** 它既被前序占满（PEXESO/LTC/PM-tree），实测上限也仅 1.4×。

## 轮 4（待核）：谓词分层的完备性保证连接

### 机制（一句话）
把兼容 pair 空间按"品类祖先对 × 属性签名"切成层，层的大小由树与 posting **精确算出**（无需扫描）；在总预算 B 下按 Neyman 最优分配抽取层内 pair 并精算距离，输出保证"未返回的真实 pair 占比 ≤ γ"（置信度 1−δ）。

### 待核的三点
1. 抽样近似 join 的前序（LSH 近似 join、采样式 join 规模估计 JOSIE、近似集合 join）是否已含"分层 + 最优分配 + 完备性 δ 保证"；
2. "层大小可由谓词结构精确得到"这一点是否已被用作分配依据；
3. 是否存在同类结论（分配等价于带约束的凸问题，闭式解）。

### 已知风险
- 改变 exact 语义（需与 `problem-formulation.md` 对齐，或明确为"双模式算子"）；
- 若前序已有"sampling-based similarity join with guarantees"，则退回 L2，需再改。

## 轮 5：面向该算子的代价最优计划选择（先过门，未验证）

轮 3 把"几何剪枝"这条线关掉了：上限 ~1.4×，且前序占满。剩下的差别不在"用不用索引"，而在**三个归约杠杆的先后**——品类（树）、属性（签名）、几何（ε）。B1–B4 基线的本质差异正是这个顺序，而它们从未被统一比较过。

### 机制（一句话）
先用**只碰直方图、不碰 pair**的算法精确算出三个基数（品类兼容 pair 数、品类∧属性兼容 pair 数、每个块的签名分布），再由闭式代价函数在 {属性优先, 品类优先, 向量优先} 三个计划中选择最便宜者执行。

### 关键理论点（G3）
1. **引理 1（精确基数、免枚举）**：设每个块 (c_a,c_b) 带签名直方图 \(h\), 则
   \[
   |\text{cat∧attr}|=\sum_{(c_a,c_b)\ \text{compatible}}\ \sum_{s_a\asymp s_b} |\text{Local}_A(c_a,s_a)|\cdot|\text{Local}_B(c_b,s_b)|,
   \]
   其中 \(s_a\asymp s_b\) 表示签名在共同已知维度上一致。计算代价 \(O(\#\text{blocks}\times\#\text{signatures})\)，**与 pair 数无关**。
2. **引理 2（代价单调）**：若 \(c_{\text{dist}}\gg c_{\text{pred}}\)（实测 67 ns vs ~5 ns），则计划代价由"执行到距离阶段前保留的 pair 数"单调整定；由此三个计划可在一个标量上比较。
3. **定理（计划分离）**：存在数据集族使最优计划与最差计划相差 \(\Theta(|A||B|)\)，且选择所需的工作量严格小于执行任一计划的代价（因为选择只读直方图）。给出构造与证明。
4. **可证伪预测**：模型预测的最优计划与实测最优计划一致率 ≥ 90%；若 ≤ 70%，模型不可用。

### G1 新颖性
- 代价模型与计划选择：System R 以来是经典（join order），空间连接也有代价模型；但对"拓扑可比较品类 × 通配属性 × 阈值向量"这个谓词类，**没有**计划选择工作。
- "精确基数免枚举"这一引理依赖谓词的结构（树 + 签名），在传统空间 join 里不存在对应物。
- 待核：是否有 filtered/similarity join 的计划选择或自适应执行（adaptive query processing）工作覆盖。

### G2 创新性
L1 候选，条件是定理（计划分离）成立且引理 1 被用作选择信号——不是"加了个优化器"，而是"该算子存在一个免执行的代价判定"。

### G4 长论文承载力
四条贡献：①免枚举基数引理；②计划分离定理；③代价模型与实测校准（四段分解 + 三个比值）；④负结果（几何剪枝不是主杠杆，1.4× 上限）。基线：B0/B2 + 移植 ε-kdB-tree 或 EGO 作为几何侧对手 + 三个计划臂。实验矩阵：n × ε 分位 × 缺失率 × 块规模。这构成一篇分析+系统型长文的基本盘。

### 风险
- 可能被判"只是 cost-based optimizer 的一个实例"；缓解：必须把"免枚举基数"和"分离定理"作为主结果，计划选择只是应用。
- 若前序已有 self-tuning / adaptive filtered join，需退回轮 4。

## 轮 5 结论：**G2 未过（L2），且被一条上限定理判死** — 否

### 新颖性核验（对抗）
阻断项：`Filtered ANN as a Phase Transition`（arXiv:2606.16341，预印本）已给出"闭式代价 + 分计划 + 相位边界 + plan regret"；`When Does q-error Predict Plan Regret?`（arXiv:2606.15600，预印本）给出 MSO/κ 计划分离度量；`Instance Optimal Join Size Estimation`（LAGOS 2021，已发表）占据"免执行的 join 规模判定"；`Similarity Join Size Estimation using LSH`（PVLDB 2011，已发表）与 TKDE 2019 已把"先估后跑"写进动机；NPRR（2012）与 Leapfrog Triejoin 已给出"计划族渐近分离"的定理。

另一条反对意见来自 ADOPT（PVLDB 2023，已发表）：它**放弃**执行前选择，理由是执行前估计不可靠，改用多 episode 试探。也就是说我们主张的方向在文献里正被反向论证。

### 更要紧的：这个方向有硬上限

对**精确**阈值连接，任何计划都必须对"谓词已兼容"的每一对计算距离（否则无法判定 ≤ε）。因此计划选择只能省**谓词阶段**，不能省距离阶段。

实测分解（B2，200 查询）：总 1.712 s = 生成 0.006 + 谓词 0.251 + 距离 1.042 + 输出统计 0.413。

- 谓词阶段归零 ⇒ 1.461 s ⇒ **1.17× 上限**；
- 再叠加"枢轴过滤砍 30% 距离" ⇒ 约 1.4 s ⇒ **1.22×**；
- 两者都做到极限 ⇒ **≤1.5×**。

**定理（本算子的计划上限）**：对精确阈值连接，若代价模型只使用谓词侧基数（不含 ε 相关的量），则最优计划与最差计划的比值不超过 \((T_{\text{dist}}+T_{\text{out}}+T_{\text{gen}}+T_{\text{pred}})/(T_{\text{dist}}+T_{\text{out}}+T_{\text{gen}})\)，在本实例上为 1.17。

结论：轮 5 不是"能不能写"的问题，是**它最多值 1.17×**。放弃。

## 轮 4 细化（唯一未封顶的方向）：预算受限、可认证的输出

### 已在本数据上验证的引理（T1）
用"品类×签名"完备频数立方（degenerate cube）直接算：

| 量 | 公式计算值 | 逐对枚举值 | 一致 |
|---|---:|---:|:--:|
| 品类兼容 pair | 12,997,075 | 12,997,075 | ✓ |
| 品类∧属性兼容 pair | 3,056,627 | 3,056,627 | ✓ |
| 兼容块数 | 2,402 | 2,402 | ✓ |

签名类数：A 侧 814、B 侧 816（可能 819）。计算耗时 1.6 s（纯 Python），**不触碰任何 pair**。

这条说明：本算子的**谓词部分**存在免枚举精确基数；这也是与"抽样估计"的分水岭——我们不需要估计它，只需要估计 ε 相关的那部分。

### 设计（三阶段）
1. **精确层**：由 T1 得到每个块 (c_a,c_b,s_a,s_b) 的精确规模与精确兼容性；不可兼容的直接删除，不做任何采样。
2. **试点层**：对每个块均匀抽 \(n_0\) 对算距离，得命中率估计 \(\hat p_b\) 与方差。
3. **分配层**：在预算 \(B\) 下按 Neyman 分配 \(n_b\propto N_b\sqrt{\hat p_b(1-\hat p_b)}\)，用经验 Bernstein + 联合界给出"遗漏率 ≤ γ 的概率 ≥ 1−δ"。

### 待证的四条（G3）
- **T2（分配最优）**：在 \(\sum n_b\le B\) 下最小化期望遗漏，Neyman 分配为最优，闭式。
- **T3（完备性保证）**：给出 \(P(\text{漏检率}>\gamma)\le\delta\) 的显式表达式，并把 \(B\) 与 \((\gamma,\delta)\) 的关系写成可反解的形式（给定 γ、δ 反求预算）。
- **T4（与 size estimation 的区别）**：JOSIE / LSH-SS 估的是**规模**；这里层规模已知且精确，未知的只有层内命中率。给出"当层内同质时方差为 0"的命题——即该方案在谓词分层充分时**不需要任何抽样**，这是与既有估计方法的可分离差异。
- **T5（不可约性）**：证明不存在只依赖谓词基数的预算分配能保证 γ，必须依赖 ε 相关的采样结果。这条把轮 5 的失败转化为轮 4 的动机。

### 风险（写进 G1 待核清单）
1. 前序可能已有"sampling-based approximate similarity join with error guarantee"（如 Aumüller 等的近似 join 修复工作）；
2. 三阶段分配可能与"两层抽样/自适应分配"的经典结果重合；
3. 若审稿人要求 exact 语义，本方案只能作为"双模式算子"的一部分。

## 轮 4 结论：**G2 未过（L1 已死，仅 L2）** — 否

阻断项：**BaS**（`arXiv:2603.16153` / PACMMOD 4(3), 2026，`DOI 10.1145/3802004`）已在"join 交叉积上分层 + 预算最优分配 + 高置信保证 + TopK 集合级 recall"整条线上做完，且层界是**优化出来的**（比我们的确定性层界更一般）。另有 CPSJOIN（ICDE'18，输出带 recall 保证）、Joins on Samples（PVLDB 13(4)，混合抽样族的方差下界）、Optimized Stratified Sampling（TODS 2007）、LSH-SS（PVLDB 2011）。

审计同时给出三条会打脸的细节（必须写进 limitation）：
1. Neyman 分配里的 \(\sigma_h\) 未知，用同批样本 plug-in 会破坏标称 \(1-\delta\)（BaS 用两阶段 pilot + bootstrap 补这个洞）；
2. "未返回真实 pair 占比"是比值型估计量，分母本身是估计，\(p_h\to0\) 时正态近似失效（Joshi & Jermaine ICDE'08 已证低选择率分层不可靠）；
3. 若抽样单位取成 posting 而非 pair，有效样本量按设计效应 \(1+(m-1)\rho\) 缩水。

剩余 delta 只是："层由品类祖先对 × 属性签名**确定性**切分、层大小由树 + posting **精确计数**、通配语义下长度/前缀过滤订正"。属 L2。

## 轮 6（待核）：层级目录维护下的连接结果增量维护

### 机制（一句话）
当目录发生 MOVE/MERGE、或对象的品类/属性值改变时，只有位于该子树祖先链上的兼容块才可能改变；据此维护兼容 pair 集合与其距离结果，避免全量重算。

### 为什么可能未被占
- 已核的前序：动态/流式相似 join 有（Adaptive MapReduce Similarity Joins, BeyondMR'18；TKDE'20 流式规模估计），但**触发源是数据插入/流**，不是**目录拓扑变更**；
- TrieHI 的 DSM 是检索侧维护（单查询 top-k），不产出 pair；
- EMA 维护的是过滤 ANN 索引，不产出 pair。
- 因此"谓词结构本身的变更"作为增量触发源，可能是空白。

### 可证的（G3 草案）
- **引理**：MOVE(u,w) 只改变满足 \(c\in \mathrm{Anc}(u)\cup\mathrm{Desc}(u)\) 的品类参与的可比较关系；其余块对的兼容性与规模不变。
  ⇒ Δpairs ⊆ 以受影响品类为一侧的块对并集，规模可由 posting 计数**精确算出**。
- **定理（局部性）**：单次 MOVE 的重算代价 ≤ \(O(\sum_{c\in\mathrm{chain}} |\mathrm{Local}(c)|\cdot|\mathrm{Local}(\cdot)|)\)，与总规模无关；给出与全量重建的比值界。
- **推论**：维护代价与 ε 无关（只有新出现的兼容对需要算距离），因此高频维护下摊薄。

### G4 草案
实验：churn 率 0→100%（MOVE/MERGE/属性变更三种事件），报每次事件的重算 pair 数、距离调用、墙钟、与全量重建比；对比 TrieHI-DSM（检索侧）与全量重建。理论 + 系统 + 实验，可成长文。

### 风险
1. 动态相似 join 可能已有"谓词变更"版本（待核）；
2. 若审稿人认为"目录变更"是稀有事件，动机不足 → 需用真实目录变更（CCS 版本演进、SciHTC 目录维护操作 2,000 条已生成）撑住。

## 轮 6 结论：**G2 未过（仅 L2）** — 否，但留下一条 L1 缝隙

阻断项：
- **TrieHI §IV-A（MOVE）**："removes S from inclusive ids on old-only ancestors and adds S to new-only ancestors … **independent of the number of descendant directory keys**" —— 轮 6 的"祖先链局部性"机制表述与其重合；
- **IVM 侧定理类型**：LMCS 19(3:11) 的 worst-case optimal update time、arXiv:2606.07795v2 的"p-hierarchical α-acyclic 查询摊还更新时间为常数"，使"维护代价与总规模无关"这一类定理不再新颖。

审计给出的**唯一未被覆盖处**（原文）：MOVE 把子树 S 从 A 移到 B 时，pair 增量不只是 S 内部与 S 的祖先链，还包括
- **S ×（旧祖先独有子树）** 的**失效对**，
- **S ×（新祖先独有子树）** 的**新生对**。

TrieHI 的 S 是 entry-ID 集合的搬移，**从未涉及对侧集合**；ALJoin 与 ICALP'21 都**没有树可跨**。

## 轮 7：“跨边界 pair delta”定理（L1 候选，最后一搏）

### 主张
给出目录编辑（MOVE/MERGE/属性变更）下 **pair 级**增量 ΔR 的**精确刻画**与**规模界**，并证明该规模**只由受影响边界的 posting 计数决定**，与两侧总规模无关；据此得到"维护代价与 ε 无关"的增量算法。

### 与 TrieHI 的区别（必须写死）
| | TrieHI DSM | 轮 7 |
|---|---|---|
| 被搬对象 | 单侧的 entry-ID 集合 S | **双侧** pair 集合 |
| 变化源 | 祖先链上的聚合集 | 祖先链 **∪ 跨边界子树对** |
| 产出 | 作用域集合（喂给 top-k） | **pair 集合 + 距离结果** |
| 代价 | 与后代键数无关 | 与总规模无关，但**与边界子树基数的乘积相关**（这条必须如实写，否则会被指为错误） |

### 要证的
- **T1（delta 刻画）**：\(\Delta R \subseteq [\mathrm{Desc}(u)\times(\mathrm{Anc}_{\text{old}}\text{独有})\cup(\mathrm{Anc}_{\text{new}}\text{独有})]\) 及对称项，且为并集分解、互不重叠。
- **T2（规模可精确计数）**：\(|\Delta R|\) 由 block 直方图精确算出（本轮已验证：12,997,075 与 3,056,627 与逐对枚举完全一致）。
- **T3（ε 无关）**：只有 \(\Delta R\) 中新增的兼容对需要算距离；失效对直接删除。⇒ 单次编辑的距离调用 = 新增兼容对数。
- **T4（下界）**：存在编辑使 \(|\Delta R|=\Theta(|A||B|)\)（构造：MOVE 到根的另一侧），因此任何宣称"严格与总规模无关"的定理都是错的——**这条把我们与 TrieHI 的错误类比隔开**。

### 为什么仍可能过 G1
IVM 的 delta 规则能机械推导 eq-join 的增量，但：①MOVE 是**目录关系本身的变更**，不是数据元组变更，需要重算可比性而非连接键；②对侧、双向上界与 ε 无关性三者组合未见。**若审稿人认为这只是 IVM 的应用，则退回 L2。**

## 轮 8：归约定理——解释为什么前七轮必然失败

### 定理（谓词层是一个合取查询）
把两侧的祖先路径物化为关系
\[
\mathrm{Path}_A=\{(a,c):c\in\mathrm{Anc}(c_a)\},\qquad \mathrm{Path}_B=\{(b,c):c\in\mathrm{Anc}(c_b)\},
\]
则品类可比较等价于
\[
\mathrm{CatCompat}(a,b)\iff \exists c:\ (a,c)\in\mathrm{Path}_A\wedge(b,c)\in\mathrm{Path}_B\ \vee\ \text{（对称项：}\exists c:(b,c)\in\mathrm{Path}_A\wedge(a,c)\in\mathrm{Path}_B\text{）},
\]
属性兼容是逐维的等值或通配，可写成对 \(\mathrm{Attr}\) 关系的等值连接 + 通配谓词。于是整个算子为
\[
\mathrm{Ans}=\sigma_{\,d(a,b)\le\varepsilon}\Big(\mathrm{Compat}\big(\mathrm{Path}_A,\mathrm{Path}_B,\mathrm{Attr}_A,\mathrm{Attr}_B\big)\Big).
\]

### 推论（为什么七轮都被前序吃掉）
1. 谓词侧的**一切**结构化机制（分块、局部性、增量、计划选择）都是这个合取查询上的**连接顺序 / 视图维护**问题；
2. 因此"品类分块"≡ 连接顺序，"MOVE 的祖先链局部性"≡ 增量视图维护，"免枚举基数"≡ 基数估计，"分层抽样"≡ 近似查询处理。四类前序分别对应这四件事，且都已成熟。
3. 唯一不属于关系层的是 `d(a,b)≤ε` 这个 UDF，而它正是经典阈值连接的对象。

**结论：在原问题（精确全对枚举）的谓词侧不存在 L1 机制；这是可证的结构性原因，不是检索不足。**

## 轮 9（唯一可能过 G1 的重构）：非对称"最近兼容邻居"

### 问题重构
原式输出 \(A\times B\) 中所有满足条件的对；改为：对每个 \(a\in A\)，输出**距离最近的兼容** \(b\)（per-row top-1），即
\[
f(a)=\arg\min_{b\in B,\ \mathrm{CatCompat}(a,b)\wedge \mathrm{AttrCompat}(a,b)} d(a,b).
\]
输出规模 \(O(|A|)\)，不是 \(O(|A||B|)\)；这是跨平台对齐的实际需求（"给 A 侧每个商品找最佳对照"）。

### 为什么可能未被占（待核）
- **与 filtered ANN 的区别**：filtered ANN 的谓词作用在**被检索对象自身**（label∈集合）；这里的谓词是**对关系**（品类可与 a 比较 ∧ 属性与 a 兼容），查询侧与对象侧不对称，**不能**退化成单侧过滤。
- **与 join 的区别**：不枚举全对，无输出爆炸；也不等于对 a 做一次普通的 filtered kNN。
- **与"每概念 top-k 再合并"的区别**：比较集是 \(\bigcup_{c\in \mathrm{Anc}(c_a)\cup\mathrm{Desc}(c_a)}\mathrm{Local}_B(c)\) 与属性兼容集的**交**，不是单概念子图。

### 可能的理论点（G3 草案）
- **T1（可比集结构）**：比较集 = 路径并 \(\cup\) 子树并 \(\cap\) 属性相容集；给出其大小与"最近邻落在哪个分支"的界。
- **T2（分支定界正确性）**：若对每个分支有质心底界（到分支代表的下界），可按分支优先级搜索，给出**精确**的 top-1 证书（第一个被证明优于所有未展开分支下界的候选）。
- **T3（代价界）**：总距离调用 ≤ \(\sum_{\text{visited branches}} |\text{sampled}|\)，并与"单张全局图 + 掩码"对比的上界。
- **T4（与 filtered ANN 的分离例）**：构造数据使"把谓词近似为对象侧过滤"的任一方法必错（因兼容性依赖 a 的品类路径），而本方法正确。

### 风险
1. 可能已有"per-row nearest neighbor join with predicates"或"retrieval with query-dependent candidate sets"；
2. 若判为 L2，仍需靠 T4 的分离例与系统实现撑。

### 下一步
派 `novelty-auditor` 核验：nearest neighbor join / constrained kNN / per-row retrieval with pair predicates / filtered ANN 的 query-dependent candidate set。

## 轮 10（收敛方案）：开放世界语义下的连接——语义、必要统计、与不可优化边界

不做"更快"，做**这个算子本身**。四条贡献，全部可核：

### C1 算子与语义（新设定，L2）
拓扑可比较品类 × 通配 facet × 阈值枚举；给出形式定义、合格集构造、与 filtered ANN / similarity join / structural join 三者的**不可互化**说明（谓词是对关系、schema 逐对可变）。

### C2 schema 分解定理（可证）
按"定义模式"（哪个维度已知）把 pair 空间切成互不相交的部分：设维度数 \(k\)，则
\[
\mathrm{Ans}=\bigsqcup_{S\subseteq[k]}\mathrm{Ans}_S,
\]
每个 \(\mathrm{Ans}_S\) 是一个**固定 schema 上的等值连接 + 阈值谓词**。
⇒ 证明：开放世界语义下，连接可归约为 \(2^k\) 个封闭世界连接的不交并；\(k=3\) 时 7 个部分。
用途：每一部分都可用经典方法处理，且各部分的基数可由立方体精确得到（本数据已验证）。

### C3 统计的必要与充分（L1 候选，理论的落点）
- **充分**：给定 (品类 × 定义模式 × 取值) 的**完备频数立方**，任意部分基数与"属性兼容对"的基数**精确可算**（已在数据上验证：12,997,075 与 3,056,627 与逐对枚举完全一致）。
- **必要（否证性）**：只给逐属性边际（即标准独立性假设所需的统计量）时，通配语义下的连接基数**误差无界**——给出构造族：边际完全相同，而真实基数相差任意倍数。
  ⇒ 结论：标准基数估计器（含 System R 独立性假设、以及依赖固定 schema 的 filtered ANN 选择率模型）在该算子上**必然失效**；2^k 立方体不是"更好"，而是**必要**。
- **推论**：由 C3 + 轮 5 的上限定理，任何"用边际估计代替立方体来做计划选择"的方法都被双重否定。

### C4 不可优化的边界（三条已证的负结果）
1. **计划选择上限 1.17×**（本轮已证：精确 join 必须对每个谓词兼容对算距离）。
2. **几何剪枝上限 1.4×**（实测枢轴 30%；块级 ≈0）。
3. **近似保证已被占**（BaS）。

⇒ 该算子的可用优化空间被压缩到"统计 + 语义"，这本身是结论。

### 四门评估
| 门 | 判定 | 依据 |
|---|---|---|
| G1 新颖性 | **通过（限定于 C3）** | C1 设定未被占；C2 分解是新的（开放世界 × 成对谓词）；C3 的"必要性"未见同款；C4 是本轮自证 |
| G2 创新性 | **C3 = L1（理论）；C1/C2 = L2；C4 = L3** | 不写"新方法"，写"必要统计 + 分解定理 + 边界" |
| G3 理论有效性 | **通过** | C2 不交并证明、C3 充分性（已在数据上验证）与必要性（构造族）、C4（已证上限） |
| G4 长论文承载力 | **通过** | 理论 3 条 + 系统 1 条 + 实验矩阵（n、ε、缺失率、k）+ 强基线（B0/B2、移植 Quickjoin/Super-EGO） |

### 仍需一次核验（唯一未确认项）
"通配/空值语义下连接基数估计的必要统计"是否已有工作（Imieliński–Lipski 1984 是 null 语义的经典，但它是关系代数语义而非 join 基数估计）。**若已被做穿，C3 降为 L2，全篇退为"新设定 + 边界"，仍可成文但分量减半。**

### 与之前九轮的关系
前九轮试图在"精确加速 / 近似保证 / 计划选择 / 结构维护"里找机制，全部被前序占满（原因已由归约定理证明：谓词层是合取查询）。轮 10 不再找机制，而是把**该算子不可优化的部分证明清楚**，并把**唯一必要的统计结构**给出。这是七轮负面结果的自然归宿。

### C3 的实证半边（本轮实测，直接支撑"必要性"）

在同一份数据上对比三种口径：

| 口径 | 相容对数 | 相对真值 |
|---|---:|---:|
| **通配语义（定义的本算子）** | **3,056,627** | 1.00× |
| 封闭世界（两侧所有维度都已知且相等） | 19,014 | **0.0062×** |
| 仅用逐属性边际 + 独立性假设的估计 | 92,953,385 | **30.4×** |

两条读数：

1. **把未知当"缺失"（封闭世界）会丢掉 99.4% 的匹配**：19,014 vs 3,056,627，差 **160.8×**。这不是实现细节，是语义决定的——任何把通配当成"必须有值"的系统，在该算子上系统性漏答。
2. **只用逐属性边际的独立性估计高估 30.4×**：92.9M vs 3.06M。标准基数估计器（System R 独立性假设、以及依赖固定 schema 的 filtered ANN 选择率模型）在此不可用；误差不是几个百分点，而是 30 倍量级。

⇒ 支撑 C3 的两条主张：完备的 (品类 × 定义模式 × 取值) 立方是**必要**统计；边际不足。

⇒ 也解释了为什么"谓词选择性"不能用来选计划（轮 5 的上限 1.17×）：选择性本身无法从边际得到。

## 轮 10 结论：C3 已被做穿 — 理论侧 L1 也关闭

| 子主张 | 阻断者 | 状态 |
|---|---|---|
| 语义层"未知=通配，相容=共同已知维全等" | **Imieliński & Lipski 1984**（JACM 31(4):761–791，naive 表/可能世界语义） | 已有同设定 |
| "定义模式作分组维度" | Little 1993（pattern-mixture）、外连接 null-supplying side（TODS 1997） | 已有同类手段 |
| "仅边际不足" | **Robinson 1950**（JASA 15(3):351，列联表不可辨识）+ **ℓp degree-sequence bounds**（PACMMOD 2(2):96, 2024） | 已发表定理 |
| "精确计数" | **Arenas, Barceló, Monet**（PODS'20 / TOCL 2021）数 completion 的 #P 二分 | 地形已划定 |
| 组合（通配连接 + 定义模式立方 + 精确计数） | 未见直接前作 | 窄缝在工程侧，不在理论侧 |

⇒ C3 只能作为**动机引理**（必须引 1984 与 2024），不能作为理论贡献。

## 十轮之后的最终判定

**该问题内不存在可通过 G1–G4 的 L1 方案。** 这不是检索不足，而是可证的结构：

1. 谓词层 = 合取查询（轮 8 归约定理）⇒ 分块/局部性/基数/抽样分别等价于连接顺序、IVM、基数估计、近似查询处理，四类前序均已成熟；
2. 语义层 = naive 表语义（1984）；
3. 统计层 = 不可辨识性（1950/2024）；
4. 距离层 = 经典阈值连接（1975–2013），实测上限 1.4×；
5. 计划层 = 上限 1.17×（本轮自证）；
6. 近似层 = BaS（2026）。

### 能通过四门的唯一配置：L2 设定 + L3 证据 + 两条已证上限

| 门 | 判定 | 依据 |
|---|---|---|
| G1 | **通过（设定维度）** | "拓扑可比较品类 × 通配 facet × 全对阈值枚举"这一交集在 filtered ANN（全 top-k）、similarity join（无层级无通配）、NK join（单侧谓词）三处均未被占 |
| G2 | **通过（L2 + L3，不得写 L1）** | 措辞限定为"新设定下的系统与分析"，禁止"首次提出/新机制" |
| G3 | **通过** | 两条自证上限（计划 1.17×、几何 1.4×）+ 归约定理 + 三条实测比值 |
| G4 | **通过** | 设定 + 语义订正 + 成本模型 + 负结果 + 系统实现 + 可移植基线 |

### 论文骨架（五节）
