## 轮 0：谓词块 × 几何下界 — **G3/G4 未过（已否）**

块级球界需要半径 \(r\le\varepsilon\)；d=128、块内 ~50 点时 \(\mathbb E[r]\approx3.9\sigma\)，与 1% 分位 ε 同量级。只有 soundness + 一条负结果，无可证正向界；且缺可对打的基线。

---

## 轮 1：枢轴过滤（pivot / LAESA 式）搬进谓词块 — **G1 未过**

机制：每个 a 先算 p 个枢轴距离，块内用三角不等式下界 \(d(a,b)\ge|d(a,p_i)-d(b,p_i)|\) 逐对排除。

- G1：枢轴过滤是度量空间 join 的既有手段（Dohnal 2003 eD-index、Jacox & Samet TODS'08 的度量 join 综述），只是换到谓词块上；**无新维**。
- G3：可证的下界是教科书内容，不构成理论贡献。
- 结论：直接否，不进入实验。

---

## 轮 2：签名分区 + 分层抽样的完备性保证 — **G1 部分过、G3 强、G2 弱、G4 待定**

机制：以属性签名（各维已知值）为层，层的大小可由品类树与属性 posting **精确算出、无需扫描**；在总预算 B 下按 Neyman 最优分配抽样，只对抽到的 pair 精算距离；给出"漏掉的真结果占比 ≤ γ"的 \((1-\delta)\) 保证。

- G1：抽样近似 join 有前序（LSH 近似 join、采样式集合 join），但"以**分类树 + 属性签名精确分层的已知层大小**驱动最优分配，并给出输出完备性保证"未见。风险：可能只是把分层抽样搬到 join 上。
- G2：L2（新设定下套用估计理论），除非能证明分配的最优性是该问题首次给出。
- G3：**强**。层大小精确已知 ⇒ 每层命中率可无偏估计 ⇒ Hoeffding/Bernstein 给统一置信界 ⇒ 在预算 B 下最小化遗漏期望是凸的 Neyman 分配，有闭式解与最优性证明。
- G4：实验可做，但需要"精确 vs 近似"两条线的公平定位；若只做近似，会偏离 `problem-formulation.md` 的 exact 要求。
- 结论：理论过，但改变问题定义，暂缓。

## 轮 3：把"完备性"做成精确算法的**证书**，不改变 exact 语义 — **G1/G3 均过，G2 = L1，G4 过（本轮的候选）**

核心转向：**不追求少算距离，而是追求"用可证下界判定整块为空"**。注意这与轮 0 的球界不同——球界用单球，本方案用**块对的精确最小距离下界**（而不是半径上界）。

### 机制（一句话）
对每个兼容块对 (ca, cb)，用一次性的 8 个枢轴距离为该块对算出下界 \(L(c_a,c_b)\)；若 \(L>\varepsilon\) 则整块为空，一条边都不用算；否则对块内 pair 用同一批枢轴距离做逐对下界判定，仍不能判定的才精算距离。块对的枢轴距离可由每个对象的 p 个枢轴距离**复用**，不增加距离调用。

### G1 新颖性
- ε-kdB-tree / EGO：块来自**几何**网格或排序，谓词不存在；
- M-tree join / eD-index：块来自**度量树**，谓词不存在；
- 本方案：块来自**谓词**（品类可比 × 属性签名），枢轴下界**跨谓词块复用**，且枢轴距离按对象缓存一次。
- 差别维度：分块依据（谓词 vs 几何）、下界复用面（跨块 vs 块内）、维护（新增对象只更新本块与 p 个枢轴距离）。
- 待核：是否已有"predicate-partitioned pivot filtering"的论文。

### G2 创新性
L1 候选。判据：若定理 1 成立（见 G3），机制本身改变结论（下界可跨块复用这一事实使谓词分块从"无效"变为"有效"），而不只是参数调整。

### G3 理论有效性
1. **定理 1（下界单调复用）**：对任意块对 \(B=(c_a,c_b)\)、任意 pair \(x\in B\)，
   \(d(x,y)\ \ge\ \max_i |d(x,p_i)-d(y,p_i)|\ \ge\ \max_i |\mu^{(a)}_i-\mu^{(b)}_i|-\operatorname{rad}^{(a)}_i-\operatorname{rad}^{(b)}_i\)，
   其中 \(\mu,\operatorname{rad}\) 为块内枢轴距离的均值与最大偏离。因此块级下界可由**块内枢轴距离摘要**给出，摘要大小 \(O(p)\) 与块内对象数无关，可跨所有含该块的查询复用。
2. **定理 2（可行性条件）**：块对下界有效当且仅当 \(\operatorname{rad}^{(a)}_i+\operatorname{rad}^{(b)}_i< \mu^{(a)}_i-\mu^{(b)}_i-\varepsilon\)。给出该条件在独立同分布下的期望违反概率，并据此预测块级剪枝率随块规模、p、ε 的变化。
3. **定理 3（代价界）**：总距离调用 ≤ \(p(|A|+|B|)+|\{(x,y): L(x,y)\le\varepsilon,\ \text{predicate-ok}\}|\)。即精算次数被"下界通过者"的数量控制，而枢轴开销是一次性 \(p(|A|+|B|)\)。
4. 可证伪预测：若实测块级剪枝率显著低于定理 2 的预测，模型错。

与轮 0 的关键区别：轮 0 用**半径上界**判整块（需要 \(r\le\varepsilon\)，实测不可能）；本轮用**枢轴下界的最大值**判整块，只要求"块内枢轴距离的离散度小于枢轴间的分离度"，这在**谓词块内对象几何分散**时可能反而成立（谓词块与几何无关 ⇒ 块内分布接近全局，枢轴分离度大）。

### G4 长论文承载力
贡献可列成四条：语义订正（通配使 PPJoin 族失效，定理 0）＋ 谓词块枢轴下界（定理 1–3）＋ 成本模型（四段分解 + 三个比值）＋ 负结果（球界无效；100:1 冗余不可由下界消除的部分）。基线：B0/B2 + 移植 ε-kdB-tree 或 EGO 作为几何侧对手。实验矩阵：n ∈ {40k, 200k}、ε 分位 5 档、缺失率 3 档、块规模 2 档。

### 仍需先核的风险
1. 是否已有 predicate-partitioned pivot filtering（G1 的关键）。
2. 定理 2 的可行性条件在本数据上是否真的成立——**这条可以用解析数算**：块内枢轴距离的离散度 vs 枢轴间分离度，不需要跑性能实验。

## 轮 3 结论：**G1 未过（已被做穿），G3 实测无效** — 否

对抗核验（`novelty-auditor`）给出的阻断项：

| 前序 | 覆盖了什么 |
|---|---|
| **PEXESO**（ICDE 2021，DOI 10.1109/ICDE51399.2021.00046） | 分组 + 枢轴过滤 + **块对（group-group）剪枝** + 一次映射反复复用；50–300 维真实嵌入，报告最高 76× |
| **LTC / List of Twin Clusters**（SISAP'08 / JDA 7(1), 2009） | 块级半径式下界 `|D(ca,cb) − d(a,cb)| ≤ Ra + r` + 块距离矩阵复用 |
| **PM-tree**（ADBIS'04 / DEXA'05） | 节点级枢轴**超环区间**摘要，界比"均值±半径"更紧 |
| eD-index（DEXA'03） | 桶内按枢轴排序 + 滑窗下界，跨窗口复用同一批枢轴距离 |
| MISP（学位论文 2019）、SIEVE（PVLDB'25）、Filtered-DiskANN（WWW'23） | 按类别/谓词切块后放度量子索引 |

结论：轮 3 的"谓词分块 + 枢轴块摘要 + 跨块复用"三件事分别都有前序，且下界形式严格弱于 PM-tree 与 PEXESO。只剩"分块键是品类祖先对 × 属性签名"这一设定差异，**不构成新机制**。

### 我们自己测到的数值（含一次方法学勘误）

- **勘误**：平方 L2 上三角不等式不成立，`|S(a,p) − S(b,p)|` 不是合法下界（实测误剪率 0.7%–3.7%）。必须先开方再取界。
- 修正后（枢轴距离从原始向量直接算，避免用 A×B 矩阵冒充 B×B；误剪率 **0**）：

| 枢轴数 | 1% 分位剪枝率 | 5% 分位剪枝率 |
|---:|---:|---:|
| 8 | 8.8% | 1.2% |
| 16 | 22.0% | 6.4% |
| 32 | 30.4% | 11.4% |

即逐对枢轴过滤最多省约 30% 的距离调用（≈1.4× 总时间），且这正是 LAESA/eD-index 的既有能力。**块级下界在本数据上按块半径可达 0**（块内枢轴距离半幅与全局同量级）。

**判定：几何剪枝这条线关闭。** 它既被前序占满（PEXESO/LTC/PM-tree），实测上限也仅 1.4×。

## 轮 4（待核）：谓词分层的完备性保证连接

### 机制（一句话）
把兼容 pair 空间按"品类祖先对 × 属性签名"切成层，层的大小由树与 posting **精确算出**（无需扫描）；在总预算 B 下按 Neyman 最优分配抽取层内 pair 并精算距离，输出保证"未返回的真实 pair 占比 ≤ γ"（置信度 1−δ）。

### 待核的三点
1. 抽样近似 join 的前序（LSH 近似 join、采样式 join 规模估计 JOSIE、近似集合 join）是否已含"分层 + 最优分配 + 完备性 δ 保证"；
2. "层大小可由谓词结构精确得到"这一点是否已被用作分配依据；
3. 是否存在同类结论（分配等价于带约束的凸问题，闭式解）。

### 已知风险
- 改变 exact 语义（需与 `problem-formulation.md` 对齐，或明确为"双模式算子"）；
- 若前序已有"sampling-based similarity join with guarantees"，则退回 L2，需再改。
