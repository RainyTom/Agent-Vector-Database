# 属性频繁更新下的层级过滤 ANN：前序核实与可辩护窄缝

日期：2026-10-28。范围：目录/层级谓词约束下的单查询向量 top-k（DSQ）在**属性频繁变化**时的索引维护与召回保持。**本轮只做文献核实与方案设计，不实现、不运行实验。**

## 0. 结论

1. **方向成立，但“属性可更新所以不用重建 ANN”已经不新，而且比预想更拥挤。** 数值 range 谓词下的动态索引至少已有 DIGRA、RangePQ+、DSG/ESF、Peng 等 PVLDB 18(10) 工作；一般属性（数值+类别混合、布尔组合）的动态更新已有 EMA，并报告了更新吞吐与 patch/rebuild 阈值。因此“解耦 ANN 与可变属性索引”只是基线，不是贡献。
2. **你给的第一条链接指向了另一篇论文。** `arxiv.org/abs/2604.22171` 是 **MCI: A Maximal Clique Index for Efficient Arbitrary-Filtered ANNS**（Ye, Li, Wang, Xue, Wang, Li），不是 “Filter Index Updates”。不过你的**实质判断在该文里确有依据**：MCI Table 1 的 “Upd.” 列把 Filtered-DiskANN 标为 **✗**，表注为“feature values … can be updated after index construction without rebuilding”。同时 EMA Table 1 却把 Filtered DiskANN 标为 **Dynamic ✓**。两篇 2026 年论文对同一事实判断相反，这条冲突本身值得记录，不能单方面引用。
3. **剩下最窄的缝隙是谓词形状，不是“更新”本身**：上述动态工作覆盖 flat range 与 flat label set；**层级/前缀（祖先闭包）谓词 + 频繁 MOVE/重标注 + 查询期快照一致性**在已筛范围内没有对应工作。这恰好是本项目已有实测对象（TrieHI MOVE、HLG 连接边维护、DFS 区间布局）。

**判定**：把“属性更新”当作创新点会被上述工作直接覆盖。可辩护的差异必须落在**谓词代数（laminar 祖先闭包）**、**更新传播范围（树高 vs 全图）**、**快照正确性**三者之一或其组合，并用同预算实测支撑。

两个直接推论：

- **重建成本极不对称**：属性/层级更新若触发全局图重建，代价与“只改元数据”相差两个数量级以上。这正是“更新频繁时应避免重建”的量化理由，而不是修辞。
- **我们自己的加速器已经踩到更新问题**：scope-run 依赖 DFS 连续区间，MOVE 一次就失效。这条不是文献缺口，而是本项目已记录的实现缺口——可直接作为问题动机。

## 3. 修订后的问题定义

数据集 $x_i=(v_i, A_i, \sigma_i)$，其中 $A_i$ 为多属性取值，$\sigma_i\subseteq V$ 为对象绑定的目录节点集（单绑定场景 $|\sigma_i|=1$）。

查询：$(q, u, \text{rec}/\text{nrec}, k, \rho)$，要求返回 $\mathcal D_u$ 中距离最近的 $k$ 个对象，且平均召回不低于 $\rho$。

更新流：属性改值、标签增删、层级 MOVE/MERGE、向量替换，各自有到达率 $\lambda$。

系统须同时满足（四条，缺一不可）：

1. **不重建全局向量索引**即可让更新可见；
2. 查询读到**一致的属性版本**（不返回已不符合谓词的旧记录，也不漏掉已符合的新记录）；
3. 更新累积后，过滤后 ANN 的 recall/延迟**不随时间单调劣化**，或劣化有可证界；
4. 维护成本可计入固定内存与给定压实预算。

与既有工作的语义差别：这里的谓词是**祖先闭包**（`Desc+`），不是 flat range 也不是 flat label set；而范围谓词天然有序、便于分段，层级谓词天然可加性聚合、便于**局部传播**。这个结构差异是唯一可辩护的立足点。

## 4. 对原六方向的逐项裁定

| 方向 | 裁定 | 理由 |
|---|---|---|
| ANN 与可变属性索引解耦 | **降级为基线** | 这是 pre/post/in-filter 的标准分层；EMA/MCI/ACORN 都以此为前提。解耦本身不构成贡献 |
| LSM / Base+Delta | **可作执行层，不作为贡献** | Base+Delta + 压实是通用存储技术；EMA 的 patch/rebuild 已是同一族策略的实例。差异必须来自“层级属性下压实粒度” |
| 版本化 posting / 位图 | **保留为机制候选** | 现有动态工作多用标记/惰性删除，未强调**查询快照**；可做“版本化祖先聚合 + 快照读”，但需先证并发语义可测 |
| 过滤感知图搜索与动态入口 | **高风险** | 需要把谓词信息放进图结构（EMA 已做边级 Marker），一旦放进去就回到“更新要改图”；除非只维护极少量可更新入口 |
| 动态层级属性索引 | **最匹配** | 树高 $h$ 的祖先传播 vs 全图传播，是本项目可测的差异；且我们已有 MOVE 计时工具 |
| 更新负载自适应物化 | **降级** | 与已否证的“按选择率切换索引”同族；除非限定为“按更新率选择传播策略”，且要有硬预算 |

## 5. 收敛后的最小设计：可撤销的祖先聚合

**问题**：EMA 类方案用 **OR** 把属性位并入边/邻域摘要。OR 是单调的：属性被**删除或改值**时无法回收已置位。因此假阳性只会增加，只能靠周期性全量重建复位——这是其“50% 阈值重建”的结构性原因。

层级谓词给出一个更好的结构：对象绑定的目录节点只有一个（单绑定），属性变化对**祖先聚合**的影响是**沿一条路径的加减**，而不是全图摘要的单调累积。

**设计（未实现）**：

- 每个目录节点 $a$ 维护 posting（或 Roaring 位图）与**引用计数**；对象的标签/属性变化时，只更新其绑定节点路径上的祖先（$O(h)$ 个节点），计数减一即精确撤销，不残留假阳性。
- 查询 scope 直接读祖先聚合；`nrec` 读本地集合。无需为每次更新触碰向量图。
- 与 HLG 连接边解耦：连接边只保证可达性，不携带属性；属性更新不改变连接边，故不触发图维护。
- 版本化：每次更新写全局 epoch；查询在入口快照 epoch，读该 epoch 的聚合视图（或允许 epoch 内的可见性延迟并在结果中声明），保证不返回过期记录。

**与 EMA 的可测差异（预测，非结论）**：

| 维度 | EMA 类（边级 OR 摘要） | 本设计（祖先引用计数） |
|---|---|---|
| 属性删除/改值 | 无法回收位，假阳性单调累积 | 计数减一，精确撤销 |
| 更新触碰范围 | 一跳反向边的 Marker（$O(M)$ 条边） | 一条祖先路径（$O(h)$ 个节点） |
| 复位机制 | 阈值触发 patch / 全量重建 | 无需复位；除非计数与真实集合失配（可用审计发现） |
| 空间 | $O(nM\cdot sm)$ 边摘要 | $O(\sum_a |\text{posting}(a)|)$ + 计数 |

**必须同时承认**：引用计数 posting 是信息检索的常规技术；TrieHI 本身就维护祖先聚合。所以本设计的可辩护增量只能是：(a) 把“撤销正确性”与“更新率”作为一等指标量化；(b) 证明在层级谓词下更新传播范围的界（树高而非全图）；(c) 快照一致性的可测协议。**任一项做不到，就只是 TrieHI 的复述。**

## 6. 否证条件与必须报告的指标

| 编号 | 问题 | 否证条件 |
|---|---|---|
| U1 | 更新传播是否真的只有 $O(h)$ | 实测更新触碰节点数随 $h$、$n$、扇出的增长；若随 $n$ 增长则设计错误 |
| U2 | 撤销是否消除假阳性累积 | 纯 OR 方案的 recall/QPS 随 churn 单调下降，而引用计数方案保持平稳；若两者都平稳，则撤销无价值 |
| U3 | 更新后查询是否返回过期记录 | 并发更新 + 查询的越界/漏检必须为 0；出现一次即不通过 |
| U4 | 是否需要重建才能维持召回 | 在固定 churn 比例（如 20%/50%）下，不重建仍达目标召回；否则记录所需重建频率 |
| U5 | 是否比 EMA 类更强 | 同内存、同召回下的更新吞吐与查询 p95；若打平，则无独立贡献 |

指标必须包含：更新吞吐（ops/s，按操作类型分）、更新的 p50/p95、查询 recall（macro 与 global pair 分开）、查询 p95、峰值 RSS、重建/压实累计耗时、以及**churn 曲线**（横轴累计更新比例，纵轴 recall 与 QPS）。

**质量门槛沿用冻结 harness**：recursive macro/global ≥ 0.999、non-recursive recall = 1（精确型变体要求全 GT 命中）。不因引入更新而降低。

## 7. 与现有计划的关系

- **不改变 HLG 的优先级**：G1/G2 仍待用户执行，仍按原门槛判定；本方向复用 `hlg_tool move` 的计时与 overlay 结构，不新开一套。
- 本方向与 HLG 共享一个对象：**目录拓扑变化后，哪些已物化结构失效**。HLG 侧是连接边与 eID 区间，本方向是祖先聚合与快照。
- 若 HLG G1/G2 不通过（连通性不是瓶颈），本方向仍独立成立，因为它针对的是**更新**而非连通性。
- 本轮没有运行任何实验；U1–U5 的命令需在实现后由用户执行，助手提供目的、命令、资源与判定。

## 8. 未核实与边界

- Filtered-DiskANN 原文是否提供属性更新协议：**未核实**；MCI 与 EMA 的对比表互相矛盾，本文不选边。
- DIGRA、RangePQ+、Peng PVLDB 18(10)、DSG/ESF 的正文、保证与实验：**未读**，仅据 MCI 引用句记录其存在。
- MicroNN 等未过滤可更新索引：未读。
- EMA 的 Marker 假阳性界（Thm 4.6）依赖 Codebook 分辨率条件；其“动态支持”实测在 SIFT 系数据集上，未在大规模层级目录上验证。
- 本文不声称“层级谓词下的动态过滤 ANN 无人研究”；只记录已筛范围内未见对应工作，检索链未闭合。
