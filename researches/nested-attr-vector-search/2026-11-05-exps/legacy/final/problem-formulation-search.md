# Problem Formulation：CCS 概念 DAG 下的多属性 + 向量过滤搜索

> 2026-11-05 切换：本文件取代此前的 vector join 定义，成为当前主问题。旧的 join 定义保留在 `problem-formulation.md`（历史依据，不再是主线）。

## 1. 背景

学术文献与商品目录的知识组织往往是 **DAG**，不是树。ACM CCS 2012 实测：**1,929 个概念 / 2,040 条父边 / 1 根 / 103 个概念有 ≥2 个父（最大 3）/ 深度 0–6（1, 13, 82, 495, 989, 320, 29）**。一个概念可以有多个父，意味着它的后代集合是**可达闭包**，不能由单亲指针递推；同一对象也可能同时落在两个父概念的检索范围里。

检索需求是：**先按概念范围 + 若干属性过滤，再在该合格集内按向量找最近邻**。例如"检索 IR 与 ML 两个方向下、venue 为 A 类、2019 年之后的论文里，与查询向量最近的 10 篇"。

这与 vector join 是不同问题：这里输出**单次查询的 k 个对象**，不产生对象对，也不枚举全量结果。

## 2. 对象与层级

- 对象集 `O`，每个对象 `o=(v_o, c_o, σ_o)`：向量 `v_o ∈ ℝ^d`，**直接概念** `c_o ∈ V`（单一直属），属性状态 `σ_o`。
- 概念 DAG `G=(V,E)`，`E` 为"父 → 子"。`Desc⁺(c)` = `c` 自身及全部可达后代；`Anc⁺(c)` 同理。**多父概念必须按可达闭包计算**。
- 概念集合 `A ⊆ V` 表示查询范围，语义为 **OR**：`Eligible_c(A) = ⋃_{a∈A} Desc⁺(a)`。

## 3. 属性

- 维度集合 `F`（例如 venue、年份、是否有代码），每维取值域 `D_f`。
- `σ` 是部分函数：未定义 = **未知**。与 join 定义不同，这里未知的对象**不进入**属性过滤的结果（过滤是"必须满足"，不是"互不冲突"）。
- 查询谓词 `φ`：每维给一个约束（等值 / 集合 / 区间），未给约束的维度不限。
- `Eligible_φ = {o : ∀f∈dom(φ), σ_o(f) 已定义且满足 φ(f)}`。

## 4. 查询与输出

查询 `Q=(q, A, φ, k, ef)`：

```
R = argmin_k^{o ∈ Eligible_c(A) ∩ Eligible_φ} ‖q − v_o‖²
```

- 距离固定为平方 L2（FP32）。
- 返回至多 k 个对象；并列按对象 ID 升序截断。
- 合格集为空时必须返回空集并单独统计，不得回退到祖先范围或忽略属性约束。
- 是否要求精确 top-k 由 `ef` 与实现决定；报告时必须同时给出 `recall@k` 与 `k/ef`，**不同 ef 的结果不可直接比较**。

## 5. 指标

| 指标 | 定义 |
|---|---|
| `recall@k` | ties-aware 命中数 / `min(k, |Eligible|)`；欠填计入损失，不按返回数归一化 |
| 延迟 | 同批、同核、批内中位；分位报告 P50/P95 |
| 距离调用 | 每次向量比较计一次；与延迟分开报，不把次数下降当时间收益 |
| 内存 | 索引 + 位图 + 映射表；与基线同口径 |
| 空结果查询 | 次数与耗时单列，不进非空 recall 均值 |

## 6. 基线

| 基线 | 说明 |
|---|---|
| **S0 全局图 + 掩码** | 一张 HNSW（M=64）遍历，命中不合格对象则跳过；最朴素、也是"过滤后导航"的上界参照 |
| **NodeANN** | 每个非空概念一张完整 HNSW，查询时对范围内图各跑一次并归并 |
| **DAG 合并图** | 本地图导出 + 门户桥接成一张图、单队列（旧实现，需重建） |
| **pre-filter 精确** | 直接扫描合格集（小范围时的下界） |

## 7. 与树形目录的关键差别（本问题存在的理由）

1. **闭包不可单亲递推**：103 个多父概念使 `Desc⁺` 必须按可达性算；把 DAG 压成 canonical tree 会改变合格集。
2. **范围的重复覆盖**：落在一个多父概念下的对象，会同时属于其两个父概念的 scope；OR 查询必须去重，`|Scope|` 不等于各分支大小之和。
3. **入口集合不再是一条路径**：多父概念的入口需要覆盖多条祖先链。
4. 上述几点在纯树形目录里不出现，因此树形方案不能直接照搬。

## 9. 边界

- 本问题**不是** vector join：输出是单查询的 k 个对象，不是对象对；不枚举全量结果。
- 本问题**不是**平坦属性过滤：概念范围是拓扑谓词，按可达闭包解析，与属性谓词分属两层。
- 不确定项：属性谓词的表达力（等值 / 集合 / 区间）与是否允许对象多概念，需在实验前定稿；本定义默认**单一直属概念 + 单值属性**。
