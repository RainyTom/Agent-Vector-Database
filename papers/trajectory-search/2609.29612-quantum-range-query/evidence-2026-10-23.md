# Evidence — Quantum Range Query

Version: arXiv:2609.29612v1. Checked: 2026-10-23 via local PDF and alphaXiv page extraction.

- PDF p.1: trajectory geodata are polylines of `(x,y,t)` samples; the range query asks which segments intersect a spatiotemporal window and requires the exact intersecting set, not nearest-neighbor ranking.
- PDF p.2, §2.1: a record is `r_i=(tau_i,p_i,s_i,id_i)` with temporal, spatial, and semantic components; encoded keys are tested against an axis-aligned window `W=[l,u]`. The target output is the normalized quantum superposition of matching records.
- PDF p.2: classical materialization still costs `Omega(k)`; the quantum state is intended for downstream quantum operations.
- PDF pp.3–4, Table 1: experiments cover `Time`, `Space`, and `Space-time` queries on GeoLife, T-Drive, and GDP Drifter. They do not report a semantic-query column.
- PDF p.4, conclusion: extending index keys to semantic attributes is future work needed to complete the paper's spatial-temporal-semantic vision.

Classification: trajectory-level hybrid **range reporting**, not top-k similarity. It is relevant to the data model and hard constraints, but it does not solve semantic episode ranking.
