# Evidence — N-tree trajectory similarity search

Version: arXiv:2408.07650v1; formal version DOI 10.1145/3716825, ACM T-SAS 11(1), 2025. Checked: 2026-10-23 via local PDF, alphaXiv page extraction, and Crossref.

- PDF pp.1–2: supports exact metric-space kNN and radius-range queries over complete trajectories.
- PDF p.2: `DistanceAvg` is a spatio-temporal metric over continuous trajectories; trajectories are time-aligned by stretching or shrinking duration, so movement speed affects distance.
- PDF p.4: the N-tree returns exact result sets for the selected distance; it does not target approximate ANN.
- PDF p.16, Definition 5.1: defines ordinary metric radius range and kNN operators.
- No POI category/text semantic component and no subtrajectory/episode output are part of the query definition.

Classification: direct exact whole-trajectory similarity-index prior. It demonstrates that timestamps can participate in trajectory distance without providing semantic episode retrieval.
