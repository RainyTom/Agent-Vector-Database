# Evidence — REPOSE

Version: arXiv:2101.08929v2 / ICDE 2021. Checked: 2026-10-23 via local PDF, alphaXiv page extraction, and Crossref.

- PDF p.2, Definition 3: given trajectory set `D`, query trajectory `tau_q`, distance `Dist`, and `k`, return the `k` complete trajectories with smallest distance.
- PDF pp.1–2: supported distances include Hausdorff, Frechet, DTW, LCSS, EDR, and ERP.
- The trajectory representation is a time-ordered sequence of longitude/latitude samples; the evaluated task does not add POI/text semantics or an absolute-time predicate.
- The output unit is a complete trajectory, not a subtrajectory interval.
- Method: Spark distributed execution, heterogeneous global partitioning, and local reference-point tries with lower-bound pruning.

Classification: direct whole-trajectory top-k retrieval/indexing prior; relevant for scalable execution, not semantic episode localization.
