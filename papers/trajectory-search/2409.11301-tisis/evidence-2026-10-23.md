# Evidence — TISIS / TISIS*

Version: arXiv:2409.11301v2. Checked: 2026-10-23 via local PDF and alphaXiv page extraction.

- PDF p.1: TISIS indexes trajectories that share POIs in the same order; TISIS* adds POI embeddings for contextual POI similarity.
- PDF p.2, §2.1: query input is a POI trajectory `q` plus threshold `S`; output is every complete trajectory `t` satisfying `LCSS(q,t)/|q| >= S`.
- PDF p.2: TISIS uses exact POI equality. TISIS* uses Word2Vec POI embeddings and a user relaxation threshold.
- Timestamps establish chronological POI order, but elapsed time, absolute time windows, and duration do not enter the reported similarity predicate.
- Output is a threshold set of complete trajectories, not top-k episodes or subtrajectory intervals.

Classification: direct semantic-trajectory retrieval prior. The abstract alone is insufficient, but the full text explicitly confirms POI embeddings for TISIS*.
